# 날짜별 작업 인계 기록

이 폴더는 각 문서 작성일의 구현·검증·미해결 항목을 보존한다. 당시의 커밋 번호, 테스트 수, 미추적 파일 상태는 현재 작업 트리 상태와 다를 수 있다.

현재 동작은 최신 소스와 테스트, `docs/FOXMAINPC-VALIDATION-20261026.md`, `docs/BIAS-RETRY-NG.md`, `docs/MANUAL-BIAS-RESTORE.md`를 기준으로 확인한다. 과거 문서의 변경 제안이나 미해결 항목을 현재 요구사항으로 간주하지 않는다.

특히 2026-09-22 문서의 Raw 요청을 JPEG로 전환하는 구현은 이후 제거됐다. 현재 Raw 저장은 요청 형식을 유지하며 방사 측정 데이터가 없으면 실패로 보고한다.
