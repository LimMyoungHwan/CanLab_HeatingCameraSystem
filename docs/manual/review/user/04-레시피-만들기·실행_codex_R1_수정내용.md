# 04-레시피-만들기·실행 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 기본 작업 흐름은 이해하기 쉽지만, 저장 방식의 오류와 레시피·스텝별 설정 관계, 실행 반복 범위 및 중단 방법을 명확히 해야 한다.

## 수정 필요 항목
1. [4.2 새 레시피 만들기, 6번] 문제: “레시피는 파일로 저장됨”은 SAVE와 EXPORT의 역할을 혼동하게 하며, 실제 기본 저장소인 `data.db`와도 맞지 않음 -> 제안: “SAVE RECIPE를 누르면 시스템 내부 데이터베이스에 저장된다. JSON 파일 백업은 EXPORT를 사용한다”로 수정.
2. [4.2 새 레시피 만들기, 2번·4번] 문제: 상단의 챔버 목표 온습도와 각 스텝의 챔버 ℃/%RH가 어떤 관계인지 설명이 없어 어느 값을 입력해야 하는지 판단하기 어려움 -> 제안: 상단 값과 스텝 값의 적용 시점·우선순위를 명시하고, 같은 값이라면 중복 입력 여부를 설명.
3. [4.2 새 레시피 만들기] 문제: 필수 입력값, 허용 범위, 단위 및 저장 전에 확인할 항목이 제시되지 않음 -> 제안: 레시피 이름, 온습도, 좌표, 흑체 온도, 카메라 선택의 필수 여부와 화면상 허용 범위를 간단히 안내.
4. [4.3 라이브 프리뷰로 좌표 잡기] 문제: `USE CURRENT X/Y`로 가져온 좌표가 선택된 스텝에 즉시 반영되는지, 이후 SAVE가 필요한지 불명확함 -> 제안: 좌표 반영 대상과 저장 절차를 순서대로 명시.
5. [4.3 라이브 프리뷰로 좌표 잡기] 문제: 서보 이동과 원점 복귀 전에 필요한 안전 확인이 없음 -> 제안: 이동 범위에 사람이나 장애물이 없는지 확인하고, 비상정지 상태와 장비 연결 상태를 점검한 뒤 조작하도록 경고문 추가.
6. [4.5 레시피 실행과 진행 단계] 문제: 표만 보면 챔버 안정화부터 캡처까지의 과정이 전체 레시피에서 한 번만 수행되는지, 각 스텝마다 반복되는지 알기 어려움 -> 제안: 스텝별 반복 단계와 전체 레시피에서 한 번만 수행되는 단계를 구분해 설명.
7. [4.5 레시피 실행과 진행 단계] 문제: START 전 준비사항과 실행 중 중단 방법이 없음 -> 제안: PLC·카메라 Agent 연결, 대상 레시피와 카메라 확인 등 실제 선행 조건과 화면에서 제공하는 STOP/일시정지 기능의 동작을 확인해 안내.
8. [4.5 BB 안정화] 문제: “허용오차”의 값과 설정 위치가 제시되지 않아 대기 원인을 운전자가 판단하기 어려움 -> 제안: 허용오차를 어디에서 확인·변경하는지와 기준에 들지 않을 때의 대응 절차를 명시.
9. [4.5 캡처] 문제: “제한시간 기본 30초, 설정 가능”이라고 했지만 설정 위치가 없음 -> 제안: 실제 설정 화면 또는 설정 파일의 항목명을 명시하거나, 일상 운전자가 변경할 수 없다면 “관리자 설정값”으로 표현.

## 누락/추가 제안
- 레시피 이름 변경과 레시피 자체 삭제 방법을 추가.
- IMPORT 시 같은 이름의 레시피가 이미 있을 때 덮어쓰기·추가·오류 중 어떤 결과가 발생하는지 안내.
- 실행 전에 선택한 레시피의 스텝 순서, 좌표, 온습도, 흑체 온도 및 카메라를 최종 확인하도록 체크 절차 추가.
- 대시보드에서 레시피를 선택하고 START를 누르는 위치와 실행 상태를 확인하는 방법을 보여주는 이미지 추가.

## 이미지 자리 검토
- [그림 7] 적절 — 3분할 화면 구조와 각 작업 영역의 위치를 처음 설명하는 데 유용함.
- [그림 8] 적절 — 스텝별 입력 항목과 여러 스텝의 순서를 함께 확인할 수 있음. 드래그 영역, 삭제 버튼, SAVE RECIPE까지 표시되도록 캡처 범위를 넓히는 것이 좋음.
- [그림 9] 적절 — 영상, 좌표 이동, 셔터·카메라 및 조그 조작부를 한 번에 설명할 수 있음. `USE CURRENT X/Y`와 선택된 스텝의 관계가 보이도록 표시 또는 주석을 추가하는 것이 좋음.
- [4.5 실행 화면] 부적절(누락) — 핵심 작업인 레시피 선택, START, 진행 상태 및 중단 조작을 설명하는 대시보드 이미지가 필요함.
