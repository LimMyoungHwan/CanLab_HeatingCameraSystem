1. [5.1 챔버 / 온도 램프] 비상정지 주의사항 위치 이동 및 UI 명칭 일치
   - 문제: 섹션 맨 하단(5.4 다음)에 위치한 비상정지 주의사항이 5.1 챔버 조작 내용과 떨어져 있어 가독성이 떨어지며, 챔버 시작/정지 버튼의 UI 명칭('온도제어 시작', '온도제어 정지')이 매뉴얼 표현과 약간 상이함.
   - 제안: 5.1 섹션 내 챔버 버튼 설명 바로 아래로 `[주의] 비상정지` 블록을 이동시키고, 버튼 명칭을 실제 화면 UI와 정확히 일치시킴.

2. [5.3 서보 조작] 수치 단위(mm) 명시 및 JOG 버튼 동작 특성 서술
   - 문제: 서보 현재 위치 및 절대/상대 이동 수치의 단위(`mm`)가 누락되어 있고, JOG 버튼 조작 특성이 생략되어 운전자의 오조작 가능성이 있음.
   - 제안: X/Y 좌표 및 이동거리 수치 단위가 `mm`임을 명시하고, JOG 버튼은 "마우스 버튼을 누르고 있는 동안 이동하며 떼면 즉시 정지"함을 명확히 서술.

3. [5.4 흑체 / 카메라 제어] NATS 제어 Ack 응답 상태 표시 설명 추가
   - 문제: 카메라 제어 명령(RUN/STOP/셔터/캡처 등) 실행 시 선택된 카메라 제목 옆에 실시간 응답 상태(⏳ 전송 중, ✔ 성공, ✘ 실패)가 표시되는 현장 확인 요소가 누락됨.
   - 제안: 카메라 제어 버튼 조작 후 화면 상단에 표시되는 Ack 처리 결과 메시지 확인 방법에 대한 안내 추가.

4. [이미지 자리 - 그림 12, 그림 14] 캡처 대상 명칭 보완

## (선택) 수정 제안 전문

# 5. 수동 조작

레시피 없이 챔버·서보·흑체·장비·카메라를 직접 조작하는 화면이다. 초기 셋업, 점검, 좌표 확인 등에 사용한다. 화면 하단의 상태바를 통해 각 조작 명령의 처리 결과를 실시간으로 확인할 수 있다.

> 📷 **[그림 10] 수동 조작 전체**
> - **캡처 대상:** 수동 조작 화면 전체
> - **화면/상태:** 모든 수동 조작 카드가 보이는 상태
> - **표시 영역:** 창 전체


## 5.1 챔버 / 온도 램프

- **챔버 제어**: '온도제어 시작' / '온도제어 정지', '비상정지', '습도제어' 체크박스 토글. 목표 온도(℃) 및 목표 습도(%) 입력 후 각각 '적용' 버튼 클릭.
- **온도 램프**: 목표 온도(℃)와 도달시간(분) 입력 후 '램프 시작' 또는 '중지' 버튼 클릭 (지정된 시간 동안 선형 스텝 승온/강온 수행).

> **[주의]** 비상정지 버튼(붉은색)은 즉시 챔버 온도제어를 정지시킨다. 실제 설비 이상 발생 시 주저하지 말고 클릭한다.

> 📷 **[그림 11] 챔버·온도 램프 카드**
> - **캡처 대상:** 수동 조작 좌측 상단의 챔버 카드와 온도 램프 카드
> - **화면/상태:** 정상 설정값 입력 및 표시 상태
> - **표시 영역:** 창 왼쪽 위


## 5.2 모터/팬 · 장비 원터치

- **모터/팬**: 서보 속도 비율(1~100%) 입력 후 '적용', 목표 팬 속도(Hz) 입력 후 '적용'. 오른쪽에서 현재 측정 팬 속도(Hz)를 실시간 확인.
- **장비 원터치**: 1차/2차/상온 냉동기, 블로워1/2, 칠러, 도어락, 조명, 페어글라스 토글 버튼 (클릭 시 초록색 하이라이트 표시되며 On/Off 전환).

> 📷 **[그림 12] 모터/팬 · 장비 원터치 카드**
> - **캡처 대상:** 모터/팬 설정 카드 및 장비 원터치 토글 스위치 카드
> - **화면/상태:** 각 토글 스위치의 On/Off 하이라이트 상태가 보이도록 캡처
> - **표시 영역:** 창 가운데/우측 상단


## 5.3 서보 조작

- **서보 상태**: X/Y축 현재 위치(mm), X/Y BUSY 램프(이동 중 녹색 점등), 현재 위치한 포인트 번호 표시.
- **JOG 이동**: X축/Y축 `+`/`-` JOG 버튼 (마우스 버튼을 누르고 있는 동안 해당 방향으로 continuous 이동, 마우스를 떼면 즉시 정지).
- **원점 복귀**: `X 원점` / `Y 원점` 버튼을 클릭하여 각 축을 원점으로 이동.
- **절대 위치 이동**: 목표 X/Y 좌표(mm) 입력 후 `X 이동` 또는 `Y 이동` 버튼 클릭.
- **상대 위치 이동**: 이동 스텝값(mm) 입력 후 X/Y의 `+` / `-` 버튼 클릭.
- **포인트 이동**: 사전 설정된 1~20번 포인트 버튼을 클릭하여 해당 위치로 즉시 이동.

> 📷 **[그림 13] 서보 조작 카드**
> - **캡처 대상:** 서보 조작 카드(위치/BUSY/JOG/원점/절대·상대 이동) 및 20개 포인트 이동 버튼 카드
> - **화면/상태:** 서보 좌표 수치 및 BUSY 램프가 표시된 상태
> - **표시 영역:** 창 가운데


## 5.4 흑체 / 카메라 제어

- **흑체 제어**: 흑체 1 / 흑체 2 각각의 목표 온도(℃) 입력 후 '적용' 버튼 클릭, 오른쪽에 현재 흑체 온도(℃) 실시간 표시.
- **카메라 제어**:
  - 선택 영역: 대상 카메라 선택 드롭다운, 컬러맵(컬러/그레이스케일) 선택 드롭다운.
  - 모니터링 & 상태: 실시간 영상 라이브 뷰어 및 명령 수신 상태(⏳ 전송 중 / ✔ 성공 / ✘ 실패) 확인.
  - 기능 버튼: `RUN`, `STOP`, `셔터 열기`, `셔터 닫기`, `캡처`, `NUC`(비균일성 보정), `설정 저장`, `정보 갱신`.

> 📷 **[그림 14] 흑체 및 카메라 제어 카드**
> - **캡처 대상:** 수동 조작 하단의 흑체 카드 및 카메라 제어 카드 (실시간 영상 + 제어 버튼)
> - **화면/상태:** 카메라 라이브 영상 출력 및 ACK 수신 상태가 표시된 상태
> - **표시 영역:** 창 아래쪽
