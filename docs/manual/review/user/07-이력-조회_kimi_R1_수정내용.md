• # 07-이력-조회 — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 중
  - 한 줄 요약: 화면 구조·컬럼·알람 수준 필터 등 기본 기술은 실제 구현(`HistoryView.xaml`, `HistoryViewModel.cs`)과 일치하나, 'CSV 내보내기'의 실제 동작(촬영 이력 전용·현재 탭 무관)과 카메라 필터의 실제 선택지가 부정확하고, 페이지네이션·기본 조회 기간·상세 창 닫기 등 운전자에게 필요한 정보가 누락됨.

  ## 수정 필요 항목
  1. [7.1 필터] 문제: "카메라 필터"라고만 기술되어 있으나 실제로는 카메라 **그룹** 콤보박스이며 선택지가 고정되어 있음(전체 / Agent-PC-01 (CAM-01~16) / Agent-PC-02 (CAM-17~32) / Agent-PC-03 (CAM-33~64)). 개별 카메라 단위 필터가 아니므로 운전자가 오해할 수 있음 → 제안: "카메라 그룹 필터(전체 / Agent-PC-01 / Agent-PC-02 / Agent-PC-03 — 각 16대 단위)"로 구체화.
  2. [7.1 CSV 내보내기] 문제: "'CSV 내보내기'로 표를 파일로 저장"은 현재 보이는 표가 내보내진다는 인상을 주지만, 실제 구현(`ExportCsv`)은 **현재 탭과 무관하게 항상 촬영 이력만** 내보냄. 챔버/알람 이력은 CSV 내보내기가 불가능 → 제안: "CSV 내보내기는 촬영 이력 전용이며, 챔버 이력·알람 이력은 지원하지 않는다"고 명시.
  3. [7.1 CSV 내보내기] 문제: 내보내기 범위 미기재. 실제로는 현재 페이지가 아닌 **필터 조건에 맞는 전체 레코드**를 내보내며, CSV 컬럼(Timestamp, CameraId, Temperature, Humidity, RecipeStepId, ImagePath)은 화면 표와 다름(썸네일 대신 이미지 경로·레시피 스텝 ID 포함) → 제안: 내보내기 범위와 CSV 컬럼 구성을 한 줄로 안내.
  4. [7장 전체] 문제: 페이지네이션 누락. 모든 탭에 페이지당 10건, 하단 « ‹ › » 페이지 이동 버튼과 "N / 전체 페이지" 표시가 있으나 챕터에 전혀 언급 없음 → 제안: 7.1에 "조회 결과는 페이지당 10건씩 표시되며 하단 버튼으로 페이지 이동" 항목 추가.
  5. [7.1 필터] 문제: 기본 조회 기간 미기재. 화면 진입 시 시작일=오늘-2일, 종료일=오늘 23:59:59로 자동 설정되어 바로 조회됨 → 제안: "기본 조회 기간은 최근 3일"임을 명시하면 운전자가 오래된 데이터가 안 보일 때 혼란을 줄일 수 있음.
  6. [7.3 이미지 상세 보기] 문제: 상세 창 닫는 방법(우상단 ✕ 버튼) 미기재 → 제안: "우상단 ✕ 버튼으로 닫는다" 한 줄 추가.

  ## 누락/추가 제안
  - 상세 창의 열화상 스케일 바 상·하한(예: 70°/10°)이 현재 고정 표시인지 실측 연동인지 매뉴얼에서 명확히 할 것 — 실제 구현은 고정 라벨이라, 운전자가 해당 이미지의 실제 온도 범위로 오독할 우려가 있음. (코드 개선 예정이라면 그에 맞춰 서술)
  - CSV 내보내기 완료 시 하단 상태 표시줄에 "Exported N records to ..." 메시지가 표시됨 — 내보내기 성공 확인 방법으로 언급 권장.
  - 알람 수준 필터의 실제 선택지(전체 / 정보 이상 / 경고 이상 / 오류만)를 괄호로 열거하면 운전자 이해에 도움.

  ## 이미지 자리 검토
  - [그림 17] 적절 — 필터+표+썸네일이 이 챕터의 핵심 화면. 캡처 시 카메라 그룹 콤보박스와 하단 페이지네이션 바까지 프레임에 포함되도록 "표시 영역"을 보완하면 더 좋음.
  - [그림 18] 적절 — 챔버 이력 표 구성(Time/Temp/Humidity/BB1/BB2) 확인용으로 필요.
  - [그림 19] 적절 — 알람 수준 필터가 이 탭에만 나타나는 차별점이므로 캡처 시 필터 영역이 잘 보이게 찍도록 지시 유지 권장.
  - [그림 20] 적절 — 모달 팝업과 메타정보 바 구성 전달에 유효. 다만 스케일 바 라벨(70°/10°)이 고정값이므로 캡처 이미지의 실제 온도와 괴리가 생길 수 있음을 캡처 담당자에게 주지시키면 좋음.
