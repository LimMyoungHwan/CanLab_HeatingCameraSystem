# 01-이-매뉴얼에-대하여 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 대상 독자와 범위는 명확하지만, 별도 매뉴얼의 명칭과 시스템 구성 설명·그림 지시문의 일관성을 보완해야 한다.

## 수정 필요 항목
1. [도입부/다루지 않는 내용] 문제: 설치·설정 등 관리 작업의 참조 문서를 `[운영자 매뉴얼]`이라고 표기해 현재 매뉴얼과 구분하기 어렵다. -> 제안: 실제 문서명에 맞춰 `[관리자 매뉴얼]` 등으로 통일하고 링크를 연결한다.
2. [1.1 시스템 한눈에 보기] 문제: Master가 챔버·서보·흑체를 제어한다고 설명하지만, 구성 요소 목록에는 해당 제어 대상이나 PLC 통신 경로가 나타나지 않는다. -> 제안: 일상 운전자에게 필요한 수준에서 “PLC/설비 제어부 — Master의 명령으로 챔버·서보 등을 동작” 항목을 추가하거나, 그림 1에 제어 경로를 표시한다.
3. [1.1 시스템 한눈에 보기] 문제: “각 지점의 온도·습도와 함께 이미지를 저장”이라는 문장은 온도·습도가 어디에서 측정되고 어떤 결과에 함께 저장되는지 불분명하다. -> 제안: 실제 동작에 맞춰 측정 주체와 저장 위치를 짧게 명시한다.
4. [그림 1 캡처 대상] 문제: 본문에서는 “서보”를 언급하지만 그림 설명에는 의미가 불명확한 “서버”가 적혀 있다. -> 제안: NATS 서버를 뜻한다면 “NATS 서버”로 구체화하고, 오기라면 “서보”로 수정한다.
5. [그림 1 화면/상태] 문제: “그대로 써도 됨”은 제작 과정의 메모처럼 보여 완성된 매뉴얼 문구로 부적절하다. -> 제안: 최종 그림으로 교체한 뒤 해당 제작 지시문은 삭제한다.

## 누락/추가 제안
- 첫 화면에서 이 매뉴얼과 별도 관리 문서를 즉시 구분할 수 있도록 실제 문서명과 링크를 명확히 제시한다.
- “레시피”를 처음 사용하는 독자를 위해 “촬영 조건과 순서를 미리 정한 작업 절차”처럼 한 번 더 풀어 설명하면 이해하기 쉽다.

## 이미지 자리 검토
- [그림 1] 적절 — 시스템 구성 요소와 Master 중심의 관계를 처음 소개하는 위치로 적절하다. 다만 사진과 네트워크 구성도 중 하나를 확정하고, Master→PLC/설비 및 Master↔Agent의 흐름을 운전자 관점에서 간단히 표시해야 한다.
