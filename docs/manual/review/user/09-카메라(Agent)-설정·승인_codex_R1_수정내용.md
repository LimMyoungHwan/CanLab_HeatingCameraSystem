# 09-카메라(Agent)-설정·승인 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 화면 구성은 간결하게 소개했지만, Agent와 카메라의 관계 및 승인 절차가 불명확해 운전자가 실제 조치하기에는 정보가 부족하다.

## 수정 필요 항목
1. [도입부] 문제: ‘Agent’, ‘카메라 PC’, ‘카메라’를 혼용해 각각 같은 대상인지 별도 장치인지 알기 어렵다. -> 제안: Agent는 카메라 PC에서 실행되는 프로그램이고, 하나의 Agent가 카메라 목록을 관리한다는 관계를 먼저 설명한다.
2. [탭1 ‘에이전트 원격설정’] 문제: 기능만 나열되어 있으며 설정 조회·변경·전송 순서와 전송 성공 확인 방법이 없다. -> 제안: `온라인 Agent 선택 → 조회 → 필요한 값 변경 → 전송 → 성공 여부 확인` 순서로 기본 절차를 제시한다.
3. [탭1 ‘에이전트 원격설정’] 문제: NATS, 저장 경로, 하트비트 등 일상 운전자가 임의로 바꾸면 연결이나 촬영에 영향을 줄 수 있는 항목에 경고가 없다. -> 제안: 해당 값은 관리자 지시 없이 변경하지 않도록 주의문을 추가한다.
4. [탭2 ‘디바이스 관리’] 문제: 승인·거부·이름 저장·시리얼 설정 전송·로그 가져오기가 한 문장에 나열되어 각 기능의 대상과 사용 시점을 구분하기 어렵다. -> 제안: 운전자에게 필요한 ‘미승인 장치 확인 및 승인’ 절차를 중심으로 쓰고, 나머지는 용도별로 분리하거나 운영자 매뉴얼로 안내한다.
5. [[참고] 문구] 문제: “자동 발견·승인은 운영자 매뉴얼 7장 참조”는 자동으로 승인된다는 의미로 읽힐 수 있어, 앞의 수동 승인 설명과 충돌한다. -> 제안: 실제 동작에 맞춰 “자동 발견 및 수동 승인 절차”처럼 발견과 승인을 구분해 표현한다.
6. [[참고] 문제 해결] 문제: Approved 상태 확인 뒤 무엇을 해야 하는지 안내가 끝난다. -> 제안: 미승인 상태라면 장치를 선택해 승인하고, 승인 후에도 촬영되지 않으면 담당자에게 문의하도록 후속 조치를 명시한다.

## 누락/추가 제안
- 원격 설정을 전송하면 Agent 재시작이 필요한지, 즉시 적용되는지 명시가 필요하다.
- 승인과 거부가 촬영 가능 여부에 미치는 영향을 한 문장으로 설명하는 것이 좋다.
- 오프라인 Agent는 조회·설정 전송이 가능한지, 목록에 나타나지 않을 때 운전자가 확인할 기본 항목을 추가하는 것이 좋다.
- ‘Approved’처럼 화면에 영문 상태가 표시된다면 `승인됨(Approved)`으로 병기해 이후 용어를 통일한다.

## 이미지 자리 검토
- [그림 22] 적절 — Agent 선택, 조회된 설정값, 카메라 목록을 한 화면에서 보여 주므로 탭 구성 이해에 유용하다. 단, ‘조회’와 ‘전송’ 버튼 및 온라인 상태가 식별되도록 캡처 설명을 보완해야 한다.
- [그림 23] 적절 — 미승인 장치의 상태와 승인 조작 위치를 안내하는 핵심 이미지다. 승인 전 상태가 표시된 장치를 선택하고 승인·거부 버튼이 보이는 상태로 캡처하는 편이 목적에 더 잘 맞는다.
