# 05-수동-조작 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 기능 나열은 정확하나, 비상정지 경고 위치가 부적절하고 초심자 대상 설명(포인트·NUC 등)이 부족함.

## 수정 필요 항목
1. [문서 최하단 "[주의]" 박스] 문제: 비상정지는 5.1 챔버 카드의 기능인데, 경고문이 5.4 카메라 제어 뒤(문서 맨 끝)에 배치되어 있어 챔버 조작 시점에 놓치기 쉬움 -> 제안: 5.1 챔버/온도 램프 섹션 바로 아래로 이동.
2. [5.2 모터/팬 · 장비 원터치] 문제: "서보 속도(1~100%) 적용"이라는 표현과 5.3 "서보 조작"(위치 이동)이 같은 "서보" 용어를 다른 의미로 사용해 혼동 가능 -> 제안: 5.2 항목명을 "모터/팬 속도"처럼 서보란 단어를 피하거나, 괄호로 "(회전 속도, 위치 이동과 별개)" 부기.
3. [5.3 서보 조작 - 포인트 이동] 문제: "1~20번 포인트"가 무엇을 의미하는지(사전 저장된 좌표인지, 어디서 등록하는지) 설명 없음 -> 제안: 포인트가 레시피/설정 화면에서 등록되는 좌표임을 한 줄 부연.
4. [5.4 흑체/카메라 제어] 문제: RUN/STOP, 셔터 열기/닫기, 캡처, NUC 순서 관계 설명 없음(예: 캡처 전 셔터 열어야 하는지, NUC은 언제 수행하는지) -> 제안: 정상 촬영 절차 순서를 한 줄로 명시.
5. [5.4 카메라 제어] 문제: "NUC"이 무엇의 약자인지 일상 운전자에게 생소함 -> 제안: "NUC(비균일 보정)" 정도로 최초 등장 시 병기.
