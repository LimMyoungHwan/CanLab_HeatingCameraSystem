# 05-수동-조작 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 높음 (상)
- 한줄 요약: 조작 항목은 폭넓게 나열되어 있으나 실제 운전자가 안전하게 따라 할 조작 절차, 실행 조건, 결과 확인 방법이 부족하고 일부 용어와 기능 설명이 모호하다.

## 수정 필요 항목
1. [장 전체] 문제: 기능 목록만 제시되어 있어 운전자가 무엇을 먼저 확인하고 어떤 순서로 조작해야 하는지 알기 어렵다. → 제안: 각 기능을 `사전 조건 → 입력 또는 선택 → 실행 → 결과 확인` 순서로 설명한다.
2. [장 도입부] 문제: 수동 조작을 시작하기 전에 자동 운전의 정지 여부, 통신 상태, 비상정지 상태 등을 확인하라는 안내가 없다. → 제안: “자동 운전이 정지되어 있고 PLC·Agent·카메라가 정상 연결된 상태에서 사용한다”는 사전 점검 절차를 추가한다.
3. [장 전체] 문제: 버튼을 눌러도 동작하지 않을 때 확인할 항목이 없다. → 제안: 비상정지, PLC 연결, 서보 BUSY, Agent 연결, 카메라 선택 상태를 확인하도록 안내한다.
4. [5.1 챔버 / 온도 램프] 문제: 목표 온도와 목표 습도를 입력한 뒤 각각 `적용`을 눌러야 하는지, 적용 결과를 어디에서 확인하는지 불명확하다. → 제안: 입력 가능한 범위와 단위를 밝히고, 적용 후 현재값 또는 목표값 표시가 갱신되는지 확인하도록 설명한다.
5. [5.1 챔버 / 온도 램프] 문제: 챔버 시작·정지와 온도 램프 시작·중지의 관계가 설명되지 않았다. → 제안: 챔버 운전 중에만 램프가 동작하는지, 램프 중지 시 목표 온도가 유지되는지 또는 현재값에서 멈추는지 명시한다.
6. [5.1 챔버 / 온도 램프] 문제: 비상정지가 “챔버 온도제어”만 정지하는 것으로 설명되어 다른 설비에 미치는 영향이 불명확하다. → 제안: 실제 정지 대상과 해제·복구 절차를 정확히 기술하고, 하단 주의문과 같은 용어로 통일한다.
7. [5.2 모터/팬·장비 액추에이터] 문제: `모터/팬`, `팬 속도(Hz)`, `현재 팬 Hz`의 대상과 관계가 모호하다. → 제안: 각 입력값이 제어하는 장비를 구분하고 허용 범위와 적용 후 확인 위치를 명시한다.
8. [5.2 장비 액추에이터] 문제: 토글 스위치를 켰을 때 실제 장비가 즉시 동작하는지, 화면 상태만 변경되는지 설명이 없다. → 제안: “토글 즉시 PLC 명령이 전송된다”와 같이 동작 방식을 밝히고, 실제 상태 표시로 결과를 확인하도록 안내한다.
9. [5.2 장비 액추에이터] 문제: `1차/2차 고온 평동기`, `블로워/2`, `칠러`, `에어건`, `조명`, `하어글라스`로 보이는 명칭 중 일부가 불명확하거나 표기가 깨져 있다. → 제안: 실제 화면의 장비명과 대조하여 정확한 정식 명칭으로 수정한다.
10. [5.3 서보 조작] 문제: X/Y 위치와 BUSY 표시의 의미, 동작 가능한 상태가 설명되지 않았다. → 제안: BUSY가 켜져 있을 때 추가 이동 명령을 금지하고, 꺼진 뒤 다음 명령을 실행하도록 명시한다.
11. [5.3 서보 조작] 문제: JOG 버튼을 누르는 동안 이동한다고만 되어 있고 이동 방향, 이동 한계, 손을 떼었을 때 정지 여부가 불명확하다. → 제안: 각 버튼의 `+/-` 방향을 설명하고, 이동 중 충돌 위험이 있으면 즉시 버튼에서 손을 떼도록 경고한다.
12. [5.3 서보 조작] 문제: X/Y 원점 복귀의 순서와 원점 복귀 완료 확인 방법이 없다. → 제안: 주변 간섭물을 확인한 뒤 원점 버튼을 누르고, BUSY 해제 및 위치 표시를 통해 완료를 확인하도록 절차를 추가한다.
13. [5.3 서보 조작] 문제: 절대 위치와 상대 위치 입력값의 단위, 허용 범위 및 음수 입력 가능 여부가 없다. → 제안: 화면에서 사용하는 단위와 입력 범위를 명시하고 범위를 벗어난 값은 입력하지 않도록 안내한다.
14. [5.3 서보 조작] 문제: 포인트 이동 1~20번의 좌표 출처와 실행 결과가 설명되지 않았다. → 제안: 저장된 포인트 좌표로 이동하는 기능임을 밝히고, 포인트 설정·변경 위치 또는 관련 절을 안내한다.
15. [5.4 객체 / 카메라 제어] 문제: `객체1/2 목표(℃)`가 무엇을 제어하거나 판정하는 값인지 불명확하다. → 제안: 측정 대상, 현재값과 목표값의 의미, 적용 결과를 명시한다.
16. [5.4 카메라 제어] 문제: 카메라 선택과 컬러맵 선택 후 별도의 적용 조작이 필요한지 설명되지 않았다. → 제안: 선택 즉시 적용되는지 또는 명령 버튼을 눌러야 하는지 정확히 기술한다.
17. [5.4 카메라 제어] 문제: RUN, STOP, 셔터 열기·닫기, 캡처, NUC의 실행 조건과 정상 결과가 없다. → 제안: 각 버튼별로 선행 조건과 화면에서 확인할 결과를 표 또는 단계별 절차로 정리한다.
18. [5.4 카메라 제어] 문제: NUC가 약어로만 표시되어 일반 운전자가 기능과 주의점을 이해하기 어렵다. → 제안: “NUC(비균일 보정)”로 풀어 쓰고, 보정 중 영상이 일시 중단될 수 있는지 등 실제 동작상의 주의사항을 추가한다.
19. [5.4 카메라 제어] 문제: `설정 저장`과 `정보 갱신`의 저장 대상, 저장 위치, 갱신 대상이 불명확하다. → 제안: 저장되는 설정과 적용 시점, 정보 갱신으로 다시 읽는 항목을 구체적으로 설명한다.
20. [하단 주의문] 문제: 비상정지 사용 시 실제 설비에서 이상 상황 여부를 주시하라는 표현만 있고 인명·설비 안전 절차가 부족하다. → 제안: 위험 시 현장 비상정지를 우선 사용하고, 원인 확인 및 안전 확보 전에는 재가동하지 않도록 경고한다.

## 누락/추가 제안
- 수동 조작 전에 자동 운전을 정지하고 관련 장비의 연결 상태를 확인하는 공통 사전 점검 절차를 추가한다.
- 원격 화면의 표시와 실제 장비 상태가 다를 수 있으므로, 구동 장비 조작 시 현장 안전을 함께 확인하도록 경고한다.
- 서보 이동 전에 이동 경로에 사람이나 장애물이 없는지 확인하도록 별도의 위험 경고를 배치한다.
- 온도·습도·속도·좌표 입력값마다 단위와 허용 범위를 추가한다.
- 각 명령의 성공·실패 또는 통신 오류가 어디에 표시되는지 설명한다.
- 장비가 동작 중인 상태에서 화면을 전환하거나 프로그램을 종료할 때의 처리 방법을 안내한다.
- 캡처 결과의 저장 여부와 저장 위치를 관련 장으로 연결한다.

## 이미지 자리 검토
- [그림 10] 적절 — 화면 전체 구성과 각 조작 영역의 위치를 먼저 파악하는 데 유용하다. 단, 주요 영역을 번호나 테두리로 구분하면 이후 설명과 연결하기 쉽다.
- [그림 11] 적절 — 챔버와 온도 램프 기능을 함께 설명하는 위치가 자연스럽다. 목표값 입력란, 적용 버튼, 시작·중지 버튼이 식별되도록 표시해야 한다.
- [그림 12] 적절 — 다수의 액추에이터 토글 상태를 확인하는 데 필요하다. 켜짐과 꺼짐의 시각적 차이가 보이는 상태로 촬영해야 한다.
- [그림 13] 적절 — 서보 조작부는 버튼이 많아 이미지가 특히 유용하다. JOG 방향, 원점, 절대·상대 이동, 포인트 이동 영역을 각각 표시해야 한다.
- [그림 14] 적절 — 실시간 영상과 카메라 명령 버튼을 함께 보여 주어 조작 결과를 이해하는 데 도움이 된다. 선택된 카메라와 영상 수신 정상 상태가 명확히 보이도록 촬영해야 한다.
