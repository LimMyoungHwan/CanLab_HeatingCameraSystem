4. **[등급 필터] 문제:** 선택 방식과 기본값이 없다. → **제안:** 단일 선택 콤보 상자이며 기본값은 `전체`, 선택지는 `전체/정보/경고/오류`라고 명시한다. 선택 등급과 정확히 일치하는 현재 알람만 표시된다. (Codex)
5. **[✕ 버튼] 문제:** 삭제와 설비 오류 해제가 혼동된다. → **제안:** 각 항목의 ✕는 별도 선택·상세 확인 없이 해당 항목을 현재 메모리 목록에서 제거할 뿐이며 PLC 상태, 부저 또는 오류 비트를 변경하지 않는다고 경고한다. (Codex, Claude, agy)
6. **[알람 확인 용어] 문제:** 코드에는 확인·인지 상태가 없다. → **제안:** “확인”은 화면의 발생 시각·발생원·메시지를 읽는 행위로 설명하고, ✕는 `알람 삭제`로 표기한다. (Codex, Claude)
7. **[알람 이력] 문제:** 현재 목록 삭제와 이력 보존 관계가 없다. → **제안:** 알람은 발생 시 별도 이력 저장소에 기록되므로 현재 목록에서 ✕로 지워도 이력은 유지된다고 명시한다. `이력 조회` 화면에서 `알람 이력` 탭을 선택하고 시작일·종료일·알람 수준을 설정한 뒤 `조회`를 누르는 절차를 추가한다. (Codex, Claude, agy)
8. **[이력 등급 조건] 문제:** “기간·등급” 설명이 실제 UI보다 모호하다. → **제안:** 알람 수준은 `전체/정보 이상/경고 이상/오류만` 조건으로 조회된다고 정확히 적는다. (Codex)

10. **[PLC 에러 리셋] 문제:** 실제 처리 범위가 과장될 수 있다. → **제안:** 버튼은 PLC 에러 리셋 트리거 비트에 모멘터리 펄스를 전송한다고 기술한다. 클릭 자체를 오류 해제 완료로 표현하지 않는다. (Codex, Claude, agy)
11. **[PLC 원점 복귀] 문제:** 그림에는 있으나 본문에 없다. → **제안:** 별도 항목을 추가한다. 현재 구현은 X/Y 좌표를 0,0으로 설정한 포인트 1 이동을 요청한다. 수동 제어 화면의 축별 `HomeAsync`와 동일한 기능으로 설명하지 않는다. (Codex, Claude, agy)
