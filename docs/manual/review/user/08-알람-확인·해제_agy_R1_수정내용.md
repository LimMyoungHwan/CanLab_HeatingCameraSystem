# 8. 알람 확인·해제

설비 운용 중 발생하는 이벤트 및 이상 상태는 화면 좌측의 알람 패널을 통해 실시간으로 확인하고 조치할 수 있다.

> 📷 **[그림 21] 알람 패널·공용 버튼**
> - **캡처 대상:** 좌측 알람 목록과 PLC 부저 OFF / 에러 리셋 / 원점 복귀 버튼
> - **화면/상태:** 실시간 알람이 표시되고 제어 버튼이 활성화된 상태
> - **표시 영역:** 창 왼쪽


## 8.1 실시간 알람 목록 확인

- **실시간 알람 표시**: 발생한 알람은 최신순으로 좌측 목록에 실시간 추가된다. 알람은 심각도에 따라 **정보**, **경고**, **오류** 등급으로 구분된다.
- **등급 필터**: 목록 상단의 등급 필터([전체], [정보], [경고], [오류])를 선택하여 특정 등급의 알람만 선별해 볼 수 있다.
- **알람 항목 제거**: 각 알람 항목 우측의 **✕** 버튼을 클릭하면 해당 알람을 목록에서 삭제할 수 있다.

> ⚠️ **주의**  
> 알람 목록의 **✕** 버튼은 UI 화면에서 해당 알람 표시를 지우는 기능입니다. PLC의 경고 경보음이나 물리적 에러 상태 자체를 해제하지 않으므로, 에러 발생 시에는 아래의 **PLC 에러 리셋** 절차를 진행하십시오.


## 8.2 PLC 부저 OFF 및 에러 리셋

PLC 이상 및 경보 발생 시 좌측 패널 하단의 공용 제어 버튼을 통해 경보음을 끄고 에러를 해제한다.

1. **PLC 부저 OFF**: PLC 경보 부저가 울릴 때 `PLC 부저 OFF` 버튼을 누르면 부저 소리가 즉시 소음(음소거) 처리된다.
2. **원인 조치 및 에러 리셋**: 발생 원인(비상정지, 온도 이상, 서보 이동 제한 등)을 확인 및 해제한 후 `PLC 에러 리셋` 버튼을 클릭하여 PLC 에러 상태를 리셋한다.
3. **원점 복귀 및 복구**: PLC 에러가 발생했던 경우 에러 리셋 후 `원점 복귀` 버튼을 실행하여 서보 축 원점 복귀가 완료되어야 레시피 재가동 인터록이 해제된다.


## 8.3 과거 알람 이력 조회

실시간 알람 목록에서 삭제되었거나 과거에 발생한 알람 기록은 메인 메뉴의 **이력 조회** → **[알람 이력]** 탭에서 기간 및 등급 조건별로 다시 조회할 수 있다.
