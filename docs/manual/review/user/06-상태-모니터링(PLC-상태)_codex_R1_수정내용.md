# 06-상태-모니터링(PLC-상태) — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 화면 구성은 간결하게 정리되어 있으나, 연결 이상과 값 갱신 실패 시 운전자가 어떻게 판단하고 대응해야 하는지 설명이 부족하다.

## 수정 필요 항목
1. [도입부] 문제: “약 1초 주기”가 정상 연결 상태에서의 갱신 주기인지 불명확하다. -> 제안: “PLC가 정상 연결된 동안 약 1초마다 상태를 갱신한다”로 조건을 명시한다.
2. [도입부] 문제: 읽기 전용 화면이라는 설명은 있으나, 표시된 조작 요소가 있더라도 이 화면에서는 제어할 수 없다는 점이 충분히 강조되지 않는다. -> 제안: “이 화면에서는 PLC 값이나 장비 상태를 변경할 수 없다”라고 명확히 안내한다.
3. [상단 요약] 문제: “PLC 연결”이 상태값인지 단순 항목명인지 모호하다. -> 제안: 실제 화면 표현에 맞춰 “PLC 연결 상태”로 표기한다.
4. [상단 요약] 문제: “진행 상태(스텝/진행바)”의 스텝이 현재 번호인지 전체 대비 값인지 알기 어렵다. -> 제안: 실제 표시 형식에 맞춰 예시를 추가하거나 “현재 스텝과 전체 진행률”처럼 의미를 설명한다.
5. [상단 요약] 문제: “서보 포인트(POINT·X/Y)”에서 POINT와 X/Y의 의미 및 단위가 설명되지 않았다. -> 제안: POINT는 현재 위치 포인트인지 목표 포인트인지 명시하고, X/Y 값에 단위가 표시된다면 해당 단위도 적는다.
6. [카드 목록] 문제: 카드 이름만 나열되어 있어 각 카드에서 무엇을 확인할 수 있는지 일상 운전자에게 충분한 안내가 되지 않는다. -> 제안: 각 카드별 주요 확인 항목을 한 문장씩 설명한다.
7. [PLC 알람 카드] 문제: 활성 오류가 빨간색이라는 설명만 있고, 오류 발생 시 운전자의 대응 절차가 없다. -> 제안: 자동 운전을 계속해도 되는지 판단하지 말고 오류 내용 확인 후 담당자에게 알리도록 안내하며, 실제 제공되는 오류 정보의 범위도 명시한다.
8. [하단 표시등] 문제: “입력 P000~ · 출력 P020~”의 물결표가 정확한 주소 범위를 나타내지 않아 표시 대상이 불명확하다. -> 제안: 화면에 표시되는 시작·끝 주소를 정확히 적거나, 범위가 가변적이면 “화면에 구성된 PLC 입력·출력 신호”로 표현한다.
9. [하단 표시등] 문제: 표시등의 켜짐/꺼짐이 각각 어떤 논리 상태를 뜻하는지 설명이 없다. -> 제안: 색상과 ON/OFF 의미를 실제 화면 기준으로 추가하고, 점등 자체가 반드시 장비의 정상 상태를 의미하지는 않는다는 점을 알린다.

## 누락/추가 제안
- PLC 연결 끊김, 갱신 정지 또는 값 미표시 상태를 식별하는 방법과 기본 대응 절차를 추가한다.
- 화면 값이 약 1초 간격으로 갱신되므로 순간적인 신호 변화는 놓칠 수 있다는 주의사항을 추가한다.
- 온도·습도·좌표 등 수치 항목에 화면에서 사용하는 단위를 명시한다.
- PLC 알람과 장비 상태 표시등의 차이를 간단히 설명한다.
- 이 화면이 상태 확인용이며 실제 장비 이상 여부는 알람 내용과 현장 상태를 함께 확인해야 한다는 주의사항을 추가한다.

## 이미지 자리 검토
- [그림 15] 적절 — 전체 화면 구성과 상단 요약 및 카드 위치를 한 번에 확인할 수 있어 유용하다. 다만 연결 상태, 정상 수치, 진행 상태가 식별되도록 캡처 조건을 더 구체화하는 것이 좋다.
- [그림 16] 적절 — 주소별 입출력 및 장비 상태 표시등을 별도로 확대하면 본문 설명을 이해하는 데 도움이 된다. 정상 상태뿐 아니라 ON/OFF 색상 차이가 함께 보이도록 캡처해야 한다.
