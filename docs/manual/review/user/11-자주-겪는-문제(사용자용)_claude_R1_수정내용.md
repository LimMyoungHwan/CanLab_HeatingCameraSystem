# 11-자주-겪는-문제(사용자용) — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 표 항목은 대체로 정확하고 다른 챕터 용어와 일치하나, 두 항목에서 "운영자 문의" 원칙이 깨져 있어 통일 필요.

## 수정 필요 항목
1. [행: "레시피가 '챔버 안정화'에서 멈춤"] 문제: 다른 모든 행은 사용자 조치 불가 시 "운영자에게 문의"로 끝나는데, 이 행만 "STOP 후 설비 점검"으로 끝나 일상 운전자가 직접 설비를 점검해야 하는 것처럼 읽힘(타깃 독자 범위 밖). -> 제안: "STOP 후 운영자에게 문의(히터/습도제어 점검 필요)"로 수정.
2. [행: "알람이 계속 뜸"] 문제: 마찬가지로 "원인(설비/연결) 점검"으로 끝나 사용자 직접 점검을 암시함. -> 제안: "재발하면 운영자에게 문의(설비/연결 원인 점검 필요)"로 수정해 다른 행과 톤 통일.
3. [전체 행] 문제: "부저 OFF/에러 리셋"이 02장·08장의 정식 명칭("PLC 부저 OFF", "PLC 에러 리셋")과 다르게 축약되어 있음. -> 제안: "PLC 부저 OFF/PLC 에러 리셋"으로 표기 통일.
