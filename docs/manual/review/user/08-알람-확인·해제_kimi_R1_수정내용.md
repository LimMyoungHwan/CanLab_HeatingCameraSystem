• # 08-알람-확인·해제 — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 상
  - 한 줄 요약: 화면 요소 나열 수준의 개요만 있고, 운전자가 실제로 알람을 "확인·해제"하는 절차·주의사항·언제 리셋해도 되는지에 대한 내용이 없어 일상 운전자 대상 챕터로는 부족함.

  ## 수정 필요 항목
  1. [전체] 문제: 불릿 나열만 있고 "어디에서"(Master 메인 화면의 좌측 알람 패널) 작업하는지, 화면 진입 경로에 대한 설명이 없음 -> 제안: 챕터 도입부에 알람 패널의 위치와 접근 방법(기본 화면에 항상 표시되는지, 별도 탭인지)을 한두 문장으로 명시.
  2. [알람 목록 항목] 문제: "✕로 개별 삭제"만 있고, ✕로 지우면 어떻게 되는지(알람 조건 자체가 해소되는지, 화면 표시만 사라지는지, 이력에는 남는지) 설명이 없음 — 운전자가 알람을 '해제'한 것으로 오해할 수 있음 -> 제안: "✕는 화면 표시에서만 제거되며, 실제 알람 원인이 해소되지 않으면 다시 발생할 수 있음" 같은 구분 설명 추가.
  3. [PLC 에러 리셋] 문제: 에러 원인을 확인하지 않고 리셋할 때의 위험(히터 과열, 위치결정 축 이상 상태에서 재기동 등)에 대한 경고가 없음. 일상 운전자가 가장 실수하기 쉬운 지점 -> 제안: "PLC 에러 리셋 전에 반드시 알람 내용과 설비 상태를 확인하고, 원인이 해소된 경우에만 리셋하라"는 경고 블록(⚠) 추가.
  4. [PLC 부저 OFF] 문제: 부저를 꺼도 경보 자체는 유지되는지(새 알람 발생 시 다시 울리는지, 수동으로 켤 방법은 없는지) 불명 -> 제안: 부저 OFF 동작 범위(현재 울리는 부저만 끄는지, 이후 알람까지 무음인지)를 한 줄로 명시.
  5. [알람 이력 조회] 문제: "이력 조회의 알람 이력 탭"이라고만 되어 있어 해당 화면으로 가는 방법이 안내되지 않음 -> 제안: 이력 조회 화면 진입 경로(메뉴/버튼 위치)와 조회 절차(기간·등급 선택 → 조회)를 2~3단계로 서술.
  6. [구성] 문제: 챕터 제목은 "알람 확인·해제"인데 본문에 소제목 구조가 전혀 없어 '확인'(목록 보기/필터/이력 조회)과 '해제'(✕ 삭제/부저 OFF/에러 리셋) 흐름이 섞여 있음 -> 제안: `8.1 알람 확인`, `8.2 알람 해제(개별 삭제·부저 OFF·PLC 에러 리셋)`, `8.3 지난 알람 조회` 식으로 소제목을 나누어 절차형으로 재구성.

  ## 누락/추가 제안
  - 알람 등급(정보/경고/오류)별 의미와 각 등급에서 운전자가 취해야 할 조치(예: 오류 등급은 설비 담당자에게 보고 등)에 대한 최소한의 안내 테이블 추가 권장.
  - [그림 21]에 "원점 복귀 버튼"이 캡처 대상에 포함되어 있는데 본문에 원점 복귀 설명이 전혀 없음 — 본문에 한 줄 추가하거나, 다른 챕터(축 제어/시작하기)에서 다룬다면 캡처 대상 설명에서 제외하는 것이 일관성에 맞음.
  - 반복적으로 같은 알람이 발생할 때의 대처(무시하지 말고 이력으로 빈도 확인 후 보고) 같은 운용 팁 한두 줄.

  ## 이미지 자리 검토
  - [그림 21] 적절 — 알람 목록과 공용 버튼 위치를 보여주는 것은 이 챕터의 핵심 안내에 정확히 대응함. 다만 캡처 대상에 본문에서 설명하지 않는 "원점 복귀" 버튼이 포함되어 있어, 본문 보강 또는 캡처 설명 수정이 필요함. 알람이 실제 표시된 상태로 캡처한다는 조건은 타당함.

  ## (선택) 수정 제안 전문
  (생략 — 챕터 전체 재구성이 필요한 수준이나, 실제 화면·기능 근거가 없는 부분(부저 동작 범위, ✕ 삭제 의미, 원점 복귀 설명)을 지어내지 않기 위해 수정 전문 대신 위 제안으로 대체함)
