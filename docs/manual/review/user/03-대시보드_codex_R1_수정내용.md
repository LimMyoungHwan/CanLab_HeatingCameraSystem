# 03-대시보드 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 핵심 요약: 화면 영역과 주요 기능은 간결하게 정리되어 있으나, `POINT`, `AGENTS`, `Mode 1~5` 등 일부 표시명의 의미가 불명확하다. 시스템 시작·중단 절차에는 실행 전 확인사항과 `STOP` 동작 범위를 보완해야 한다.

## 수정 필요 항목
1. [3장 도입부] 문제: “좌측 텔레메트리 카드, 가운데 카메라 영상, 우측 카메라 시스템 패널”이라고 설명하지만 3.4의 명칭은 “시스템 실행 패널”이다. -> 제안: 화면 명칭을 “우측 시스템 실행 패널”로 통일한다.
2. [3.1 상단 상태 요약] 문제: `AGENTS`가 온라인 Agent 수인지 전체 등록 Agent 수인지 불분명하다. -> 제안: “현재 온라인 상태인 카메라 Agent 수”처럼 집계 기준을 명시한다.
3. [3.1 상단 상태 요약] 문제: `POINT`의 설명만으로 번호가 무엇을 의미하는지 알기 어렵다. -> 제안: 실제 화면에서 나타내는 대상이 레시피 단계, 촬영 위치 또는 설비 포인트 중 무엇인지 확인하여 정확히 설명한다.
4. [3.1 상단 상태 요약] 문제: PLC 연결 표시등의 색상과 메시지별 의미가 없다. -> 제안: 실제 화면을 기준으로 정상·연결 끊김 상태의 표시와, 연결 끊김 시 시스템 실행 가능 여부를 추가한다.
5. [3.1 상단 상태 요약] 문제: 비상정지 배너가 표시될 때 운전자가 무엇을 해야 하는지 안내하지 않는다. -> 제안: “배너 표시 중에는 시스템을 시작하지 말고 비상정지 원인을 확인한다”는 경고와 해제 후 확인 절차를 추가한다.
6. [3.2 텔레메트리 카드] 문제: `BLACKBODY`, `MOTION`, `PROGRAM`, `EQUIPMENT`에 영문·한글·약어가 혼재하며 `PV`, `SV`, `BUSY`의 뜻이 설명되지 않는다. -> 제안: 최초 등장 시 각각 현재값(PV), 설정값(SV), 동작 중(BUSY)으로 풀이한다.
7. [3.2 텔레메트리 카드] 문제: `PROGRAM` 카드의 속도 항목이 어떤 장치 또는 동작의 속도인지 불명확하다. -> 제안: 화면의 실제 필드명과 단위를 그대로 적고 대상 장치를 명시한다.
8. [3.2 텔레메트리 카드] 문제: `EQUIPMENT` 카드가 장비 이름만 나열하고 정상·동작·정지·이상 상태를 어떻게 구분하는지 설명하지 않는다. -> 제안: 실제 표시 방식에 따라 색상 또는 상태 문구의 의미를 추가한다.
9. [3.3 카메라 영상] 문제: `Mode 1(Auto 8)`, `Mode 2(8)`, `Mode 3(4)`, `Mode 4(2)`, `Mode 5(1)`의 숫자가 화면 분할 수인지 카메라 수인지 명확하지 않다. -> 제안: 각 모드의 자동 전환 여부와 동시에 표시되는 영상 수를 표로 정리한다.
10. [3.3 카메라 영상] 문제: “Mode 2~5에서는 좌측 카메라 목록의 영상 칸으로 끌어다 놓아 배치” 문장은 드래그 시작 위치와 놓을 위치가 모호하다. -> 제안: “좌측 카메라 목록에서 원하는 카메라를 선택해 가운데 영상 칸으로 끌어다 놓는다”처럼 조작 순서를 명확히 적는다.
11. [3.3 카메라 영상] 문제: “더블클릭 확대” 이후 원래 화면으로 돌아오는 방법이 없다. -> 제안: 실제 복귀 조작을 확인하여 함께 설명한다.
12. [3.3 카메라 영상] 문제: `No Signal` 발생 시 단순 상태 표시인지 운전자 조치가 필요한 오류인지 알 수 없다. -> 제안: Agent 온라인 상태와 함께 확인하도록 안내하고, 계속 발생할 때의 보고 또는 점검 기준을 추가한다.
13. [3.4 시스템 실행 패널] 문제: 실행 절차가 레시피 선택부터 시작되어 PLC 연결, Agent 상태, 비상정지 및 알람 여부 등 실행 전 확인사항이 빠져 있다. -> 제안: `START` 전에 상단 HUD와 필요한 카메라 영상을 확인하도록 첫 단계를 추가한다.
14. [3.4 시스템 실행 패널] 문제: 레시피 목록이 비어 있을 때 새로고침 이후에도 표시되지 않는 경우의 대응이 없다. -> 제안: 재시도 범위와 운전자가 확인하거나 보고할 항목을 명시한다.
15. [3.4 시스템 실행 패널] 문제: `STOP`의 “현재 단계 처리 후 안전 정지”가 즉시 정지인지 단계 완료 후 정지인지 불명확하며 비상정지와 혼동될 수 있다. -> 제안: 실제 정지 시점과 완료 확인 표시를 명확히 쓰고, 긴급 상황에서는 `STOP`이 비상정지를 대신하지 않는다는 경고를 추가한다.

## 누락/추가 제안
- 상단 HUD에서 이상 상태를 발견했을 때 어느 카드 또는 화면을 추가로 확인해야 하는지 짧은 운전자 확인 순서를 추가한다.
- 온도·습도·위치·속도 값의 단위를 실제 화면 필드별로 통일하여 표기한다.
- 시스템 실행 중 레시피 변경 가능 여부와 `START`·`STOP` 버튼의 활성화 조건을 실제 화면 동작에 맞게 설명한다.
- 진행률 100% 도달 후 완료 여부를 확인하는 표시 또는 문구를 추가한다.

## 이미지 자리 검토
- [그림 4] 적절 — 장 전체의 좌·중·우 영역 구성을 한눈에 설명하는 데 필요하다. HUD, 텔레메트리, 카메라 영상, 시스템 실행 패널의 경계를 식별할 수 있도록 표시하면 더 유용하다.
- [그림 5] 적절 — Mode 버튼, 컬러맵 선택, 카메라 목록과 영상 칸의 관계를 보여 주기에 적합하다. 드래그 시작 위치와 놓을 위치가 모두 보이도록 캡처해야 한다.
- [그림 6] 적절 — 레시피 선택부터 시작·중단 및 진행 확인까지의 조작 요소를 설명하는 데 필요하다. 실행 중 화면을 사용하되 선택된 레시피명, 진행률, 단계 문구와 `STOP` 버튼이 선명하게 보여야 한다.
