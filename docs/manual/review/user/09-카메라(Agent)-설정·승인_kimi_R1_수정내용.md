  # 09-카메라(Agent)-설정·승인 — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 하
  - 한 줄 요약: 화면 구조·필드명이 실제 UI(`AgentSettingsView`, `DevicesView`)와 정확히 일치하고 분량도 대상 독자(일상 운전자)에게 적절하나, 탭1의 '시뮬레이션 모드' 체크박스 누락 등 소규모 보완점이 있음.

  ## 수정 필요 항목
  1. [탭1 설명] 문제: 실제 탭1 폼 최상단에는 **'시뮬레이션 모드' 체크박스**(`Agent_SimMode`)가 있는데 본문 필드 나열(NATS/저장경로/하트비트/캡처 포맷·장수/카메라 목록)에 없음. 운전자가 화면에서 보이는데 매뉴얼에 없으면 오조작 위험이 있음. -> 제안: 필드 목록에 한 줄 추가하거나, "시뮬레이션 모드는 개발·시험용이니 운전자는 변경하지 않는다"는 주의 문구 추가.
  2. [탭1 설명] 문제: "온라인 Agent 선택→조회" 절차만 있고, **드롭다운에 Agent가 표시되지 않는 경우**(오프라인) 어떻게 해야 하는지 안내가 없음. 일상 운전자가 가장 먼저 마주칠 상황임. -> 제안: "목록에 Agent가 없으면 해당 카메라 PC의 Agent 프로그램 실행 상태와 NATS 연결을 확인" 한 줄 추가.
  3. [본문 하단] 문제: '설정 전송' 버튼의 **적용 시점**(즉시 반영인지, Agent 재시작이 필요한지)에 대한 안내가 없어, 운전자가 촬영 중 변경해도 되는지 판단할 수 없음. -> 제안: 실제 동작을 확인한 뒤 "설정 전송은 촬영 중이 아닐 때 수행" 등의 주의 문구 추가 여부 검토.

  ## 누락/추가 제안
  - 탭1 카메라 목록 아래의 '카메라 추가' 버튼(`Common_AddCamera`)도 실제 화면에 존재함. 운전자 대상 본장에서는 생략해도 무방하나, [그림 22] 캡처 시 목록 아래 버튼까지 포함되므로 캡처 지침상 범위만 명확히 하면 충분함.
  - '디바이스 관리' 탭에서 승인 처리 후 결과 확인 방법(목록의 '승인' 열이 변경되는지) 한 줄이 있으면 절차가 완결됨.

  ## 이미지 자리 검토
  - [그림 22] 적절 — 탭1 전체(온라인 Agent 선택 + 설정 폼 + 카메라 목록) 구성이 명확하고, "Agent 1대를 조회해 값이 채워진 상태"라는 캡처 조건도 구체적임. 단, 실제 캡처 시 시뮬레이션 모드 체크박스도 함께 보이므로 위 수정 항목 1과 함께 반영 필요.
  - [그림 23] 적절 — 탭2(발견 카메라 목록 + 승인/거부/이름저장/시리얼 설정) 구성이 실제 화면과 일치함. "카메라 1대 이상 표시된 상태"가 다소 느슨하니, 미승인 카메라가 선택된 상태로 캡처하면 오른쪽 작업 패널의 버튼들이 함께 보여 더 유용함(선택 사항).
