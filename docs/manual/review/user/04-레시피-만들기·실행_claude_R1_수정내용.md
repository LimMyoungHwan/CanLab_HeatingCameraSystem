# 04-레시피-만들기·실행 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 전체 흐름과 화면 구성 설명은 명확하나, 실행 단계(4.5)가 "스텝마다 반복"되는지 불명확하고 일상 운전자에게 필요한 중단/일시정지·결과 이미지 확인 경로가 빠져 있다.

## 수정 필요 항목
1. [4.5 레시피 실행과 진행 단계 표] 문제: 표의 5단계(챔버 안정화→서보 이동→BB 안정화→캡처→완료)가 전체 레시피에 대해 한 번만 도는 것인지, 스텝마다 반복되는 것인지 명시가 없음. 4.2에서 스텝마다 챔버 ℃/%RH·흑체온도·좌표를 각각 지정한다고 했으므로 스텝별로 반복되는 구조로 보이나 표만 보면 "챔버 안정화"가 맨 처음 1회만 일어나는 것으로 오해 가능. -> 제안: 표 위에 "아래 4단계(챔버 안정화~캡처)를 스텝 순서대로 반복하며, 스텝마다 해당 스텝에 지정된 좌표·흑체온도·챔버값으로 진행한다"는 문장 추가.
2. [4.5] 문제: 실행 중 중단/일시정지 방법이 없음. 운전자가 실수로 START를 누르거나 급히 멈춰야 할 때 대응 방법이 매뉴얼에 없음. -> 제안: STOP(또는 PAUSE) 버튼 위치와 동작(현재 스텝까지만 진행 후 정지 / 즉시 정지 등) 한 줄 추가.
3. [4.5] 문제: 캡처된 이미지를 운전자가 어디서 확인하는지(저장 경로, 대시보드 내 미리보기 등) 언급이 없어 "일상 운전자가 촬영 결과를 확인"하는 목적에 비해 완결성이 부족. -> 제안: 결과 이미지 확인 방법을 1줄 추가하거나 해당 내용이 있는 다른 챕터로 상호참조.
4. [4.2 5번] 문제: 스텝 삭제(X)는 있으나 레시피 자체 삭제/이름변경 방법이 이 챕터에 없음. -> 제안: 레시피 삭제·이름변경이 가능한지, 가능하면 방법을, 불가능하면(즉 새로 만들기/EXPORT-IMPORT로만 관리) 그 사실을 명시.

## 누락/추가 제안
- 4.2 참고문 아래 또는 4.5 표 앞에 "허용오차(BB 안정화 판정 기준)"를 운전자가 어디서 보거나 바꿀 수 있는지(설정값인지 고정값인지) 한 줄 필요.
- 4.5 참고문에 캡처 제한시간(기본 30초)은 "설정 가능"이라 했는데 어디서 설정하는지 언급 없음. 이 챕터 범위 밖이면 상호참조 표기 권장.

## 이미지 자리 검토
- [그림 7] 적절 — 편집기 3분할 전체 구조를 한눈에 보여주는 자리로 타당.
- [그림 8] 적절 — 스텝 2개 이상 입력 상태 지정은 좋으나, 이왕이면 흑체온도/좌표/카메라 필드에 실제 값이 채워진 예시로 캡처하도록 캡션에 추가하면 더 명확.
- [그림 9] 적절 — 다만 "카메라 영상이 나오는 상태"만으로는 SHUTTER 열림/닫힘 여부가 화면에 반영되는지 알 수 없음. 셔터 열린 상태로 캡처하도록 조건 명시 권장.
