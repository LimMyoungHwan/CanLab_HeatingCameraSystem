- agy의 “녹색=ON/동작, 회색=OFF/대기, 빨간색=오류”를 모든 표시등의 공통 범례로 적용하면 틀린다. 일반 상태·입출력 램프는 녹색/회색만 사용하고, 빨간색은 PLC 오류 활성 및 PLC 연결 끊김 표시에 사용한다.
- agy의 “서보 이동 목표 포인트” 표현은 현재 코드와 맞지 않는다. 화면 바인딩과 모델 속성은 `CurrentPoint`, 화면 문구도 “현재 포인트”이다.
- agy가 제안한 PV/SV 약어는 현재 화면에 표시되지 않는다. UI 문구는 “현재/목표”이며, 내부 모델 속성에서만 PV/SV 명칭을 사용한다.
