# 07-이력-조회 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 기본 조회·내보내기 흐름은 명확하나, CSV 내보내기 적용 범위·조회 결과 없음 상태·필터 값 설명이 빠져 있어 보완 필요.

## 수정 필요 항목
1. [7.1 촬영 이력] 문제: 'CSV 내보내기'가 촬영 이력에만 있는 기능인지, 7.2의 챔버/알람 이력에도 각각 있는지 불명확 -> 제안: 각 절(7.1/7.2)에 CSV 내보내기 유무를 명시하거나, 공통 기능이면 7절 서두에 한 번 기술.
2. [7.1 촬영 이력] 문제: '카메라 필터'가 드롭다운인지 텍스트 입력인지, 선택 가능한 값(예: 전체/개별 카메라 ID) 설명 없음 -> 제안: 필터 입력 방식과 예시 값 한 줄 추가.
3. [7.1~7.2 공통] 문제: 조회 결과가 없을 때(빈 표) 어떤 안내가 뜨는지 언급 없음 -> 제안: "조회 결과가 없으면 표가 비어 있음" 등 한 줄 추가하거나 없으면 '없음' 명시.
4. [7.2 챔버 이력 / 알람 이력] 문제: 두 개의 서로 다른 탭(챔버/알람)을 하나의 소제목으로 묶어 목록 항목처럼 서술 — 7.1과 구성 형식이 달라 일관성 저하 -> 제안: 7.2 챔버 이력 / 7.3 알람 이력으로 분리하고 기존 7.3 이미지 상세 보기는 7.4로 조정, 또는 현재처럼 유지할 경우 각 하위 항목에 소제목(예: **챔버 이력**, **알람 이력**) 부여.
5. [7.3 이미지 상세 보기] 문제: 상세 창을 닫는 방법(예: X 버튼/ESC) 언급 없음 -> 제안: "닫기 버튼(X) 또는 배경 클릭으로 닫는다" 등 한 줄 추가.

## 누락/추가 제안
- 날짜 필터 기본값(예: 오늘 날짜, 최근 N일)이 무엇인지 명시하면 실사용자에게 도움됨.
- 조회 가능한 최대 기간/건수 제한이 있는지 여부 (성능·응답 지연 관련 안내로 유용).
- CSV 내보내기 저장 위치/파일명 규칙 안내 없음 — 다른 챕터에 이미 공통 설명이 있다면 "없음" 처리 가능.

## 이미지 자리 검토
- [그림 17] 적절 — 필터+표+썸네일이 함께 보이는 상태 캡처로 촬영 이력 절 이해에 충분.
- [그림 18] 적절 — 챔버 이력 표 구성 확인에 적합.
- [그림 19] 적절 — 알람 수준 필터 포함 캡처로 7.2 알람 이력 설명과 부합.
- [그림 20] 적절 — 상세 모달의 구성요소(확대 이미지/스케일바/메타정보)를 한 번에 보여줌. 단, 닫기 버튼 위치도 캡처에 드러나면 위 항목 5 보완에 도움.
