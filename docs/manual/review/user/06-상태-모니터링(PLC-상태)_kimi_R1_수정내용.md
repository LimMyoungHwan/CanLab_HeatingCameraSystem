• # 06-상태-모니터링(PLC-상태) — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 중
  - 한 줄 요약: 화면 구성 요소 나열은 실제 구현과 정확히 일치하나, 화면 진입 경로·각 항목의 의미·알람 발생 시 대응 지침이 없어 일상 운전자가 "보고 무엇을 해야 하는지" 알기 어려운 수준의 개요만 담고 있음.

  ## 수정 필요 항목
  1. [본문 전체] 문제: 화면에 어떻게 진입하는지(메뉴/탭 위치) 설명이 전혀 없어 일상 운전자가 이 화면을 찾기 어려움. -> 제안: 도입부에 "Master 좌측/상단 ○○ 메뉴에서 'PLC 상태' 화면 선택" 등 진입 경로 1문장 추가.
  2. [상단 요약 설명] 문제: "PLC 연결"이 무엇으로 표시되는지(녹색=정상/적색=끊김 램프) 설명 없음. 실제 UI는 램프 색상으로만 연결 상태를 표현함. -> 제안: "녹색 램프=정상 연결, 적색 램프=통신 끊김. 적색이면 아래 모든 값이 갱신되지 않으므로 통신 상태를 먼저 확인" 문구 추가.
  3. [챔버 환경 카드] 문제: "팬 속도 (Hz)", "GAS 유속" 등 세부 항목이 본문 나열에서 빠져 있고, GAS 유속의 단위가 본문에도 UI에도 표기되지 않아 운전자가 값의 의미를 해석하기 어려움. -> 제안: 카드별 표시 항목을 간단한 목록으로 추가하고, 최소한 GAS 유속의 단위(예: LPM 등 실제 단위)와 통상 범위를 명기.
  4. [서보/직교로봇 카드] 문제: X/Y 에러코드, X/Y BUSY, X/Y 원점 램프가 존재하나 본문에서 누락됨. 에러코드가 0이 아닐 때 어떻게 해야 하는지 안내 없음. -> 제안: "에러코드가 0이 아니거나 BUSY가 계속 켜져 있으면 동작 중/이상 상태이므로 운영 담당자에게 보고" 수준의 해석 지침 추가.
  5. [PLC 알람 카드] 문제: "활성 오류는 빨간색으로 표시"라고만 하고, 알람이 켜졌을 때의 대응 절차가 없음. -> 제안: "빨간색 알람이 하나라도 활성이면 촬영을 중단하고 ○○(장비 담당/유지보수)에 보고" 같은 대응 절차 1~2문장 추가. 알람 항목별 의미 목록(또는 별도 부록 참조)도 권장.
  6. [장비 상태 표시등] 문제: 히터·1차/2차/상온 냉동기·바이패스·도어램프·페어글라스·MCF·블로워1/2 등 실제 램프 목록이 본문에 없고, 램프 ON/OFF가 무엇을 의미하는지(녹색=동작 중) 설명 없음. -> 제안: "녹색=해당 장비 동작 중, 회색=정지" 설명과 램프 항목 목록 추가.
  7. [도입 문장] 문제: "값을 바꾸지는 않는다"는 핵심 안내(읽기 전용)는 있으나, 값이 갱신되지 않을 때의 조치가 없음. -> 제안: "숫자가 1초 이상 변하지 않으면 PLC 통신 이상일 수 있으니 상단 연결 램프를 확인" 문구 추가.

  ## 누락/추가 제안
  - "비정상 시 조치" 소절 추가 제안: ① PLC 연결 적색 → 통신 확인, ② 알람 빨간 램프 → 촬영 중단 및 보고, ③ 서보 에러코드 ≠ 0 → 담당자 보고 식의 3줄 체크리스트. 일상 운전자 대상 챕터이므로 이 한 절이 실질 가치를 만듦.
  - 진행 상태(스텝/진행바)가 "자동 촬영 진행 시"에만 의미가 있다는 안내(대기 중에는 0/0 표시 등) 추가 권장.
  - 온도·습도 현재/목표 값 단위(℃, %RH)가 본문 나열에 빠져 있으므로 명시 권장.

  ## 이미지 자리 검토
  - [그림 15] 적절 — 화면 전체(요약 바+카드) 캡처는 본문 구성 나열과 정확히 대응되며, "PLC 연결된 상태(값이 표시됨)" 조건 지정도 타당함.
  - [그림 16] 적절 — 하단 입력/출력/장비 램프 영역을 별도 확대 캡처하는 것은 램프 식별에 유용함. 다만 캡처 시 일부 램프가 ON(녹색)인 실제 운전 상태로 찍는 것이 램프 의미 설명에 더 도움이 되므로 "화면/상태: 정상 표시 상태"를 "일부 장비 동작 중인 상태"로 보완 권장.
  - (추가 제안) [그림 17] PLC 알람 카드에 활성 알람이 있는 상태 캡처 — 본문이 "빨간색으로 표시"를 설명하는 유일한 수단이 글이므로, 실제 빨간 램프 예시 그림이 있으면 운전자 인식에 직접 도움이 됨.
