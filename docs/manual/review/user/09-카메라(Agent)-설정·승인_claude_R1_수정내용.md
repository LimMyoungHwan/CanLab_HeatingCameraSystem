# 09-카메라(Agent)-설정·승인 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 탭 구성 설명은 명확하나, 실제 조작 절차(버튼/순서)가 없고 그림 캡처 대상과 본문 내용이 일부 어긋난다.

## 수정 필요 항목
1. [탭1 설명] 문제: "온라인 Agent 선택→조회 후 ... 전송"만 서술되어 실제 화면상 버튼명·조작 순서(예: 목록에서 선택 → [조회] 클릭 → 값 확인/수정 → [전송] 클릭)가 없어 운전자가 그대로 따라 하기 어렵다. -> 제안: 번호 매긴 절차(1. 온라인 Agent 목록에서 대상 선택 2. [조회] 클릭해 현재 설정값 로드 3. 필요한 필드 수정 4. [전송] 클릭)로 구체화.
2. [탭1 설명] 문제: "하트비트"라는 용어가 설명 없이 사용되어 일상 운전자에게 생소함. -> 제안: 괄호로 "(Agent 생존 확인 주기)" 등 짧은 설명 추가.
3. [그림 23 캡처 대상] 문제: 본문 탭2 설명에는 "로그 가져오기"가 포함되어 있으나 그림23 캡처 대상 항목에는 빠져 있어 본문-이미지 설명이 불일치. -> 제안: 그림23 캡처 대상에 "로그 가져오기" 항목 추가하거나, 별도 그림으로 분리.
4. [전체] 문제: 설정 전송/승인 실패 시 대응(예: 전송 실패, Agent 응답 없음) 안내가 없음. -> 제안: 간단한 "전송이 안 되면 Agent PC 네트워크·NATS 연결 확인" 수준의 참고 문구 추가.

## 누락/추가 제안
- 탭1에서 "카메라 목록" 항목이 구체적으로 무엇을 설정하는지(추가/삭제/순서 등) 한 줄 설명 필요.
- 탭2 "이름 저장"이 어떤 값(카메라 별칭 등)을 저장하는지 짧게 명시하면 좋음.

## 이미지 자리 검토
- [그림 22] 적절 — 탭1 화면 전체와 값이 채워진 상태를 보여줘 이해에 도움.
- [그림 23] 부적절(부분) — 캡처 대상 항목이 본문의 "로그 가져오기" 기능을 누락해 캡처 범위 재확인 필요.
