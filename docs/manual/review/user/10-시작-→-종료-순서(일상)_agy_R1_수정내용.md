## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 일상 운용의 전체 흐름(시작부터 종료까지)은 잘 간추려져 있으나, 매뉴얼 표준인 visual guide(📷 그림 자리)가 전혀 반영되어 있지 않고, Agent 프로그램 실행 상태 확인 및 레시피 가동 중 종료 방지 등 일상 운전자에게 필수적인 안전 주의사항과 상세 가이드 보완이 필요합니다.

## 수정 필요 항목
1. [전체 / 이미지 누락] 문제: 챕터 본문에 이미지 자리(📷 [그림 N]) 블록이 단 하나도 작성되어 있지 않아, 운전자가 실제 UI 화면의 어떤 위치를 확인해야 하는지 직관적으로 파악하기 어려움. -> 제안: 대시보드 상태, Agent 연결 등 핵심 단계별로 📷 [그림 N] 블록 4개를 지정 배치함.
2. [3단계 / Agent 기동] 문제: "카메라(Agent) PC 기동"으로만 표현되어 있어 단순 전원 온(On)으로 오해할 수 있음. -> 제안: Agent PC 전원 온 및 Agent 응용프로그램(Agent.exe/AgentUI) 실행 상태 확인과 대시보드 하트비트(5초 주기 초록색 점) 연결 확인으로 구체화.
3. [4단계 / Agent 설정] " (필요 시) Agent 설정에서 시리얼/카메라 설정 전송": 일상 운전 절차에 매일 수행하는 기본 순서처럼 보일 수 있어 운전자에게 혼선을 줌. -> 제안: 매일 수행하는 기본 순서가 아닌 '특이사항 발생 시 또는 설정 변경 시(선택)' 항목으로 역할을 명확히 분류.
4. [8단계 / 종료 순서] 문제: 레시피 동작 중에 Master 창을 무심코 닫거나 카메라 PC를 먼저 종료할 경우 발생할 수 있는 데이터 손실 및 공정 이상 위험 경고가 누락됨. -> 제안: 레시피 완료/중단 상태 확인 후 안전하게 종료하는 순서를 명시하고 경고(WARNING) 문구 추가.

## 누락/추가 제안
- **운전 전 사전 점검**: Master 및 Agent 기동 후 PLC 통신 상태 및 비상정지(E-Stop) 해제 여부를 확인하는 사전 안전점검 단계 추가.
- **이상 발생 시 대처**: 모니터링 중 이상 시 STOP 버튼 또는 비상정지 절차에 대한 짧은 안내 참조 추가.

## (선택) 수정 제안 전문

# 10. 시작 → 종료 순서(일상)

일상 운전자가 매일 열화상 카메라 시스템을 안전하고 정확하게 운용하기 위한 전체 시작, 레시피 가동, 모니터링 및 종료 절차입니다.

---

### 10.1 운전 전 준비 및 시스템 기동

1. **NATS 서버 상태 확인**
   - NATS 메시지 브로커 서버가 정상 가동 중인지 확인합니다. (보통 상시 가동 상태 유지)

2. **Master PC 및 Master 프로그램 실행**
   - Master PC에서 `HeatingCameraSystem.Master.exe`를 실행합니다.
   - 프로그램이 실행되면 자동으로 NATS 브로커 및 PLC와 연결을 시도합니다. (통신 초기화 실패 시에도 대시보드 화면은 진입 가능합니다.)
   - 상단 상태 표시줄에서 NATS 및 PLC 연결 상태 아이콘이 정상(초록색)인지 확인합니다.

   📷 [그림 10-1: Master 메인 대시보드 및 통신 상태(NATS/PLC) 표시 영역]

3. **카메라(Agent) PC 기동 및 연결 확인**
   - 각 챔버별 카메라 Agent PC의 전원을 켜고 Agent 프로그램(`AgentUI.exe`)을 실행합니다.
   - Master 대시보드의 카메라 상태 영역에서 각 Agent의 초록색 점(하트비트 신호, 5초 주기)이 정상적으로 켜지는지 확인합니다.

   📷 [그림 10-2: Agent 연결 상태(초록색 하트비트 점) 및 레시피 선택/START 영역]

4. **(선택) Agent 설정 전송**
   - 카메라 교체, 시리얼 셔터 통신 재설정 등 특이사항이 있는 경우에만 'Agent 설정' 메뉴에서 해당 Agent로 시리얼/카메라 설정값을 전송합니다. (일반적인 일상 가동 시에는 생략 가능)

---

### 10.2 레시피 가동 및 모니터링

5. **레시피 선택 및 자동 운전 개시 (START)**
   - 대시보드의 레시피 선택 드롭다운에서 작업할 챔버 레시피를 선택합니다.
   - `START` 버튼을 클릭하여 자동 가동 및 열화상 자동 캡처 공정을 시작합니다.

6. **진행 상태 및 알람 모니터링**
   - 화면 중앙의 레시피 진행 상태바(Progress bar)와 단계별 남아있는 시간을 확인합니다.
   - PLC 온도 램프 상태 및 알람 발생 여부를 실시간으로 모니터링합니다.

   📷 [그림 10-3: 레시피 실행 중 진행바 및 온도 모니터링/알람 상태 화면]

7. **완료 및 이력 조회 (결과 확인)**
   - 레시피 공정이 완료되면 안내 메시지가 표시됩니다.
   - '이력 조회' 메뉴로 이동하여 방금 완료된 공정의 열화상 캡처 이미지 및 저장 결과를 최종 확인합니다.

   📷 [그림 10-4: 완료 후 이력 조회 메뉴 및 캡처 결과 데이터 확인 화면]

---

### 10.3 안전 종료 순서

8. **시스템 종료**
   > [!WARNING]
   > 레시피가 가동 중일 때는 절대로 Master 프로그램이나 Agent PC를 종료하지 마십시오. 반드시 레시피 완료 또는 STOP 확인 후 종료해야 합니다.

   - 레시피 가동이 완료되었거나 중단(STOP) 상태임을 확인합니다.
   - Agent PC의 Agent 프로그램을 종료한 후 PC 전원을 끕니다.
   - Master 프로그램 우측 상단의 닫기(X) 버튼을 눌러 안전하게 Master 프로그램을 종료합니다.
