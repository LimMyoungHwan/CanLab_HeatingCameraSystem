# 07-이력-조회 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 높음
- 한줄 요약: 화면 구성과 조회 항목은 소개되어 있으나, 실제 운전자가 따라 할 수 있는 조회·CSV 저장 절차와 필터 조건, 결과 없음·오류 상황에 대한 설명이 부족하다.

## 수정 필요 항목
1. [7장 도입부] 문제: ‘보기’ 탭으로 세 이력을 전환한다고만 되어 있어 탭의 정확한 위치와 조작 순서를 알기 어렵다. → 제안: “화면 상단의 ‘보기’에서 원하는 이력 탭을 선택한다”처럼 위치와 동작을 명확히 설명한다.
2. [7.1 촬영 이력] 문제: 필터 항목만 나열되어 있고 실제 조회 순서가 없다. → 제안: `촬영 이력 선택 → 시작/종료 날짜 지정 → 카메라 선택 → 조회 클릭 → 결과 확인` 순서로 절차를 작성한다.
3. [7.1 촬영 이력] 문제: 시작일과 종료일에 해당 날짜 전체가 포함되는지, 시작일이 종료일보다 늦을 때 어떻게 되는지 설명이 없다. → 제안: 날짜 범위의 포함 기준과 잘못된 기간 입력 시 표시되는 안내를 실제 동작에 맞게 명시한다.
4. [7.1 촬영 이력] 문제: 카메라 필터에서 전체 카메라를 선택할 수 있는지, 필수 선택인지 알 수 없다. → 제안: 기본 선택값과 ‘전체’ 선택 가능 여부를 명시한다.
5. [7.1 촬영 이력] 문제: “표시 결과를 CSV로 저장”이라는 설명만 있어 저장 범위가 현재 화면인지 전체 조회 결과인지 불명확하다. → 제안: 저장 대상, 파일 선택 창 표시 여부, 기본 파일명과 저장 위치를 실제 동작에 맞게 설명한다.
6. [7.1 촬영 이력] 문제: CSV 파일의 열 구성, 문자 인코딩 및 Excel에서 한글이 정상 표시되는지에 대한 정보가 없다. → 제안: 운영자가 후속 분석에 사용할 수 있도록 주요 열과 지원 형식을 명시한다.
7. [7.1 촬영 이력] 문제: 목록의 ‘온도’가 챔버 온도인지 카메라 측정 온도인지 불명확하다. → 제안: 실제 데이터 의미에 맞춰 ‘챔버 온도’ 또는 ‘측정 온도’처럼 구체적인 명칭을 사용한다.
8. [7.1 촬영 이력] 문제: 썸네일이 일반 영상인지 열화상인지, 이미지가 없는 경우 어떻게 표시되는지 설명이 없다. → 제안: 썸네일의 이미지 종류와 미생성·손상 시 표시 상태를 추가한다.
9. [7.2 챔버 이력 / 알람 이력] 문제: 두 이력의 표시 열만 나열되어 있고 조회 필터와 실행 방법이 생략되어 있다. → 제안: 각 탭에서 사용할 수 있는 기간·알람 수준 등의 필터와 ‘조회’ 버튼 사용 절차를 구분해 작성한다.
10. [7.2 챔버 이력] 문제: ‘객체1·객체2’가 무엇을 측정하는 값인지 알 수 없다. 그림 설명에서는 ‘BB1/BB2’로 표기되어 본문과도 일치하지 않는다. → 제안: 실제 화면의 열 이름으로 통일하고, 각 값의 의미와 단위를 설명한다.
11. [7.2 챔버 이력] 문제: 온도와 습도의 단위가 본문에 없다. → 제안: 촬영 이력과 동일하게 `온도(℃)`, `습도(%RH)`로 표기한다.
12. [7.2 알람 이력] 문제: ‘등급·출처·메시지’의 의미와 알람 수준 필터의 선택값이 설명되지 않는다. → 제안: 실제 화면에 표시되는 수준 목록과 출처의 예시를 추가하되, 구현에 없는 값은 기재하지 않는다.
13. [7.2 알람 이력] 문제: 알람 이력이 단순 기록인지, 확인·해제 등의 조작이 가능한 화면인지 구분되지 않는다. → 제안: 조회 전용 여부를 명시하여 운전자가 이 화면에서 알람을 처리할 수 있다고 오해하지 않게 한다.
14. [7.3 이미지 상세 보기] 문제: ‘보기’를 누른 뒤 표시되는 이미지 종류와 조작 기능의 문장이 깨져 읽기 어렵고, 확대·축소 가능 여부도 명확하지 않다. → 제안: 실제 제공 기능을 확인한 뒤 “일반 이미지와 열화상 이미지 표시”, “확대·축소 지원”처럼 기능별로 분리해 작성한다.
15. [7.3 이미지 상세 보기] 문제: 상세 창을 닫고 목록으로 돌아가는 방법이 없다. → 제안: 닫기 버튼 또는 창 우측 상단의 닫기 조작을 실제 화면에 맞게 안내한다.
16. [전체] 문제: 조회 결과가 없거나 데이터·이미지 로딩에 실패했을 때의 화면 상태와 대응 방법이 없다. → 제안: 기간과 필터를 다시 확인하는 방법, 반복 실패 시 확인할 항목을 간단히 추가한다.
17. [전체] 문제: 항목 나열 중심이라 일상 운전자가 원하는 기록을 찾는 작업 흐름을 파악하기 어렵다. → 제안: 각 절을 ‘조회 방법 → 결과 항목 → 상세 확인 또는 내보내기 → 예외 상황’ 순서로 통일한다.

## 누락/추가 제안
- 조회 결과가 많을 때 정렬, 스크롤 또는 페이지 이동을 어떻게 하는지 실제 화면에 맞게 설명한다.
- 타임스탬프의 표시 형식과 기준 시각을 명시한다.
- CSV 내보내기 성공·실패 시 표시되는 메시지와 동일 파일명 처리 방식을 추가한다.
- 촬영 이미지와 이력 데이터가 보이지 않을 때 카메라 Agent 연결 상태 및 조회 기간을 확인하도록 안내한다.
- 이력의 보관 기간이나 삭제 정책이 정해져 있다면 관련 장 또는 운영 정책을 참조하도록 연결한다.

## 이미지 자리 검토
- [그림 17] 적절 — 촬영 이력의 필터와 결과 목록을 함께 보여 주는 그림은 유용하다. 다만 캡처 대상의 ‘열’ 대신 실제 열 이름을 모두 적고, 조회 조건이 입력된 상태가 보이도록 한다.
- [그림 18] 적절 — 챔버 데이터의 시간별 변화를 확인하는 화면 설명에 필요하다. 본문의 ‘객체1/객체2’와 그림 설명의 ‘BB1/BB2’를 실제 화면 명칭으로 통일해야 한다.
- [그림 19] 적절 — 알람 수준 필터와 결과 열이 한 화면에 보이도록 캡처하면 유용하다. 캡처 대상 문장의 닫는 괄호가 중복되어 있으므로 수정한다.
- [그림 20] 적절 — 목록의 ‘보기’ 동작 결과를 설명하는 데 필요하다. 일반 이미지·열화상 이미지, 메타정보 및 닫기 조작이 식별되는 상태로 캡처한다.

## (선택) 수정 제안 전문

# 7. 이력 조회

이력 조회 화면에서는 촬영 결과, 챔버 측정 데이터 및 알람 기록을 확인할 수 있습니다. 화면 상단의 ‘보기’에서 ‘촬영 이력’, ‘챔버 이력’ 또는 ‘알람 이력’을 선택합니다.

## 7.1 촬영 이력

1. 화면 상단의 ‘보기’에서 ‘촬영 이력’을 선택합니다.
2. 시작 날짜와 종료 날짜를 지정합니다.
3. 조회할 카메라를 선택합니다.
4. ‘조회’를 누릅니다.
5. 결과 목록에서 타임스탬프, 카메라 ID, 온도(℃), 습도(%RH), 썸네일을 확인합니다.
6. 이미지를 자세히 보려면 해당 행의 ‘보기’를 누릅니다.
7. 조회 결과를 파일로 저장하려면 ‘CSV 내보내기’를 누릅니다.

조회 결과가 없으면 날짜 범위와 카메라 선택을 확인한 뒤 다시 조회합니다.

> **[그림 17] 이력 조회 — 촬영 이력**
> - **캡처 대상:** 날짜 및 카메라 필터, ‘조회’ 버튼, 촬영 이력 결과 목록, ‘CSV 내보내기’ 버튼
> - **화면/상태:** 조회 조건을 입력하고 여러 건의 결과가 표시된 상태
> - **표시 영역:** 창 전체

## 7.2 챔버 이력

1. 화면 상단의 ‘보기’에서 ‘챔버 이력’을 선택합니다.
2. 화면에 제공되는 조회 조건을 지정한 뒤 ‘조회’를 누릅니다.
3. 결과 목록에서 시간, 온도(℃), 습도(%RH) 및 챔버 측정값을 확인합니다.

‘객체1·객체2’ 또는 ‘BB1·BB2’로 표시되는 항목은 실제 화면 명칭으로 통일하고 각 측정값의 의미를 별도로 설명해야 합니다.

> **[그림 18] 이력 조회 — 챔버 이력**
> - **캡처 대상:** 조회 조건, ‘조회’ 버튼, 시간·온도·습도 및 기타 측정값이 표시된 결과 목록
> - **화면/상태:** 여러 건의 조회 결과가 표시된 상태
> - **표시 영역:** 창 전체

## 7.3 알람 이력

1. 화면 상단의 ‘보기’에서 ‘알람 이력’을 선택합니다.
2. 화면에 제공되는 조회 조건과 알람 수준을 선택합니다.
3. ‘조회’를 누릅니다.
4. 결과 목록에서 발생 시간, 등급, 출처 및 메시지를 확인합니다.

이 화면이 조회 전용이라면 알람 확인이나 해제는 할 수 없다는 점을 명시합니다.

> **[그림 19] 이력 조회 — 알람 이력**
> - **캡처 대상:** 조회 조건, 알람 수준 필터, 발생 시간·등급·출처·메시지가 표시된 결과 목록
> - **화면/상태:** 여러 수준의 알람이 조회된 상태
> - **표시 영역:** 창 전체

## 7.4 이미지 상세 보기

촬영 이력 목록에서 ‘보기’를 누르면 선택한 촬영 건의 상세 창이 열립니다. 상세 창에서는 촬영 이미지와 카메라 ID, 타임스탬프, 온도(℃), 습도(%RH) 등의 정보를 확인합니다. 확인을 마치면 상세 창을 닫아 촬영 이력 목록으로 돌아갑니다.

이미지 확대·축소 또는 일반 이미지와 열화상 이미지 전환 기능은 실제 화면에서 지원되는 경우에만 해당 조작 방법을 추가합니다.

> **[그림 20] 이미지 상세 보기**
> - **캡처 대상:** 촬영 이미지, 상세 정보 및 닫기 조작이 표시된 상세 창
> - **화면/상태:** 촬영 이력 한 건을 연 상태
> - **표시 영역:** 화면 중앙의 상세 창
