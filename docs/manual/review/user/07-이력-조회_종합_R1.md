## ?⑹쓽쨌?ㅼ닔 ?섏젙 (肄붾뱶 ?뺤씤??

- [서두] `'보기' 탭`이라는 모호한 표현 -> `이력 조회 화면 상단의 [촬영 이력]·[챔버 이력]·[알람 이력] 버튼`으로 명시한다. (`HistoryView.xaml`, codex·agy)
- [전체] 항목 나열만 있고 조회 흐름이 없음 -> `이력 종류 선택 → 시작일·종료일 지정 → 필요한 필터 선택 → [조회] → 결과 확인` 순서로 통일한다. 세 이력 모두 같은 날짜 필터와 조회 버튼을 사용한다. (codex)
- [날짜 필터] 범위와 기본값이 불명확 -> 조회 조건은 `Timestamp >= 시작값 && Timestamp <= 종료값`이다. 최초 기본값은 오늘 00:00 기준 이틀 전부터 오늘 23:59:59까지이다. 종료일을 DatePicker로 다시 선택하면 해당 날짜 00:00이 되므로 “종료일 하루 전체 포함”이라고 쓰면 안 된다. (codex·claude)
- [날짜 오류] 시작일이 종료일보다 늦을 때 안내가 없음 -> 별도 검증이나 경고 없이 결과가 비게 된다고 명시한다. (codex)
- [카메라 필터] 입력 방식과 선택값이 불명확 -> 드롭다운이며 기본값은 `All Units`; 개별 카메라가 아니라 `Agent-PC-01(CAM-01~16)`, `Agent-PC-02(CAM-17~32)`, `Agent-PC-03(CAM-33~64)` 그룹을 선택한다. (codex·claude)
- [카메라 필터] 모든 이력에 적용되는 것으로 오해 가능 -> 현재 코드는 촬영 이력 조회와 촬영 CSV에만 카메라 그룹을 적용하며 챔버·알람 조회에서는 무시한다. (codex)
- [촬영 결과] 온도의 의미가 불명확 -> 촬영 시 PLC에서 읽은 현재 챔버 온도이며, 습도도 PLC 현재 챔버 습도이다. PLC 읽기 실패 시 두 값은 `0`으로 기록된다. (codex)
- [촬영 결과] 썸네일과 이미지 누락 상태 설명 부족 -> 썸네일과 상세 창은 동일한 `ImagePath`를 표시한다. 경로가 없거나 이미지를 읽지 못해도 전용 안내나 대체 이미지는 없다. (codex)
- [페이징] 조작 설명 누락 -> 모든 이력에 공통으로 페이지당 10건을 표시하며 `«`, `‹`, `›`, `»`로 처음·이전·다음·마지막 페이지를 이동하고 현재/전체 페이지와 레코드 수를 표시한다. (agy·codex)
- [빈 결과] 화면 상태 설명 누락 -> 별도 “결과 없음” 메시지 없이 표가 비며, 레코드 표시는 현재 코드상 `Showing 1-0 of 0 records`가 된다. (codex·claude)
- [CSV] 저장 범위가 불명확 -> 현재 페이지가 아니라 지정 날짜와 카메라 그룹에 맞는 촬영 이력 전체를 저장한다. (codex·agy)
- [CSV] 저장 방식과 형식 설명 누락 -> SaveFileDialog에서 위치를 선택하며 기본 파일명은 `history_yyyyMMdd_HHmmss.csv`이다. UTF-8 BOM 형식이고 열은 `Timestamp, CameraId, Temperature, Humidity, RecipeStepId, ImagePath`이다. 타임스탬프는 ISO 8601, 온도·습도는 소수 둘째 자리까지 기록한다. (codex·claude)
- [CSV] 완료·실패 동작 설명 누락 -> 성공 시 하단 상태 문구가 `Exported N records to 파일명`으로 바뀐다. 별도 성공 창은 없고 쓰기 실패 전용 안내도 없다. (codex)
- [챔버 이력] 촬영 이력과 한 절로 묶여 구조가 불명확 -> `7.2 챔버 이력`, `7.3 알람 이력`, `7.4 이미지 상세 보기`로 분리한다. (claude·codex)
- [챔버 이력] 열 명칭과 단위 불일치 -> 실제 화면 기준 `시간, 온도(°C), 습도(%RH), BB1(°C), BB2(°C)`로 통일한다. BB1·BB2는 기록 시점의 흑체 1·2 현재온도(PV)이다. (codex)
- [알람 이력] 수준 옵션 설명 누락 -> 드롭다운 값은 `전체`, `정보 이상`, `경고 이상`, `오류만`이다. 각각 전체, Info 이상, Warning 이상, Error만 조회한다. (codex·agy)
- [알람 이력] 열과 화면 성격이 불명확 -> `시간, 등급, 출처, 메시지`를 표시하는 조회 전용 목록이며 확인·해제 기능은 없다. (codex)
- [이미지 상세] 표시 내용과 닫기 방법이 불명확 -> 촬영 행의 `[열기]`를 누르면 동일 이미지 한 장, 카메라 ID, 타임스탬프, 온도, 습도 및 고정된 10°~70° 색상 막대가 표시된다. 우측 상단 `✕` 버튼으로 닫는다. (codex·claude)
- [정렬·시각] 표시 기준 누락 -> 세 이력 모두 타임스탬프 내림차순으로 조회하고 화면에는 `yyyy-MM-dd HH:mm:ss`로 표시한다. 다만 UTC/로컬 변환은 수행하지 않는다. (codex)
- [보관 정책] 안내 누락 -> 촬영 이력과 캐시 이미지만 `DataRetentionDays` 설정에 따라 기본 30일 보관 후 하루마다 정리된다. 챔버·알람 이력에는 현재 자동 삭제가 연결되어 있지 않다. (codex)
