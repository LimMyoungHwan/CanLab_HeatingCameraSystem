# 11-자주-겪는-문제(사용자용) — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 주요 증상은 잘 정리되어 있으나, 조치 순서와 문의 대상이 모호하고 알람 리셋 절차는 원인 확인보다 먼저 실행하도록 오해할 수 있다.

## 수정 필요 항목
1. [전체 표] 문제: 확인 사항이 쉼표로 나열되어 점검 순서가 불명확함. -> 제안: 각 셀을 `① 확인 → ② 조치 → ③ 문의` 순서로 작성.
2. [카메라 초록 점이 안 뜸] 문제: “잠시 후”의 기준이 없고, 대상 독자가 일상 운전자인데 “운영자에게 문의”하도록 되어 있음. -> 제안: “카메라 PC와 네트워크 연결을 확인한 뒤에도 회색이면 시스템 담당자에게 문의”처럼 문의 대상을 명확히 표기.
3. [캡처 타임아웃] 문제: “실제 카메라 매칭”의 의미와 확인 방법이 모호함. -> 제안: “레시피 스텝에 지정된 카메라 번호와 대상 카메라 PC의 번호가 일치하는지 확인”으로 구체화.
4. [온도/습도가 0으로 고정] 문제: PLC 연결 표시등이 정상인 경우의 후속 조치가 없음. -> 제안: 표시등이 빨강이면 PLC·네트워크를 점검하고, 정상인데도 값이 0이면 설비 담당자에게 문의하도록 분기.
5. [챔버 안정화에서 멈춤] 문제: 목표 온도만 언급하지만 본문에는 습도 제어 문제도 포함되어 있어 설명이 일관되지 않음. -> 제안: “목표 온도 또는 습도에 도달하지 못함”으로 수정.
6. [셔터/카메라가 반응 없음] 문제: RUN과 셔터 동작 중 무엇을 어떤 순서로 확인해야 하는지 불명확함. -> 제안: 대상 카메라 상태 확인 후 수동 조작에서 RUN, 셔터 순으로 점검하도록 작성.
7. [알람이 계속 뜸] 문제: 오류 필터 적용과 부저 OFF·에러 리셋이 원인 확인보다 앞에 있어, 알람을 숨기거나 원인 확인 없이 초기화하도록 오해할 수 있음. -> 제안: 오류 내용을 먼저 확인·기록하고 원인을 점검한 뒤 리셋하며, 부저 OFF는 소리만 끄는 조치임을 명시.

## 누락/추가 제안
- 문제 해결 전 자동 운전을 계속하지 말아야 하는 증상과 즉시 STOP해야 하는 증상을 구분해 표시할 것을 권장.
- 문의 시 전달할 정보로 발생 시각, 대상 카메라 번호, 알람 내용, 상태 표시등 색을 안내하면 원인 확인에 도움이 됨.
- 표의 용어를 “시스템 담당자”, “설비 담당자” 등으로 통일하고 각 담당 범위를 구분할 것을 권장.

## 이미지 자리 검토
- 그림 없음 — 짧은 문제 해결 표이므로 필수 이미지는 아니지만, 색상 상태를 반복해서 안내하므로 대시보드의 카메라 및 PLC 상태 표시 위치를 보여 주는 그림 1개는 유용함.

## (선택) 수정 제안 전문

# 11. 자주 겪는 문제(사용자용)

문제가 발생하면 아래 순서대로 확인합니다. 자동 운전에 영향을 주는 문제가 계속되면 운전을 중지하고 담당자에게 문의하십시오.

| 증상 | 확인 및 조치 |
| --- | --- |
| 대시보드에 카메라 초록 점이 안 뜸 | ① 카메라 PC가 켜져 있는지 확인합니다. ② 네트워크 연결을 확인합니다. ③ 확인 후에도 회색이면 시스템 담당자에게 문의합니다. |
| 촬영이 제한시간 초과(캡처 타임아웃) | ① 대상 카메라의 상태 표시가 정상인지 확인합니다. ② 레시피 스텝에 지정된 카메라 번호와 실제 대상 카메라 번호가 일치하는지 확인합니다. ③ 문제가 계속되면 시스템 담당자에게 문의합니다. |
| 온도/습도가 0으로 고정 | ① PLC 연결 표시등을 확인합니다. ② 빨강이면 PLC 또는 네트워크 연결을 점검합니다. ③ 연결 표시가 정상인데도 값이 계속 0이면 설비 담당자에게 문의합니다. |
| 레시피가 ‘챔버 안정화’에서 멈춤 | 챔버가 목표 온도 또는 습도에 도달하지 못한 상태입니다. 자동 운전을 STOP한 후 히터와 습도 제어 설비를 점검합니다. |
| 셔터/카메라가 반응 없음 | ① 대상 카메라의 상태 표시를 확인합니다. ② 수동 조작의 카메라 제어에서 RUN과 셔터 동작을 차례로 확인합니다. ③ 반응이 없으면 시스템 담당자에게 문의합니다. |
| 알람이 계속 뜸 | ① 등급 필터에서 오류 내용을 확인하고 발생 시각과 메시지를 기록합니다. ② 표시된 원인을 점검합니다. ③ 원인을 해소한 뒤 에러 리셋을 실행합니다. 부저 OFF는 경고음만 끄며 원인을 해결하지 않습니다. 알람이 다시 발생하면 설비 또는 시스템 담당자에게 문의합니다. |
