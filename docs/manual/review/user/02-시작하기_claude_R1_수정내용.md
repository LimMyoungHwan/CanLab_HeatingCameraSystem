# 02-시작하기 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 하
- 한 줄 요약: 메뉴 구성·상태등 색상·하트비트 임계값(5초/15초) 모두 코드와 일치하며 정확함. 사소한 위치 표현 모호성만 정리하면 됨.

## 수정 필요 항목
1. [2.3 정상 상태 확인] 문제: "좌측 하단(또는 상단) PLC 표시등"처럼 위치를 이중으로 표기해 실제 화면에서 어디를 봐야 하는지 불명확 -> 제안: 실제 화면 기준 정확한 위치 하나로 확정해서 기술 (예: "좌측 메뉴 하단").
2. [2.1] 문제: 실행 아이콘이 안 보이거나 실행 직후 오류 창이 뜨는 경우에 대한 안내가 없음 -> 제안: "아이콘이 없다면 설치 담당자에게 문의" 정도의 1줄 안내 추가 고려(또는 트러블슈팅 챕터로 상호 참조 링크).

## 누락/추가 제안
- 2.3 마지막에 "정상 상태 확인 후 다음 단계"로 이어지는 상호 참조(예: "→ 3장 대시보드" 또는 "→ 10장 시작~종료 순서")가 있으면 흐름이 매끄러움. 없어도 무방.

## 이미지 자리 검토
- [그림 2] 적절 — 최초 실행 전체 화면 캡처 지시가 명확함.
- [그림 3] 적절 — 좌측 메뉴 캡처 범위(알람 1건 이상 포함 권장)까지 구체적으로 지시되어 좋음.
