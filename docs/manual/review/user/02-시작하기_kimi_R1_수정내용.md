• # 02-시작하기 — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 중
  - 한 줄 요약: 메뉴 구성·알람 필터·공용 버튼 명칭은 실제 화면(MainWindow.xaml, ko.txt)과 정확히 일치하나, 2.3의 PLC 표시등 위치와 하트비트 설명이 실제 구현과 어긋나고, 비상정지·공용 버튼의 동작 설명이 없어 일상 운전자가 안전 관련 조작을 배우지 못한 채 넘어간다.

  ## 수정 필요 항목
  1. [2.3 첫 항목] 문제: "좌측 하단(또는 상단) PLC 표시등" — "(또는 상단)"은 작성자가 위치를 확정하지 못한 흔적으로, 매뉴얼에 부적합. 실제로는 좌측 메뉴 패널 하단부(공용 버튼 아래·알람 목록 바로 위)에 있고, 대시보드 상단 상태 칩에도 PLC 연결 점이 별도 존재(MainWindow.xaml:259-272, DashboardView.xaml:196-200). -> 제안: "좌측 메뉴 하단부(알람 목록 바로 위)의 PLC 표시등"으로 단정 기술하고, 대시보드 상단에도 같은 표시가 있다면 한 줄 덧붙임.
  2. [2.3 둘째 항목] 문제: "초록 점으로 표시되면 해당 카메라 준비 완료(5초 이내 하트비트)" — 구현상 초록/회색 판정 기준은 "5초 이내"가 아니라 마지막 하트비트가 15초 이내인지 여부(DashboardViewModel.cs:398, `AddSeconds(-15)`). 5초는 Agent의 송신 주기일 뿐. 또한 카메라별 점은 회색·청록(Connected)·초록(Streaming) 3상태이고(DashboardView.xaml:662-676), 초록/회색 2상태는 Agent 행 헤더의 점임. 독자 입장에서는 두 점을 혼동할 수 있음. -> 제안: "Agent 행의 점이 초록이면 해당 Agent(카메라 PC) 연결 정상 — Agent는 5초 간격으로 상태를내며, 15초 이상 응답이 없으면 회색으로 바뀜"으로 고치고, 카메라 개별 점(청록=연결됨/초록=스트리밍 중) 구분을 한 줄 추가.
  3. [2.2 공용 버튼 항목] 문제: "PLC 부저 OFF / PLC 에러 리셋 / PLC 원점 복귀 — 자주 쓰는 PLC 즉시 명령" 한 줄뿐. 특히 "PLC 원점 복귀"는 서보가 실제로 움직이는 명령인데 언제 눌러야 하는지, 동작 중 장비가 움직인다는 주의가 없음. -> 제안: 버튼별로 "언제 누르는가" 한 줄씩 추가(예: 부저 OFF = 알람 부저가 울릴 때 소리만 끔, 에러 리셋 = PLC 에러 해제, 원점 복귀 = 서보 X/Y축을 원점으로 이동 — 동작 중 축이 움직이므로 주변 확인 후 사용).
  4. [2.2 비상정지 항목] 문제: "비상정지 — 하단의 큰 빨간 버튼"이 설명의 전부. 누르면 무엇이 정지하는지(레시피/서보/챔버), 누른 후 어떻게 복구하는지가 없어, 운전자가 가장 중요한 안전 버튼을 배우지 못함. -> 제안: 눌렀을 때의 동작과 복구 절차를 기술하거나, 최소한 "자세한 내용은 N장 수동 조작/비상 상황 참조" 형태의 상호참조 추가.

  ## 누락/추가 제안
  - 2.1에 언어 선택 콤보(한국어/English) 변경 시 즉시 적용되는지 여부 한 줄 — 운전자가 첫 화면에서 가장 먼저 만질 수 있는 요소이므로.
  - 2.1에 "실행 전 카메라 Agent PC가 켜져 있고 Agent 프로그램이 실행 중이어야 카메라가 초록으로 표시된다"는 전제 조건 한 줄 — 2.3의 회색 점 설명과 자연스럽게 연결됨.
  - "시작하기" 챕터에 프로그램 종료 방법(창 닫기로 종료, 종료 시 레시피 실행 중이면 어떻게 되는지)에 대한 짧은 절이 없음. 종료가 다른 장에서 다뤄진다면 상호참조라도 추가.
  - 그림 번호가 [그림 2]부터 시작 — 그림 1이 1장에 있다면 문제없으나, 매뉴얼 전체의 그림 번호 연속성은 편집 단계에서 확인 필요.
  - 2.2 표의 "탭1/탭2" 표현은 실제 탭 이름(예: 원격 설정 / 장치 관리)으로 바꾸는 편이 화면과 대조하기 쉬움.
