• # 03-대시보드 — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 중
  - 한 줄 요약: 전반적으로 실제 화면(DashboardView.xaml)과 잘 일치하나, Mode 1 동작 설명이 실제 구현과 다르고 우측 AGENTS 목록 패널과 START 인터록(복구 잠금) 설명이 누락되어 보완 필요.

  ## 수정 필요 항목
  1. [3.3 카메라 영상 — 보기 모드] 문제: "Mode 1(Auto 8)/Mode 2(8)/…/Mode 5(1) — 한 화면에 표시할 카메라 수"라고 통합 설명했으나, 실제 Mode 1은 칸 수 지정 모드가 아니다. 구현상 Mode 1은 레시피 실행 중 **현재 스텝에 지정된 카메라 1대를 자동 추적 표시**하고(상태 표시 'Mode 1 — 활성 카메라'), 대기 중에는 'Mode 1 — 대기'로 빈 상태가 된다. 고정 칸 수 모드는 Mode 2(8)/3(4)/4(2)/5(1)뿐이다. -> 제안: Mode 1을 별도 항목으로 분리해 "레시피 실행 중 촬영 중인 카메라를 자동으로 따라가 보여주는 모드"로 기술하고, Mode 2~5만 "한 화면에 표시할 카메라 수 선택"으로 설명.
  2. [3.4 레시피 실행 패널(우측)] 문제: 우측 열은 실제로 **AGENTS 목록(PC별 그룹 + 온라인 표시등 + 카메라별 Connected/Streaming 상태) + RECIPE 실행 패널** 두 블록인데, 챕터에는 레시피 패널만 절로 존재한다. 3.3에서 "우측 카메라 목록을 영상 칸으로 끌어다 놓아 배치"라고 참조하는 그 목록이 어디에도 소개되어 있지 않다. -> 제안: 3.4 앞에 "우측 카메라(Agent) 목록" 소절을 추가(PC별 그룹 헤더, 온라인 녹색 램프, 카메라 상태 Connected/Streaming, 드래그 배치의 출발점임을 명시)하거나, 3.4 제목을 "카메라 목록·레시피 실행 패널(우측)"로 확장.
  3. [3.2 텔레메트리 카드 — EQUIPMENT] 문제: 화면 라벨은 "1차 냉동 / 2차 냉동 / 상온 냉동"(ko.txt의 `Dash_Cooler1Short/2Short/RoomShort`)인데 챕터는 "냉동기1/2/상온"으로 다르게 적었다. -> 제안: 화면 표기와 동일하게 "히터·1차 냉동·2차 냉동·상온 냉동·바이패스·도어램프·페어글라스·MCF·블로워1/2"로 통일.
  4. [3.4 레시피 실행 패널] 문제: START 버튼의 실행 조건이 전혀 없다. 실제로는 ① PLC 에러 발생 후에는 **에러 클리어 + 서보 X/Y가 원점(±0.5mm) 복귀 전까지 START가 잠기는 복구 인터록**(DashboardViewModel의 `RecoveryLockActive`/`CanStartRecipe`)이 있고, ② 레시피 미선택 시 상태란에 "레시피 선택 필요"가 표시된다. 운전자가 "START가 안 눌러진다"고 할 때 가장 먼저 확인할 내용이다. -> 제안: 실행 절차에 전제조건/트러블슈팅 한 단락 추가(예: "PLC 에러 후에는 에러 해소 + 서보 원점 복귀까지 START가 비활성화됨").
  5. [3.4 레시피 실행 패널] 문제: STOP 버튼 옆에 **CONFIG 버튼이 화면에 존재**하지만 현재 Command가 연결되어 있지 않아 눌러도 동작하지 않는다(DashboardView.xaml line 717). -> 제안: 매뉴에 언급하지 않는 현재 상태도 수용 가능하나, 운전자 혼란 방지를 위해 "CONFIG 버튼은 현재 미사용" 한 줄을 넣거나, 기능 구현 후 문서화할 것을 명시.

  ## 누락/추가 제안
  - 레시피 종료 상태 문구 설명: 실행 중 "실행 중: {레시피명}", 정상 종료 "완료", STOP 시 "중지 중…", 예외 시 "오류: {메시지}"가 상태란에 표시됨 — 운전자가 진행바 외에 상태 문구로 결과를 판별할 수 있도록 추가 권고.
  - 빈 영상 칸에는 "DRAG CAMERA HERE" 안내 문구가 표시됨(Mode 2~5 배치 힌트) — 3.3에 한 줄 추가 가능.
  - 상단 카메라 영역에 LIVE 표시등과 페이지/모드 상태 텍스트(예: "Mode 1 — 활성 카메라")가 있음 — 그림 5 캡션에서 짚어주면 좋음.
  - 3.1 HUD의 AGENTS 값이 "N ONLINE" 형식으로 표시되는 점, PLC 표시등이 초록(연결)/빨강(끊김)으로 색이 바뀌는 점을 명시하면 읽는 사람이 화면과 대조하기 쉬움.
  - 챔버 추세 그래프는 데이터가 없는 초기에는 "추세 로딩 중" 안내가 표시됨 — 선택적.
