# 03-대시보드 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 구조와 흐름은 좋으나, 상단 HUD/텔레메트리 표시등의 색상·상태 의미와 우측 "카메라 목록" 패널에 대한 설명이 빠져 있어 일상 운전자가 화면을 보고 바로 판단하기 어려운 부분이 있음.

## 수정 필요 항목
1. [서론] 문제: "우측 카메라/레시피 패널"이라 소개했지만 본문에는 3.4 "레시피 실행 패널"만 있고 "카메라 목록" 패널을 별도로 설명하는 절이 없음(3.3에서 "우측 카메라 목록을 끌어다 놓아 배치"라고만 언급) -> 제안: 3.4 앞에 "카메라 목록 패널" 절을 신설하거나, 최소한 목록에 표시되는 항목(카메라 번호, 온라인 여부 등)과 위치를 3.3 또는 별도 절에서 명확히 설명.
2. [3.1 상단 상태 요약] 문제: PLC 연결 표시등, ALARMS 건수 등 표시등의 색상별 의미(정상/이상/미연결 등)가 설명되어 있지 않아 일상 운전자가 이상 상황을 즉시 인지하기 어려움 -> 제안: 표시등 색상-의미 매핑을 표로 추가.
3. [3.2 텔레메트리 카드] 문제: MOTION 카드의 "X/Y BUSY·원점 표시등"과 EQUIPMENT 카드의 각 장비 표시등도 색상/점멸 의미가 없음 -> 제안: 대표 표시등 1~2개라도 색상 의미 예시를 본문 또는 그림 캡션에 추가.
4. [3.3 카메라 영상] 문제: "Mode 1(Auto 8)"만 "Auto"가 붙고 Mode 2~5는 숫자만 있어, Mode1과 Mode2(둘 다 8분할로 보임)의 차이가 무엇인지 불명확함 -> 제안: "Auto"의 의미(자동 배치 vs 수동 배치 등)를 한 줄로 설명.
5. [3.4 레시피 실행 패널] 문제: STOP 버튼을 눌렀을 때 챔버/모션/카메라가 이후 어떤 상태(정지 유지/원점 복귀 등)가 되는지 서술이 없음 -> 제안: STOP 이후 장비 상태에 대한 짧은 설명 또는 주의 문구 추가.

## 누락/추가 제안
- POINT(현재 서보 포인트 번호)와 AGENTS(온라인 카메라 수)가 정상 범위인지 판단할 기준(예: 전체 포인트 수, 전체 등록 Agent 수 대비 몇 대)이 없어, 숫자만 보고는 정상/비정상 판단이 어려움 — 기준값 또는 비교 대상 표기 제안.
- 비상정지 배너가 뜬 후 운전자가 취해야 할 조치(해제 방법, 확인할 화면 등)에 대한 안내가 이 챕터 또는 상호 참조 링크로 없음 — 관련 챕터로의 참조 문구 추가 제안.

## 이미지 자리 검토
- [그림 4] 적절 — 대시보드 전체 구성을 한눈에 보여주는 목적에 맞으며, 레시피 실행 중 상태를 권장한 것도 타당함.
- [그림 5] 적절 — Mode 버튼·컬러맵·영상 그리드를 함께 캡처하도록 지시해 3.3 내용과 잘 매칭됨.
- [그림 6] 적절 — 다만 캡처 상태를 "진행바가 차 있는 상태"로만 권장했는데, START 이전(대기) 상태 스크린샷도 병기하면 초기 조작법 이해에 더 도움됨(선택 사항).
