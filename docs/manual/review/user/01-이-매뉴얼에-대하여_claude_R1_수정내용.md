# 01-이-매뉴얼에-대하여 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 구조는 명확하나 전문용어 사전 설명 부재와 매뉴얼 사용법(표기 규칙 등) 안내 누락이 아쉬움.

## 수정 필요 항목
1. [1.1 시스템 한눈에 보기] 문제: "챔버·서보·흑체를 제어하고 촬영을 지시"에서 '서보', '흑체'가 이 챕터는 물론 이후 참조 대상도 명시 없이 처음 등장 → 일상 운전자 입장에서 생소한 용어로 혼란 가능. -> 제안: 괄호로 짧은 설명 추가(예: "서보(셔터 구동장치)·흑체(온도 기준 열원)") 하거나, 첫 등장 시점을 실제 조작을 다루는 장으로 미루고 여기서는 "촬영 장비"처럼 포괄적 표현 사용.
2. [머리말] 문제: "[운영자 매뉴얼]"(대괄호 표기)과 이후 "운영자 매뉴얼 2장"(대괄호 없음) 표기가 불일치 → 참조 문서 명칭 표기 규칙이 안 잡혀 보임. -> 제안: 매뉴얼 전체에서 참조 문서명 표기를 하나로 통일(예: 항상 대괄호 없이 "운영자 매뉴얼").

## 누락/추가 제안
- 도입 챕터인 만큼 "이 매뉴얼 사용법" 관련 항목(아이콘/기호 의미, 화면 캡처 표기 규칙, 개정이력·버전 정보, 문의처)이 없음 → 표준 매뉴얼 1장 구성상 통상 포함되는 항목이므로 짧게라도 추가 검토 권장.
- "다루는 내용"에 "알람 확인"이 있으나, "다루지 않는 내용"에는 알람 임계값 설정 등 관리 항목이 언급되지 않음 → 알람 관련해서도 조회/확인(운전자)과 설정(관리자) 경계를 한 줄 명시하면 챕터 간 역할 분담이 더 명확해짐.

## 이미지 자리 검토
- [그림 1] 적절 — 전체 시스템 구성도는 도입부 이해에 필요하고 캡처 대상·대체 방안(운영자 매뉴얼 재사용)까지 안내되어 있어 적절함.
