• # 05-수동-조작 — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: **중**
  - 한 줄 요약: 각 카드의 기능 나열은 빠짐없이 되어 있으나, 운전자가 직접 손대는 화면인 만큼 안전 관련 주의·복귀 절차와 전문 용어(NUC 등) 설명이 부족하고, [주의] 박스의 위치가 어긋나 있다.

  ## 수정 필요 항목
  1. [챕터 말미 [주의] 박스] 문제: 비상정지 주의가 5.4 카메라 제어 뒤에 붙어 있어, 마치 카메라 조작과 관련된 주의처럼 읽힌다. 비상정지는 5.1 챔버 카드에 있는 기능이다. -> 제안: 해당 [주의] 박스를 5.1 챔버/온도 램프 섹션으로 이동.
  2. [5.1 챔버] 문제: 비상정지 사용 시 **복귀 방법**(비상정지 해제 후 온도제어를 다시 '시작'해야 하는지)이 전혀 없다. 실제 비상 상황 이후 운전자가 다음 행동을 알 수 없다. -> 제안: "비상정지 후 복귀 시 ○○ 순서로 재시작" 한두 줄 추가.
  3. [5.4 카메라 제어] 문제: 'NUC'라는 용어를 설명 없이 버튼 나열에만 포함. 일상 운전자 기준으로 생소한 약어(Non-Uniformity Correction)이며, 언제 눌러야 하는지도 없다. -> 제안: "NUC(화면 불균일 보정): 영상에 노이즈·줄무늬가 생길 때 실행" 식의 짧은 설명 추가.
  4. [5.1 습도 제어] 문제: 목표 습도 적용만 나열되고, 저온 구간에서 습도 제어 시 응결(결로) 위험 같은 최소한의 주의가 없다. 챔버 수동 조작에서 가장 흔한 실수 지점이다. -> 제안: "저온 상태에서 습도를 높이면 내부에 결로가 생길 수 있음" 수준의 주의 1줄 추가.
  5. [5.3 서보 조작] 문제: 절대 위치 이동·상대 위치 이동의 입력값 단위와 유효 범위가 없다. 운전자가 임의의 큰 값을 넣어 충돌시킬 수 있다. -> 제안: 좌표 단위(펄스/mm 등 실제 단위)와 이동 가능 범위 명시, "이동 전 챔버 내부 간섭 여부 확인" 주의 추가.
  6. [5.2 모터/팬] 문제: 서보 속도 1~100% 범위는 있는데 팬 속도(Hz)의 유효 범위가 없어 형식이 불일치. -> 제안: 팬 속도에도 허용 Hz 범위 기재.
  7. [전반] 문제: "수동 조작 화면 진입 경로"(메뉴/탭 어디에서 여는지)가 없다. 챕터 첫 문단이 기능 소개로 바로 시작한다. -> 제안: "○○ 메뉴에서 수동 조작 화면을 연다" 진입 경로 1줄 추가.

  ## 누락/추가 제안
  - 5.3 포인트 이동: 포인트 1~20번이 **어디에 저장·설정되는지**(레시피 화면? 별도 설정?) 한 줄 언급이 있으면 좋음. 현재는 버튼 존재만 나옴.
  - 챕터 말미에 "수동 조작 중 자동(레시피) 운전과의 관계" — 예: 레시피 운전 중 수동 조작 가능 여부, 충돌 시 동작 — 이 없으면 운전자가 혼란스러울 수 있음. 실제 동작 확인 후 한 줄 추가 권장.

  ## 이미지 자리 검토
  - [그림 10] 적절 — 챕터 전체 개관용 전체 캡처는 유효. 다만 카드가 많은 화면이라 "모든 카드가 보이도록" 한 장에 담으면 글자가 작아질 수 있음 → 참고용으로 명시하면 좋음.
  - [그림 11] 적절 — 5.1의 두 카드 대응 명확.
  - [그림 12] 적절 — 다만 "표시 영역: 창 가운데/우측"이 모호. '장비 원터치 카드'라고 카드명으로 지정한 게 이미 충분하므로, 모호한 위치 표현은 카드명 기준으로 통일 권장.
  - [그림 13] 부적절(부분) — JOG·원점·절대/상대 이동 카드와 포인트 이동(20버튼)이 한 장에 포함되는데, 실제 화면에서 두 영역이 떨어져 있으면 한 캡처로 표현이 어색하다. -> 제안: 필요 시 [그림 13-1] 서보 조작 카드 / [그림 13-2] 포인트 이동 버튼으로 분리.
  - [그림 14] 적절 — 영상+버튼이 함께 보여야 하는 카드 특성상 캡처 조건("카메라 영상이 나오는 상태") 명시도 좋음.
