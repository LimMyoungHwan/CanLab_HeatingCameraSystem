# 10-시작-→-종료-순서(일상) — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 상
- 한 줄 요약: 일상 운전 흐름은 간결하지만, 시작 전 연결 확인과 이상 발생 시 조치, 안전한 종료 조건이 빠져 있어 실제 운전 절차로 사용하기에는 불충분하다.

## 수정 필요 항목
1. [2단계] 문제: NATS/PLC 연결에 실패해도 화면이 표시된다는 설명만 있고, 운전자가 연결 성공 여부를 어디서 확인하고 실패 시 어떻게 해야 하는지 없다. -> 제안: 대시보드에서 NATS 및 PLC 연결 상태를 확인하고, 연결 실패 상태에서는 START하지 않도록 명시한다.
2. [3단계] 문제: Agent 상태가 “5초 내” 초록 점으로 바뀐다고 단정하지만, 네트워크 연결이나 Agent 기동 지연이 있을 수 있다. -> 제안: “기동 후 다음 상태 갱신 시점까지 기다린 뒤 초록 점 확인”으로 표현하고, 계속 표시되지 않을 때 Agent와 NATS 연결을 점검하도록 안내한다.
3. [4단계] 문제: “시리얼/카메라 설정 전송”의 대상, 필요 조건, 정상 반영 여부가 불명확하다. 매일 수행하는 절차인지 최초 설치·설정 변경 시에만 수행하는지도 알 수 없다. -> 제안: 설정 변경이 필요한 경우에만 수행한다고 밝히고, 전송 후 오류 여부를 확인하도록 작성한다.
4. [5단계] 문제: 레시피 선택 직후 START하도록 되어 있어 PLC와 필요한 Agent의 정상 연결 여부를 재확인하는 단계가 없다. -> 제안: 레시피 선택 후 연결 상태와 레시피가 올바른지 확인한 다음 START하도록 순서를 분리한다.
5. [6단계] 문제: “진행바·알람으로 모니터링”만 제시되어 알람 발생 시 운전자가 무엇을 해야 하는지 알 수 없다. -> 제안: 알람 발생 시 내용을 확인하고 원인이 해소되기 전에는 운전을 계속하거나 다시 시작하지 않도록 안내한다.
6. [7단계] 문제: “완료”의 판단 기준과 확인해야 할 결과가 모호하다. -> 제안: 화면에서 운전 완료 상태를 확인한 뒤 이력 조회에서 해당 실행의 결과와 촬영 결과를 확인하도록 구체화한다.
7. [8단계] 문제: 운전 진행 중에도 카메라 PC와 Master를 종료할 수 있는 것처럼 읽힌다. 또한 Master보다 카메라 PC를 먼저 종료해야 하는 근거가 제시되지 않는다. -> 제안: 운전이 완료되었거나 안전하게 중지된 상태임을 확인한 후 종료하도록 명시하고, 종료 중인 프로그램을 강제로 끄지 않도록 안내한다.
8. [전체] 문제: 각 단계가 짧은 메모 형태라 정상 상태와 이상 상태의 분기가 드러나지 않는다. -> 제안: “시작 전 확인–운전 시작–운전 중 감시–결과 확인–종료” 소제목으로 구분한다.

## 누락/추가 제안
- 시작 전에 PLC와 카메라 장비가 켜져 있고 통신 가능한 상태인지 확인하는 절차를 추가한다.
- 레시피명과 운전 대상이 맞는지 START 전에 확인하도록 안내한다.
- NATS, PLC 또는 필요한 Agent가 연결되지 않은 경우 START하지 않는다는 경고를 추가한다.
- 운전 중 알람이나 통신 끊김이 발생했을 때 알람 내용을 기록하고 관리자에게 보고하는 기준을 추가한다.
- 프로그램과 PC 종료 전에 진행 중인 운전이 없음을 확인하는 절차를 추가한다.

## 이미지 자리 검토
- 이미지 자리 없음 — 대시보드의 NATS·PLC·Agent 정상 연결 상태와 레시피 선택 및 START 위치를 보여 주는 그림을 추가하면 일상 운전자의 확인 실수를 줄일 수 있다.
- 이미지 자리 없음 — 완료 상태와 이력 조회 결과 화면을 보여 주는 그림을 추가하면 종료 전 확인 기준이 명확해진다.

## (선택) 수정 제안 전문

# 10. 시작 → 종료 순서(일상)

## 1. 시작 전 확인

1. NATS 서버가 켜져 있는지 확인합니다. NATS 서버는 보통 상시 가동합니다.
2. PLC와 카메라 장비가 켜져 있는지 확인합니다.
3. Master를 실행합니다. 연결에 실패해도 Master 화면은 표시될 수 있습니다.
4. 대시보드에서 NATS와 PLC의 연결 상태가 정상인지 확인합니다.
5. 카메라(Agent) PC를 기동한 뒤 대시보드에서 해당 Agent가 초록 점으로 표시되는지 확인합니다.
6. NATS, PLC 또는 운전에 필요한 Agent가 정상적으로 연결되지 않은 경우 START하지 말고 연결 상태를 점검합니다.

📷 [그림 1] 대시보드에서 NATS, PLC 및 Agent가 정상 연결된 상태

## 2. 설정 및 운전 시작

1. 시리얼 또는 카메라 설정을 변경해야 하는 경우에만 Agent 설정에서 해당 설정을 전송하고 오류가 없는지 확인합니다.
2. 대시보드에서 실행할 레시피를 선택합니다.
3. 선택한 레시피명과 운전 대상이 맞는지 다시 확인합니다.
4. 연결 상태가 모두 정상인 상태에서 START합니다.

📷 [그림 2] 레시피 선택 위치와 START 실행 위치

## 3. 운전 중 확인

1. 진행바에서 현재 진행 상태를 확인합니다.
2. 알람이 발생하면 알람 내용을 확인합니다.
3. 알람이나 통신 끊김의 원인이 해소되지 않은 상태에서는 운전을 계속하거나 다시 시작하지 않습니다.

## 4. 완료 및 결과 확인

1. 화면에서 운전이 완료되었는지 확인합니다.
2. 이력 조회에서 해당 실행의 결과와 촬영 결과를 확인합니다.
3. 오류나 누락된 결과가 있으면 내용을 기록하고 관리자에게 알립니다.

📷 [그림 3] 운전 완료 상태와 이력 조회의 결과 확인 위치

## 5. 종료

1. 진행 중인 운전이 없고 운전이 완료되었거나 안전하게 중지되었는지 확인합니다.
2. 카메라(Agent) PC를 종료합니다.
3. Master 창을 닫습니다.
4. 종료 중인 프로그램을 강제로 끄지 않습니다.
