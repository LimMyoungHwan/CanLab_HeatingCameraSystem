# 10-시작-→-종료-순서(일상) — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 절차 흐름 자체는 논리적이나, 괄호로 언급된 예외 상황(연결 실패·초록 점 미확인 등)에 대한 대응 안내와 이미지 자리가 전혀 없어 일상 운전자가 실제 현장에서 막힐 가능성이 큼.

## 수정 필요 항목
1. [2번 항목] 문제: "실패해도 화면은 뜸"이라고만 명시하고 실패 시 운전자가 무엇을 확인/조치해야 하는지 없음 -> 제안: "연결 실패 시 화면 상단 상태표시(빨간색/회색 등)로 확인 가능, 재연결은 [X] 참고" 식으로 다음 행동 또는 참고 챕터를 연결.
2. [3번 항목] 문제: "5초 내 초록 점 확인"만 있고, 5초가 지나도 초록 점이 안 뜰 때 조치가 없음 -> 제안: "초록 점이 안 뜨면 Agent PC 네트워크/전원 확인 → [문제해결 챕터] 참고" 등 분기 안내 추가.
3. [4번 항목] 문제: "(필요 시)"가 무엇을 기준으로 필요한지 불명확(레시피 신규 등록 시? 설정 변경 시?) -> 제안: 필요 조건을 구체적으로 명시 (예: "레시피에 신규 시리얼/카메라 파라미터가 있을 때만").
4. [5번 항목] 문제: START 누르기 전 확인해야 할 선행 조건(셔터 상태, 카메라 준비 상태 등)이 없음 -> 제안: START 직전 체크리스트 1줄 추가 (예: "셔터 닫힘/카메라 Ready 확인 후 START").
5. [6번 항목] 문제: "알람으로 모니터링"만 있고 알람 발생 시 대응 절차/참고 문서 연결이 없음 -> 제안: "알람 발생 시 [알람 대응 챕터] 참고" 링크 추가.
6. [8번 항목] 문제: 종료 순서가 "카메라 PC 종료 → Master 창 닫기"인데, 그 이유(순서를 지켜야 하는 근거)나 반대로 했을 때 문제 여부 언급 없음 -> 제안: 순서 근거 한 줄 추가 (예: "Master를 먼저 닫으면 Agent 연결 오류 로그 발생 가능, 반드시 Agent PC부터 종료").

## 누락/추가 제안
- 각 단계 소요 시간이나 정상 여부 판단 기준(초록 점 외 다른 상태 표시 색상 의미)이 없음 — 색상별 상태표 추가 권장.
- 시작 전 준비물/전제조건(예: 레시피 사전 등록 여부, PLC 전원 확인)이 챕터 도입부에 없음.
- 종료 후 재시작 시 유의사항(예: 진행 중 레시피 중단 여부) 언급 없음.

## 이미지 자리 검토
- 없음 — 본 챕터에는 📷 [그림 N] 자리가 하나도 없음. 일상 운전자용 첫 챕터인 만큼 최소 (1) Master 실행 후 연결 상태 화면, (2) 대시보드 초록 점 예시, (3) START 버튼 위치, (4) 이력 조회 화면 정도는 이미지 자리 추가를 권장.
