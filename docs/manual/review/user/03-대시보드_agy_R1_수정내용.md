# 03-대시보드 — agy 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 대시보드의 3단 레이아웃과 핵심 모니터링 기능이 잘 정리되어 있으나, 우측 상단 Agent/카메라 목록 섹션의 독립 설명 누락, 레시피 패널의 [CONFIG] 버튼 누락, 수동 카메라 배치(Drag & Drop) 마우스 조작법 안내 구체화가 필요합니다.

## 수정 필요 항목
1. [3. 서론 (대시보드 전체 구성)] 문제: "좌측 텔레메트리 카드, 가운데 카메라 영상, 우측 카메라/레시피 패널로 구성된다"로 표기되어 있어 상단 HUD 상태 바 및 비상정지 배너와 우측 영역의 상세 구분(Agent 목록 + 레시피 실행 패널)이 불명확함 -> 제안: "상단 상태 바(HUD/비상정지 배너), 좌측 텔레메트리 카드, 가운데 카메라 영상 피드, 우측 Agent 목록 및 레시피 실행 패널의 구조로 구성된다."로 구체화.
2. [3.1 상단 상태 요약(HUD) - AGENTS] 문제: "AGENTS — 현재 온라인 카메라(Agent) 수"로 기술되어 개별 카메라 수인지 Agent PC 수인지 운전자가 혼동할 여지가 있음 -> 제안: "AGENTS — 현재 네트워크(NATS)에 정상 연결된 온라인 Agent PC 수"로 표현 명확화.
3. [3.3 카메라 영상(가운데) - 드래그 앤 드롭 조작] 문제: "우측 카메라 목록을 영상 칸으로 끌어다 놓아 배치, 우클릭으로 비움" 설명이 다소 단순함 -> 제안: "Mode 2~5에서는 우측 상단 [AGENTS] 목록의 카메라 항목을 마우스 좌클릭으로 드래그하여 원하는 영상 칸(Slot)에 끌어다 놓아 배치하고, 할당된 영상 칸에서 마우스 우클릭을 하면 비우기(할당 해제)된다."로 마우스 동작 구체화.
4. [3.4 레시피 실행 패널(우측) - CONFIG 버튼] 문제: 레시피 실행 패널 우측 하단에 위치한 [CONFIG] 버튼(레시피 설정/편집 화면 이동)에 대한 설명이 누락됨 -> 제안: 단계 설명 5번 항목 추가: "5. 레시피 상세 설정이나 레시피 편집 화면으로 즉시 이동하려면 [CONFIG] 버튼을 클릭한다."

## 누락/추가 제안
- **우측 상단 [AGENTS] 카메라 목록 패널 설명 추가**: 우측 영역 상단에는 NATS 통신 상태(온라인/오프라인)와 각 Agent PC에 속한 카메라 목록(Connected/Streaming 상태)이 표시됩니다. 이 영역이 3.4절(레시피 실행 패널)에 묻혀 있으므로, `3.4 Agent 및 카메라 목록 패널`과 `3.5 레시피 실행 패널`로 소목적을 분리하거나 서브 섹션으로 명시할 것을 제안합니다.

## 이미지 자리 검토
- [그림 4] 대시보드 전체: 적절 — 대시보드 3단 구도와 상단 HUD, 비상정지 배너 배치를 한눈에 파악하는 데 필수적임.
- [그림 5] 카메라 영상 영역: 적절 — Mode 1~5 보기 버튼, 컬러맵 선택, 카메라 ID/실시간 영상/측정 온도 및 No Signal 표시 상태를 시각적으로 보여주므로 적절함.
- [그림 6] 레시피 실행 패널: 적절 — RECIPE 선택 콤보, 🔄 새로고침 버튼, START/STOP/CONFIG 버튼, 진행바 및 단계 문구 배치를 명확히 제시함. (우측 상단 Agent 목록까지 포함한 우측 전체 영역 캡처 권장).
