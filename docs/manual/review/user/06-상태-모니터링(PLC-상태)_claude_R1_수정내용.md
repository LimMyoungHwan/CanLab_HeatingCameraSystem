# 06-상태-모니터링(PLC-상태) — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 화면 구성 설명은 실제 UI와 정확히 일치하나, 연결 끊김·알람 없음 상태 등 예외 상황과 일부 항목(에러코드, 장비 상태 목록) 설명이 빠져 있음.

## 수정 필요 항목
1. [본문 첫 줄] 문제: "PLC 연결" 항목이 상단 요약에 있다고만 하고, 연결이 끊겼을 때 램프 색이 어떻게 바뀌는지(정상=녹색, 끊김=빨간색) 설명이 없음 -> 제안: "상단 좌측 원형 램프: 연결 시 녹색, 끊김 시 빨간색으로 표시" 문장 추가.
2. [PLC 알람 카드] 문제: "활성 오류는 빨간색으로 표시"라고만 하고 오류가 없을 때 리스트가 비어 있는지/전체 항목이 회색으로 나열되는지 설명이 없어 운전자가 "빈 화면=오류"로 오인할 수 있음 -> 제안: "오류가 없으면 모든 항목이 회색(꺼짐)으로 표시된다" 등 정상 상태 설명 추가.
3. [서보·직교로봇 카드] 문제: 실제 화면에는 X/Y 에러코드 항목이 있는데 챕터 본문에 언급이 없음(완결성 누락) -> 제안: "서보·직교로봇 카드" 설명에 "X/Y 에러코드" 항목 추가.
4. [하단 장비 상태 표시등] 문제: "장비 상태 표시등"이라고만 하고 어떤 장비들이 표시되는지(히터, 1차/2차/상온 냉동기, 바이패스, 도어램프, 페어글라스, MCF, 블로워1/2) 나열이 없어 운전자가 이상 유무를 판단하기 어려움 -> 제안: 주요 장비 목록을 한 줄로 나열하거나 "그림 16에서 항목명 확인" 안내 추가.
5. [알람 해제 관련] 문제: 알람이 빨간색으로 뜬 경우 다음 행동(해제 방법, 몇 장 참고)에 대한 안내가 없음 -> 제안: "알람 확인·해제 방법은 8장 참고" 문구 추가.

## 누락/추가 제안
- 갱신 주기 "약 1초"가 다른 장 대시보드의 갱신 주기와 일치하는지 확인 필요(용어 일관성).
- 서보 포인트(POINT) 값이 무엇을 의미하는지(현재 촬영 중인 좌표 번호 등) 한 줄 설명 추가하면 초보 운전자에게 도움됨.

## 이미지 자리 검토
- [그림 15] 적절 — 상단 요약+카드 전체가 한 화면에 잘 드러남.
- [그림 16] 적절 — 다만 정상 상태만 캡처하도록 되어 있어, 위 항목 2와 연계해 "알람 활성(빨간색) 상태" 예시 그림을 별도로 하나 더 추가하면 완결성이 높아짐(선택 사항).
