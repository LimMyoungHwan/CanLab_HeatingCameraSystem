## (선택) 수정 제안 전문

# 7. 이력 조회

촬영 결과와 챔버 데이터, 알람 이력을 조회하고 CSV 파일로 내보낼 수 있다. 이력 조회 화면 상단의 탭 버튼([촬영 이력] / [챔버 이력] / [알람 이력])을 선택하여 각 이력 화면으로 전환한다.


## 7.1 촬영 이력

- **조회 필터**: 시작/종료 날짜 및 카메라 그룹(전체/특정 Agent PC)을 지정한 후 '조회' 버튼을 클릭한다.
- **결과 표**: 타임스탬프, 카메라 ID, 온도(℃), 습도(%RH), 썸네일 이미지가 표시되며, '열기' 버튼으로 상세 정보를 확인한다.
- **페이지 이동**: 하단 페이징 컨트롤을 통해 페이지 이동(첫/이전/다음/마지막) 및 전체 레코드 건수를 확인한다.
- **CSV 내보내기**: 'CSV 내보내기' 버튼을 눌러 현재 설정된 조회 조건의 촬영 이력전체를 CSV 파일로 저장한다.

> 📷 **[그림 17] 이력 조회 — 촬영 이력**
> - **캡처 대상:** 촬영 이력 탭(필터 + 표 + 썸네일 + 하단 페이징)
> - **화면/상태:** 조회 결과가 여러 건 표시된 상태
> - **표시 영역:** 창 가운데


## 7.2 챔버 이력 / 알람 이력

- **챔버 이력**: 시간별 챔버 내부 온도·습도 및 흑체1·흑체2(BlackBody) 모니터링 데이터를 조회한다.
- **알람 이력**: 시간·등급·출처·알람 메시지 기록을 조회한다. 상단 '알람 수준' 필터('전체', '정보 이상', '경고 이상', '오류만')를 통해 특정 심각도 이상의 알람만 선별하여 확인할 수 있다.

> 📷 **[그림 18] 이력 조회 — 챔버 이력**
> - **캡처 대상:** 챔버 이력 탭(시간/온도/습도/BB1/BB2 표)
> - **화면/상태:** 조회 결과 표시 상태
> - **표시 영역:** 창 가운데

> 📷 **[그림 19] 이력 조회 — 알람 이력**
> - **캡처 대상:** 알람 이력 탭(시간/등급/출처/메시지 표 + 알람 수준 필터)
> - **화면/상태:** 알람이 조회된 상태
> - **표시 영역:** 창 가운데


## 7.3 이미지 상세 보기

촬영 이력 표에서 '열기' 버튼을 누르면 확대 이미지, 열화상 스케일 바, 카메라 소스, 타임스탬프, 온도, 습도 정보가 포함된 이미지 상세 모달 창이 표시된다.

> 📷 **[그림 20] 이미지 상세 보기**
> - **캡처 대상:** 촬영 이미지 상세 모달(확대 이미지 + 열화상 스케일 + 메타정보)
> - **화면/상태:** 이미지 1건을 연 상태
> - **표시 영역:** 화면 중앙 팝업
