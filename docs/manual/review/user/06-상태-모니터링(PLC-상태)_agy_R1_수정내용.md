# 06-상태-모니터링(PLC-상태) — agy 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 화면 항목이 단순 불릿 나열 위주로 요약되어 있어, 일상 운전자가 각 센서·알람·표시등 램프의 가동/오류 상태와 단위 의미를 직관적으로 파악하기 어렵고 체계적인 서술 구조가 필요함.

## 수정 필요 항목
1. [개요 및 기능 명세] 문제: "값을 바꾸지는 않는다" 수준의 요약만 존재하여, 왜 읽기 전용(Read-Only) 화면인지 및 약 1초 주기 자동 갱신 특성에 대한 운전 안내 부족. -> 제안: 운전자가 실시간 장비 동작, 온/습도, 서보 위치, 알람을 감시하는 목적으로 활용함을 명시하고 갱신 주기 및 모니터링 특성 서술 보강.
2. [화면 구성 항목 나열] 문제: 상단 요약 바, 각 모니터링 카드, 알람, 하단 입출력/장비 상태 표시등이 단순 텍스트 나열로 되어 있어 읽기 어려움. -> 제안: 6.1 상단 요약 바, 6.2 모니터링 카드 상세(챔버 환경, 흑체 기준 온도, 서보/직교로봇, 진행/기타), 6.3 PLC 알람 및 하단 입출력/장비 표시등으로 세부 소제목을 나누어 체계적으로 구성.
3. [표시등(램프) 상태 및 범례 미비] 문제: 알람의 빨간색 표시 외에 서보 BUSY/원점, 입력(P000~), 출력(P020~), 장비 상태 램프의 ON/OFF 색상 범례(녹색: ON/동작, 회색: OFF/대기, 빨간색: 오류) 설명 누락. -> 제안: 각 표시등 영역별 램프 색상 기준과 센서/부하 명칭을 상세히 기재하여 운전자의 시각적 직관성 확보.

## 누락/추가 제안
- **알람 발생 시 운전자 기본 조치 가이드**: PLC 알람 카드에서 빨간색 표시등(오류) 점등 시 비상 정지 상태 확인 및 알람 명칭 확인 조치 안내 추가.
- **흑체 온도(PV/SV) 용어 표기 보강**: PV(현재 측정 온도), SV(목표 설정 온도) 약어 표기와 흑체1/흑체2 교정용 온도의 연동 의미 안내 보강.

## (선택) 수정 제안 전문

# 6. 상태 모니터링(PLC 상태)

PLC 상태 모니터링 화면은 챔버 온/습도, 흑체 기준 온도, 서보 로봇 위치, PLC 알람 및 입출력(I/O) 접점 상태를 **약 1초 주기로 자동 갱신하여 읽기 전용(Read-Only)**으로 보여주는 화면입니다.
운전자는 이 화면에서 직접 설정값을 변경할 수 없으며, 레시피 진행 중이나 장비 가동 상태를 실시간으로 감독할 때 활용합니다.

> 📷 **[그림 15] PLC 상태 화면**
> - **캡처 대상:** PLC 상태 화면 전체(상단 요약 바 + 각 카드)
> - **화면/상태:** PLC 연결된 상태(실시간 값이 정상 표시됨)
> - **표시 영역:** 창 전체

---

## 6.1 상단 요약 바

화면 최상단 영역에는 운전자가 가장 자주 확인하는 핵심 상태 지표가 요약 표시됩니다.

- **PLC 연결 상태**: PLC와의 통신 상태 표시등 (🟢 녹색: 연결 정상 / 🔴 빨간색: 연결 끊김) 및 실시간 상태 메시지.
- **챔버 온도**: 현재 측정 온도(℃) 및 레시피 목표 온도(℃).
- **챔버 습도**: 현재 측정 습도(%RH) 및 레시피 목표 습도(%RH).
- **진행 상태**: 현재 실행 중인 레시피 스텝 (`현재 스텝 / 전체 스텝`) 및 진행률 바(ProgressBar).
- **서보 포인트**: 현재 장비의 서보 이동 목표 포인트 번호(`POINT`) 및 현재 X/Y 실시간 좌표(mm).

---

## 6.2 모니터링 카드 상세

화면 중앙은 4개의 주요 카드 영역으로 나누어 세부 측정값을 표시합니다.

### 1) 챔버 환경 카드
- **현재/목표 온도 (℃)**: 챔버 내부 실시간 온도 및 레시피 설정 온도.
- **현재/목표 습도 (%RH)**: 챔버 내부 실시간 습도 및 설정 습도.
- **팬 속도 (Hz)**: 챔버 내부 순환 팬의 현재 운전 주파수.
- **GAS 유속**: 챔버 공급 가스의 현재 유속.

### 2) 흑체 기준 온도 카드
- **흑체1 현재(PV) / 목표(SV) (℃)**: 열화상 카메라 교정용 흑체1의 현재 측정 온도(PV)와 설정 온도(SV).
- **흑체2 현재(PV) / 목표(SV) (℃)**: 흑체2의 현재 측정 온도(PV)와 설정 온도(SV).

### 3) 서보 / 직교로봇 카드
- **X / Y 위치 (mm)**: 서보 이송축의 실시간 위치 좌표.
- **현재 포인트**: 지정된 서보 목표 위치 번호.
- **X / Y 에러코드**: 서보 드라이버 정상(0) 및 오류 발생 시 에러 코드 번호.
- **상태 램프**: 
  - `X BUSY` / `Y BUSY`: 서보 축 이동 중 (🟢 녹색 점등)
  - `X 원점` / `Y 원점`: 서보 축 원점 복귀 완료 (🟢 녹색 점등)

### 4) 진행 / 기타 카드
- 레시피의 전체 진행 단계, 현재 포인트, 팬 속도 및 GAS 유속을 요약하여 시각화.

---

## 6.3 PLC 알람 및 입출력·장비 표시등

화면 우측 및 하단에는 장비 안전과 직결되는 알람 및 I/O 램프 상태가 배치되어 있습니다.

### 1) PLC 알람 카드 (우측)
- **오류 비트 목록**: 장비 내부 주요 오류 항목 감지.
- **표시 방법**: 정상 시 회색(⚪), 활성화된 오류는 **빨간색(🔴)** 표시등으로 강조.
- *참고:* 알람 점등 시 즉시 해당 오류 항목 명칭 및 장비 비상 정지 상태를 점검하십시오.

### 2) 입력 / 출력 표시등 (하단 좌측·중앙)
- **입력 P000~**: PLC 입력 센서 및 스위치 신호 상태 (🟢 녹색: ON / ⚪ 회색: OFF).
- **출력 P020~**: PLC 출력 리레이 및 액추에이터 제어 신호 상태 (🟢 녹색: ON / ⚪ 회색: OFF).

### 3) 장비 상태 램프 (하단 우측)
- 주요 하드웨어 부하의 실시간 동작 상태를 녹색(🟢) 램프로 표시합니다.
- **표시 항목**: 히터, 1차 냉동기, 2차 냉동기, 상온 냉동기, 바이패스, 도어램프, 페어글라스, MCF, 블로워1, 블로워2.

> 📷 **[그림 16] PLC 입출력·장비 램프**
> - **캡처 대상:** PLC 상태 화면 하단의 입력/출력/장비 상태 표시등 영역
> - **화면/상태:** 정상 동작 중 표시등 점등 상태
> - **표시 영역:** 창 아래쪽 전체 (입력 P000~, 출력 P020~, 장비 상태)
