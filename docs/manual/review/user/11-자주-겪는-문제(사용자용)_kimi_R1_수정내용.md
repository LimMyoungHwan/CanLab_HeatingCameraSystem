• # 11-자주-겪는-문제(사용자용) — kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 중
  - 한 줄 요약: 표 자체의 증상-확인 대응은 대체로 정확하나, 챕터가 표 1개뿐이라 도입부·에스컬레이션 기준·화면 위치 안내가 없어 일상 운전자가 단독으로 따라 하기에는 정보가 부족함.

  ## 수정 필요 항목
  1. [전체] 문제: 대상 독자가 "일상 운전자"인데 본문에서 반복적으로 "운영자에게 문의"라고 표현되어 역할이 혼동됨(독자 자신이 운전자). -> 제안: "관리자(또는 설비 담당자)에게 문의"로 통일하고, 챕터 도입부에 "스스로 해결할 수 있는 것 / 관리자에게 넘길 것" 구분 기준을 한두 문장으로 명시.
  2. [전체] 문제: 도입부가 없음. 문제 발생 시 공통으로 먼저 확인할 것(화면 새로고침 필요 여부, 잠시 대기, 언제 STOP을 누를지)과 문의 시 전달할 정보(발생 시각, 카메라 번호, 알람 메시지)에 대한 안내가 없음. -> 제안: 표 앞에 "공통 확인 순서" 3~4단계와 "문의 시 알려줄 정보" 목록 추가.
  3. [1행 — 카메라 초록 점] 문제: "초록 점"의 위치(대시보드 어느 영역인지)와 점 색상의 의미(초록/회색/빨강 각각의 뜻)가 설명되지 않음. "잠시 후에도 회색이면"의 대략적 기준(몇 초/몇 분)도 없음. -> 제안: 상태 점 위치와 색상 의미를 표나 그림으로 명시하고, 대기 기준을 구체화(예: 1분 이상 회색 유지 시).
  4. [2행 — 캡처 타임아웃] 문제: "레시피 스텝의 카메라 지정" 확인은 레시피 편집 권한이 없는 일상 운전자가 수행하기 어려운 항목일 수 있음. -> 제안: 운전자가 할 수 있는 확인(대상 카메라 점 색 확인)과 관리자에게 넘길 확인(레시피-카메라 매칭)을 분리해서 기술.
  5. [3행 — 온도/습도 0 고정] 문제: "PLC 연결 표시등"이 어느 화면의 어느 위치인지 명시되지 않아 독자가 찾기 어려움. -> 제안: 화면명과 위치를 명시(예: 상태 화면 상단의 PLC 표시등)하고 그림 추가.
  6. [4행 — 챔버 안정화 멈춤] 문제: "STOP 후 설비 점검"이라고만 되어 있어, STOP 버튼 위치와 설비 점검이 운전자 범위인지 관리자 범위인지 불명확. -> 제안: STOP 위치 명시, "이후 관리자에게 연락"으로 마무리.
  7. [6행 — 알람] 문제: "등급 필터", "부저 OFF", "에러 리셋"이 화면의 실제 버튼/컨트롤 명칭과 일치하는지 확인 필요하고, 위치 안내가 없음. 용어가 이전 챕터(알람 관련 장)와 일치하는지도 점검 요망. -> 제안: UI 라벨 그대로 표기하고 알람 화면 그림과 함께 위치 표시.
  8. [전체 — 용어] 문제: "점 색", "표시등", "RUN/셔터" 등 지칭 방식이 행마다 들쭉날쭉함. -> 제안: 화면 구성요소 명칭을 앞선 챕터들과 통일(예: "카메라 상태 표시", "수동 조작 탭의 카메라 제어").

  ## 누락/추가 제안
  - NATS 서버(메시지 중간 연결) 문제 증상 누락: 카메라는 켜져 있는데 전체적으로 응답이 없거나 모든 카메라 점이 동시에 회색일 때의 확인 방법(마스터 PC의 연결 상태, 관리자 문의) 추가 권장.
  - 촬영 이미지가 검게/비정상적으로 나오는 경우(셔터 상태 관련) 증상 행 추가 권장 — 5행의 "셔터 반응 없음"과 구분되는 일상적 증상.
  - Master 프로그램 자체가 시작되지 않거나 화면이 멈춘 경우의 기본 대응(재시작, 그래도 안 되면 관리자 문의) 추가 권장.
  - "문의처/연락 방법" 안내(관리자 연락처 기재 위치) — 다른 챕터에 있다면 상호 참조 한 줄.

  ## 이미지 자리 검토
  - 챕터 내 📷 [그림 N] 자리가 하나도 없음. 트러블슈팅 챕터 특성상 화면 위치를 찾아야 하는 항목이 많아 최소 2~3개의 스크린샷이 필요함:
    - [그림 1 제안] 대시보드의 카메라 상태 점(초록/회색 예시) — 1행 대응, 적절
    - [그림 2 제안] PLC 연결 표시등 위치가 표시된 상태 화면 — 3행 대응, 적절
    - [그림 3 제안] 알람 화면의 등급 필터·부저 OFF·에러 리셋 위치 — 6행 대응, 적절
