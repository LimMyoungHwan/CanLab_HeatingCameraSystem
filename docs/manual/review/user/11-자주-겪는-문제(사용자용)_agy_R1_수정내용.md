## 종합 평가
- 수정 필요도: 상
- 한 줄 요약: 기존 챕터 내용이 6개 항목의 간이 요약 표로만 작성되어 있어 일상 운전자가 현장에서 대처하기에 내용이 지나치게 단편적이며, 주요 인디케이터 위치 및 📷 이미지 자리가 완전히 누락되어 있어 보완이 필요합니다.

## 수정 필요 항목
1. [표 내 구체적 UI 위치 및 버튼 명칭 누락] 문제: "PLC 연결 표시등", "카메라 점 색", "알람이 계속 뜸" 등 확인 사항에서 실제 Master 화면 상의 위치(상단 HUD, 우측 [AGENTS] 패널, 하단 알람 배너 등)와 정확한 버튼 명칭([STOP], [Buzzer Off], [Reset Error])이 기술되어 있지 않음 -> 제안: 운전자가 화면을 보고 바로 찾을 수 있도록 정확한 UI 위치 및 버튼 명칭을 명시.
2. [1차 대응 절차와 운영자 전달 기준의 미구분] "확인 사항"에 운전자가 현장에서 조치할 내용과 운영자에게 보고해야 할 사항이 혼재되어 있음 -> 제안: 운전자의 1차 점검/조치 단계(PC 전원, Cable, 소프트웨어 조작)와 2차 운영자 문의 기준(하드웨어/통신 이상)을 구분하여 작성.
3. [레시피 정지 및 캡처 타임아웃 조치 설명 구체화] 문제: "STOP 후 설비 점검", "카메라 지정과 실제 카메라 매칭 확인"이 운전자 관점에서 추상적임 -> 제안: 타임아웃 발생 시 대시보드 우측 레시피 실행 패널의 [STOP] 버튼을 통한 안전 정지 절차와 AGENTS 패널 접속 상태 확인 방법을 단계별로 서술.

## 누락/추가 제안
- **챕터 서론 및 1차 대응 원칙 안내 추가**: 문제 발생 시 공통 1차 대응 흐름(인디케이터 확인 → 알람음 차단 → 안전 정지 → 현장 보고)에 대한 서문 추가.
- **운영자 문의 시 전달할 정보 가이드 추가**: 1차 조치 불가 시 운영자에게 보고해야 할 주요 항목(발생 시각, 알람 코드, 통신 인디케이터 상태 등) 정리 섹션 추가.

## (선택) 수정 제안 전문

# 11. 자주 겪는 문제(사용자용)

본 챕터는 일상 운전 중 발생할 수 있는 주요 이상 증상과 운전자가 현장에서 직접 확인하고 조치할 수 있는 1차 대응 절차를 안내합니다. 1차 조치 후에도 증상이 해결되지 않으면 안내된 정보를 수집하여 설비 운영자에게 문의하십시오.

📷 [그림 11.1] 자주 겪는 문제 해결 시 주요 확인 위치 (대시보드 HUD, AGENTS 패널, 알람 제어)

## 11.1 주요 증상별 확인 및 대응 표

| 증상 | 1차 확인 사항 (운전자 조치) | 추가 조치 및 운영자 문의 기준 |
| --- | --- | --- |
| **대시보드에 카메라 초록 점이 안 뜸** | ① 해당 카메라 PC(Agent) 전원이 켜져 있는지 확인<br>② 네트워크 Cable 연결 상태 확인<br>③ 잠시 대기 후에도 회색(오프라인) 상태 지속 시 | Agent 프로그램 재실행 후에도 연결되지 않으면 네트워크 switch hub 및 운영자 문의 |
| **촬영 제한시간 초과 (캡처 타임아웃)** | ① 대시보드 우측 상단 [AGENTS] 패널에서 대상 카메라의 점 색상(녹색 여부) 확인<br>② 레시피 스텝에 설정된 카메라 번호와 실제 접속된 카메라 매칭 확인 | NATS 통신 지연 또는 Agent 캡처 실패일 수 있으므로 레시피 [STOP] 후 재시도, 재발 시 운영자 문의 |
| **온도/습도가 0으로 고정됨** | ① 대시보드 상단 HUD의 **PLC 연결 표시등** 상태 확인<br>② 표시등이 빨간색(Disconnected)인지 확인 | PLC 통신 라인 또는 PLC CPU 이상일 수 있으므로 즉시 운영자에게 문의 |
| **레시피가 '챔버 안정화'에서 멈춤** | ① 현재 챔버 실시간 온도가 목표 온도에 정상 도달 중인지 확인<br>② 히터/습도 제어 설비의 물리적 동작 여부 확인 | 챔버 온도 승온이 멈춘 경우 레시피 [STOP] 버튼을 눌러 안전 정지 후 설비 운영자/정비팀에 점검 요청 |
| **셔터/카메라가 반응 없음** | ① [수동 조작] 화면 이동 → 카메라 제어 영역에서 셔터 Open/Close 동작 테스트<br>② 시리얼 통신 포트 상태 확인 | 수동 조작에서도 반응이 없으면 셔터 전원 및 시리얼 통신 선 점검을 위해 운영자 문의 |
| **알람이 계속 발생함** | ① 대시보드 하단 알람 배너 또는 [알람] 탭에서 **[Buzzer Off]** 클릭하여 경보음 차단<br>② 알람 목록 확인 후 **[Reset Error]** 클릭하여 알람 해제 시도 | 동일 알람이 즉시 재발할 경우 알람 코드와 메시지를 기록한 후 운영자에게 점검 요청 |

## 11.2 운영자 문의 시 전달 정보
1차 조치로 문제가 해결되지 않아 운영자에게 문의할 때는 다음 정보를 미리 확인하여 전달하면 빠른 조치가 가능합니다.
1. **발생 시각 및 증상**: 문제가 처음 발생한 시각 및 레시피 진행 단계
2. **알람 코드/메시지**: 화면 하단 배너 또는 알람 탭에 표시된 정확한 에러 문구
3. **대시보드 표시등 상태**: 상단 HUD(PLC 표시등) 및 우측 AGENTS 점 색상(회색/빨강 등)
