# 01-이-매뉴얼에-대하여 — agy 검토 (Round 1)

## 종합 평가
- 수정 필요도: 하
- 한 줄 요약: 매뉴얼의 범위(대상 독자, 포함/제외 내용)와 시스템 기본 구조가 일상 운전자의 눈높이에 맞게 간결하고 명확히 작성되었습니다.

## 수정 필요 항목
1. [1.1 시스템 한눈에 보기 - Master PC] 문제: Master PC의 역할 설명 중 "챔버·서보·흑체를 제어하고"에서 PLC(온도/습도 제어기)와의 연동 개념이 누락되어 이해가 다소 모호함 -> 제안: "챔버 PLC(온도·습도)·서보·흑체 등 하드웨어를 제어하고 촬영을 지시"로 구체화.
2. [1.1 시스템 한눈에 보기 - Agent PC] 문제: Agent PC 설명 중 "카메라 1대를 담당하며"라고만 표기되어 다중 카메라/Bay 구성임을 한눈에 파악하기 부족함 -> 제안: "카메라 PC — 지정된 특정 카메라(Bay)를 담당하며 Master의 촬영 명령을 받아 이미지를 찍어 되돌려 줌"으로 보완.

## 누락/추가 제안
- **[1.2 매뉴얼 표기 규칙] 섹션 추가 제안**: 일상 운전자가 본문 내 화면 요소, 버튼, 경고 문구를 쉽게 식별할 수 있도록 매뉴얼에서 사용하는 표기법(예: `[버튼명]`, `"탭/화면명"`, `⚠️ 주의사항`)에 대한 안내 섹션을 1장의 마지막에 구체적으로 제시하면 후속 챕터 가독성이 향상될 것입니다.

## 이미지 자리 검토
- [그림 1] 전체 시스템 구성: 적절 — Master PC, Agent PC, 챔버 및 통신 연결(NATS)의 전반적인 구도를 운전자에게 직관적으로 제시하므로 위치와 설명이 적절함.
