# 04-설정-파일-레퍼런스 — 검토 종합 (Round 1)

## 판정

수정 필요(중~상). 기본값은 대체로 맞지만, 실제 JSON 키를 축약해 레퍼런스 기능이 부족하고 일부 코드 필드가 누락됐다.

## 합의·다수 수정 (코드 확인됨)

- `Nats`와 `Serial` 세부 필드 및 기본값을 추가한다.
  - `Nats.Url`: `nats://127.0.0.1:4222`
  - `Serial`: `COM3`, `9600`, `8`, `None`, `One`
- `Temp*`, `Eq*`, `Admin*`, `BitJogX±/Y±`를 실제 필드명별로 분리한다.
- PLC 표에 `PulseHoldMs=100`, `CoordinateMoveDelayMs=1000`, `BitErrorReset=P525`, `BitBuzzerOff=P250`을 추가한다.
- BlackBody 표에 `SimulatedRampCelsiusPerSecond=5.0`, `InterMessageDelayMs=50`, `ReadTimeoutMs=1500`과 `Units[]`의 실제 연결 필드를 추가한다.
- `agent.json`에 `LogPath=""`, `CameraModel=null`을 추가한다.
- `AgentId`의 코드 기본값은 머신명이 아니라 빈 문자열(`""`)이다. 런타임에서 머신명이 지정된다면 그 처리 주체를 별도로 설명한다.
- `CameraPairings`, `manager-settings.json`, `state.json`의 구조와 용도를 보완하고, 결합 파일명처럼 보이는 `manager-settings/state.json` 표기를 분리한다.
- 설정 변경 전 종료·백업, JSON 문법, 재시작, `data.db` 직접 편집 금지 안내를 추가한다.
- PLC placeholder 필드는 일반 기본값과 명확히 구분한다.

## AI 지적이 부정확 (코드검증)

- Codex의 `DataRetentionDays`에서 “`0`의 의미가 누락됐다”는 지적은 부정확하다. 현 문서에 이미 `0=정리 안 함`이 명시돼 있다.
- `CameraIndex`가 단순한 라우팅 식별자라는 해석은 부정확하다. `AgentConfig.CameraIndex`는 실제 카메라 선택에도 사용되므로, 장치 인덱스와 라우팅 정합성이라는 두 역할을 함께 설명해야 한다.

## 보류 (설비 안전/도메인 확인 필요)

- `ServoSpeedPercent`, `BitEmergencyStop`, Y축 JOG, `ServoPointYBase`의 실제 PLC 주소.
- `UseHexBitIndex` 변경 절차와 허용 조건.
- BlackBody의 `Enabled`·`Simulated` 조합별 우선순위.
- 온도 허용오차, 스케일 변환 범위, 삭제 대상·주기 등 실제 운전 정책.
- AgentManager 설정·상태 파일의 정확한 배포 경로와 운영 절차.
