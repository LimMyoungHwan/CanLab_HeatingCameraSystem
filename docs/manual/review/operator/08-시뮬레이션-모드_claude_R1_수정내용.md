# 08-시뮬레이션-모드 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 상
- 한 줄 요약: 표·스크립트 목록은 정확하나, 관리자가 실제로 따라 할 전제조건·설정 파일 위치·성공 판정 기준이 빠져 있어 이 상태로는 실행 가이드로 부족함.

## 수정 필요 항목
1. [표 하단, 스크립트 목록] 문제: 3개 스크립트 실행 전 필요한 전제조건(NATS 기동 여부, `docker compose up -d`, .NET SDK, 실행 위치=저장소 루트) 언급이 전혀 없음. `run-manager-e2e.ps1`은 NATS가 이미 떠 있어야 하고, `run-e2e-simulation.ps1`은 문서상 `docker compose -f docs/deployment/docker-compose.yml up -d` 선행이 필요함(실제 스크립트 확인 결과 상이). -> 각 스크립트 앞에 "사전 준비" 항목(NATS 기동 방법, 실행 위치) 추가.
2. [표, 설정 컬럼] 문제: `hardware.json`/`agent.json`이 어디 위치하는지(`%LOCALAPPDATA%\HeatingCameraSystem\`) 안내 없음. 설치·유지보수 관리자가 실제로 값을 바꾸려면 경로가 필수. -> 표 아래에 파일 경로 명시.
3. [스크립트 목록] 문제: 3개 스크립트인데 성공 판정 예시(콘솔 출력)는 `run-e2e-simulation.ps1` 1건만 그림으로 제공. `run-external-simulator-e2e.ps1`, `run-manager-e2e.ps1`은 성공/실패 시 어떤 출력이 나오는지 전혀 없어 관리자가 실패 여부를 판단하기 어려움. -> 각 스크립트별 성공 콘솔 출력 예시(텍스트 또는 그림) 추가.
4. [표, "외부 Simulator" 행] 문제: "Simulator 프로세스"를 어떻게 시작하는지(`docs/deployment/start-external-simulator.ps1`, `simulator.json` 최초 생성 방식) 언급 없어 표만 보고는 실행 불가. -> 외부 Simulator 단독 실행 절차 1~2줄 추가.
5. [표, "운영(실HW)" 행] 문제: 시뮬레이션 검증 후 다시 실HW로 되돌릴 때 기존 운영 설정을 덮어쓰지 않도록 백업/복원해야 한다는 주의사항이 빠짐(다른 배포 문서엔 명시됨). -> "시뮬레이션→운영 복귀 시 hardware.json 백업 후 교체" 경고 문구 추가.

## 누락/추가 제안
- 각 시나리오가 "언제/왜 쓰는지"는 표로 간단히 있으나, 실패 시 어디를 봐야 하는지(로그 위치, 트러블슈팅 챕터 링크) 연결 고리가 없음 — 10-트러블슈팅 챕터로 상호 참조 링크 추가 권장.
- `run-manager-e2e.ps1`의 종료 코드(0 PASS/1 FAIL/2 NATS 연결 실패/3 timeout) 같은 판정 기준이 있다면 표나 본문에 요약해 주면 관리자가 원인 파악에 유용함.
