# 05-PLC-설정-화면 — 검토 종합 (Round 1)

## 판정

수정 필요도 **중**. 실제 화면과 누락된 기능을 맞추고, 설정별 적용 시점과 저장 대상을 구분해야 한다.

## 합의·다수 수정 (코드 확인됨)

- 화면 구성에 **흑체 1·2 목표 온도 입력 및 [적용] 카드**를 추가한다.
- **PLC 연결**과 **흑체 연결 설정**은 `hardware.json`에 저장되며 **프로그램 재시작 후 적용**됨을 명시한다.
- 관리자 설정과 서보 포인트의 **[불러오기]/[저장]은 PLC에서 직접 읽고 쓰는 동작**임을 명시한다.
- 흑체 연결 방식에 따라 Serial은 `COM 포트/Baud Rate`, IP는 `IP 주소/포트` 입력란만 표시됨을 설명한다.
- 하단 상태 표시줄에 저장·적용·불러오기 결과와 미초기화·오류 메시지가 표시됨을 추가한다.
- 화면 명칭에 맞춰 `COM 포트`, `Baud Rate`, `IP 주소`, `포트`로 표기를 정리한다.
- 그림 7에는 목표 온도 카드와 하단 상태 표시줄까지 포함하고, 그림 8·9는 각각 관리자 설정과 20개 서보 포인트를 보여준다.

## AI 지적이 부정확 (코드검증)

- 장 전체에 `현재값 불러오기 → 수정 → 저장 → 확인` 절차를 일괄 적용할 수 없다. 연결 설정은 생성 시 설정 파일에서 로드하고 저장 후 재시작하며, 목표 온도는 별도 불러오기 없이 즉시 컨트롤러에 적용한다.
- PLC IP·포트·국번, 관리자 값, 좌표에 대한 **입력 형식·허용 범위·상호 제약 검증은 View/ViewModel에 구현되어 있지 않다**. 코드 근거 없이 범위를 기재하면 안 된다.
- 연결 설정 저장에는 예외 처리나 별도의 실패 메시지가 구현되어 있지 않으므로, 존재하는 실패 안내 절차처럼 설명하면 안 된다.

## 보류 (설비 안전/도메인 확인 필요)

- 관리자 설정 각 항목의 단위, 허용 범위, 운전 판단 목적과 상호 관계.
- 서보 X/Y 좌표의 단위·유효 범위·충돌 방지 절차.
- `직접 제어 사용`의 현장 활성화 기준과 흑체 연결 상태 확인 방법.
- PLC 주소·좌표 변경 전 운전 정지, 기존값 기록 등 안전 절차. 설비 명세와 운영 규정 확인 후 반영한다.
