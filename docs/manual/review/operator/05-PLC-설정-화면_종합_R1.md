- Claude: 수정 필요도 **중**

## 합의·다수 수정 (코드 확인됨)

- [장 전체] 항목 나열만으로는 작업 흐름이 불명확함 -> 카드별로 `값 확인/불러오기 → 수정 → 저장·적용 → 하단 상태 메시지 확인` 절차를 구분한다.  (근거 AI: Codex, Kimi)
- [화면 구성] 실제 화면은 PLC 연결, 흑체 연결 설정, 흑체 목표 온도, 관리자 설정, 서보 포인트 좌표의 5개 카드와 하단 상태 표시줄로 구성됨 -> 현재 본문의 5개 카드 및 상태 표시줄 설명을 유지하고 그림 7에도 모두 포함한다.  (근거 AI: Claude, agy)
- [PLC 연결] IP 주소·포트·국번 저장의 적용 시점이 중요함 -> `[저장]`은 `%LOCALAPPDATA%\HeatingCameraSystem\hardware.json`에 기록하며, 상태 메시지와 같이 **프로그램 재시작 후 적용**된다고 명시한다. 기본 포트는 LS XGT FEnet용 TCP 2004이다.  (근거 AI: Codex, Claude, agy, Kimi)
- [흑체 연결 설정] Serial/IP 선택에 따른 입력 항목이 불명확함 -> Serial 선택 시 `COM 포트·Baud Rate`, IP 선택 시 `IP 주소·포트` 입력란만 표시되며 흑체 1·2를 각각 설정한다고 설명한다.  (근거 AI: Codex, Claude)
- [흑체 연결 설정] 저장 적용 시점 누락 -> `[저장]`은 `hardware.json`에 기록되고 **프로그램 재시작 후 적용**된다고 명시한다.  (근거 AI: Claude, agy, Kimi)
- [흑체 목표 온도] 독립 카드 설명이 누락되기 쉬움 -> 흑체 1·2 목표 온도(℃)를 입력하고 각 `[적용]`을 누르면 흑체 컨트롤러에 즉시 전달된다고 명시한다.  (근거 AI: Claude, agy)
- [관리자 설정] 불러오기·저장의 대상이 모호함 -> `[불러오기]`는 `ReadStatusAsync()`로 PLC 현재 관리자 값을 읽어 화면 입력값을 덮어쓰고, `[저장]`은 8개 값을 PLC 워드에 즉시 기록한다고 명시한다. 설정 파일 저장이 아니다.  (근거 AI: Codex, Claude, agy)
- [서보 포인트 좌표] 불러오기·저장의 대상과 단위가 불명확함 -> 포인트는 1~20번이며, `[불러오기]`는 PLC 좌표 워드를 읽고 `[저장]`은 20개 X/Y 값을 PLC에 즉시 기록한다고 설명한다. 외부 표시 단위는 mm이고 PLC에는 0.1 mm 단위 정수로 변환된다.  (근거 AI: Codex, Claude, agy, Kimi)
- [하단 상태 표시줄] 결과 확인 위치 누락 -> 저장·적용·불러오기 성공, `PLC 미초기화`, 컨트롤러 미초기화 및 오류 메시지가 표시된다고 설명한다.  (근거 AI: Codex, agy)
- [문서 구조] 화면 설명과 작업 절차가 혼재함 -> `화면 구성`, 카드별 `설정 절차`, `적용 시점`, `주의사항`으로 짧게 구분한다.  (근거 AI: Codex, Kimi)

## AI 지적이 부정확 (코드검증)

- Kimi의 “직접 제어 사용을 해제하면 레시피/자동 모드에서 제어된다”는 설명은 코드 근거가 없다. `BlackBodySettings.Enabled`는 설계상 PLC 경유 대신 SR-800N 직접 제어를 선택하는 설정이며, 수동/자동 운전 모드를 전환하는 옵션이 아니다.
- Kimi가 제안한 PLC `연결 테스트`·`재연결` 버튼은 해당 화면에 없다. PLC 연결 카드에는 `[저장]`만 있으며 저장 시 즉시 재연결하지 않는다.
- Kimi가 제안한 서보 `이동 테스트` 버튼은 해당 화면에 없다. 이 화면은 좌표 불러오기와 저장만 제공한다.
- Kimi의 “PLC IP 변경 시 즉시 재연결” 예시는 현재 코드와 반대다. 변경값은 재시작 후 새 `PlcXgtClient` 생성과 초기 연결 과정에서 적용된다.
- Kimi의 “COM 포트 변경 시 Agent 재시작” 설명은 이 화면의 대상과 다르다. 이 화면은 Master의 흑체 연결 설정을 저장하므로 Master 프로그램 재시작이 필요하다.
- Kimi가 언급한 설정 백업·복원, 기본값 초기화 기능은 이 화면에 존재하지 않는다.
- Kimi의 “포인트와 레시피 스텝/캡처 위치 매핑”은 이 화면의 코드로 확인되지 않는다. `RecipeStep.CameraIndex`는 카메라 Agent 매핑이며 서보 포인트 번호와 동일 개념이 아니다.

## 보류 (설비 안전/도메인 확인 필요)

- PLC IP·국번의 현장 적용값과 변경 전 운전 정지 절차
- 과열 상한, 냉동기·바이패스·페어글라스 경계, MFC 최소·최대 출력의 허용 범위와 상호 제약
- 관리자 설정 각 항목의 실제 설비 제어 의미와 영향
- 서보 X/Y 좌표의 현장 유효 범위, 충돌 방지 절차 및 저장 후 검증 방법
- 검증된 PLC 디바이스 주소와 서보 좌표 원점·가동 한계
- 흑체 장비별 실제 COM/IP 통신값과 연결 확인 절차
