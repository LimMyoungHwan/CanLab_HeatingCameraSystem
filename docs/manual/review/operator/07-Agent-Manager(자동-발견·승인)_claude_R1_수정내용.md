# 07-Agent-Manager(자동-발견·승인) — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 전반적 흐름은 명확하나 "Agent 설정 화면" 표현의 주체 혼동, 거부 버튼 동작의 상태별 차이 미설명, 설치 절차의 로그온 계정 설정 누락이 보완 필요.

## 수정 필요 항목
1. [7.3, 2번 항목·그림10 캡션] 문제: 이 문서는 "Agent Manager"(운영자 콘솔) 앱을 다루는데, "Agent 설정 화면의 디바이스 관리 탭"이라고 표기해 마치 Agent 자체의 설정 화면인 것처럼 읽힘. -> 제안: "Manager 설정 화면의 디바이스 관리 탭" 또는 "Agent Manager 콘솔의 디바이스 관리 탭"으로 통일.
2. [7.3, 버튼 표 — 거부] 문제: 미승인 상태(아직 Agent 미기동)에서 '거부'를 눌러도 "Agent 프로세스 종료"라고 되어 있어, 종료할 프로세스가 없는 경우와 모순되어 보임. -> 제안: "이미 승인/기동된 카메라에는 프로세스 종료도 함께 수행, 미승인 상태에서는 목록에서 제외" 식으로 상태별 동작 구분 서술.
3. [7.1 설치] 문제: 서두에서 "로그온 예약작업(HCS-Manager)"라 언급했으나 설치 스크립트에 로그온 계정/자격 증명 설정 단계가 없음. -> 제안: install-manager-task.ps1 실행 시 로그온 계정 지정 여부(또는 기본값) 한 줄 안내 추가.
4. [7.2 설정 파일 표] 문제: manager-state.json/manager-settings.json의 실제 파일 경로(예: InstallRoot 하위 경로)가 명시되지 않아 유지보수자가 위치를 특정하기 어려움. -> 제안: 표 또는 각주에 기본 경로 예시 추가.

## 누락/추가 제안
- 카메라 하드웨어를 다른 USB 포트/PC로 옮기거나 교체했을 때 HardwareId 매칭·재승인 필요 여부에 대한 안내 없음 — 유지보수 시 자주 발생할 상황이므로 짧은 안내 추가 권장.
- "대시보드에 초록 점" 언급되나 대시보드 화면을 여는 방법/위치에 대한 설명(또는 다른 장 참조)이 없음 — 상호 참조 링크 추가 권장.
- 지수 백오프·영구 드롭 [참고] 박스가 5단계 절차/버튼 표 뒤에 분리되어 있어 흐름상 다소 늦게 등장 — 4번 단계("Agent 기동") 인근으로 이동하면 이해에 더 도움.

## 이미지 자리 검토
- [그림 10] 적절 — 미승인 카메라가 있는 상태의 디바이스 관리 탭 캡처는 절차 이해에 유용함. 다만 캡션의 "Agent 설정 화면" 표현은 위 1번 지적과 함께 수정 필요.
