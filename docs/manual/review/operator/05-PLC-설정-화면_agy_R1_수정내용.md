## 수정 필요 항목
1. `[개요 불릿 2번째]` **흑체 설정과 목표 온도 제어 카드 분리 필요**: 매뉴얼에는 흑체 연결 설정에 목표 온도 제어가 모호하게 축약되어 있으나, 실제 UI에는 '흑체 연결 설정' 카드와 '챔버 흑체 목표 온도 제어' 카드가 독립되어 있습니다.
   -> **제안**: 흑체 연결 설정(직접 제어 사용 여부, 흑체 1/2 방식(Serial/IP))과 챔버 흑체 목표 온도 제어(각 흑체 목표 온도 지정 및 [적용])를 명확히 구분하여 기술할 것.
2. `[개요 PLC/흑체 연결 저장]` **재시작 필요 안내 누락**: PLC 연결 및 흑체 연결 설정 [저장] 시 즉시 PLC/흑체 통신이 재연결되는 것이 아니라 `hardware.json` 설정에 저장되며 '프로그램 재시작 후 적용'됩니다.
   -> **제안**: 설정 저장 후 프로그램 재시작이 필요하다는 유의사항(Warning/Note)을 추가할 것.
3. `[개요 관리자 설정 및 서보 포인트 좌표]` **불러오기/저장 동작 메커니즘 설명 구체화**: 관리자 설정과 서보 포인트 좌표의 [불러오기]/[저장] 버튼은 설정 파일이 아닌 PLC 장비 메모리에서 직접 데이터를 읽고 쓰는 동작입니다.
   -> **제안**: PLC 메모리 직접 읽기/쓰기 동작임을 명시하여 일반 설정 파일 저장과의 차이를 분명히 할 것.

## (선택) 수정 제안 전문

# 5. PLC 설정 화면

설치·설정·유지보수 관리자가 PLC 통신, 흑체 연결/목표 온도, 한계값(관리자 설정), 서보 포인트 좌표를 조회하고 조정하는 화면이다.

> 📷 **[그림 7] PLC 설정 화면 전체**
> - **캡처 대상:** PLC 설정 화면 전체(PLC 연결, 흑체 연결, 챔버 흑체 목표 온도, 관리자 설정, 서보 포인트 좌표 카드 및 하단 상태 표시줄)
> - **화면/상태:** 값이 정상 로드된 상태
> - **표시 영역:** 창 전체

### 주요 기능 및 카드리스트

- **PLC 연결 카드**: PLC IP 주소, 포트(기본 2004), 국번(Station No)을 입력하고 **[저장]**한다.
  > ⚠️ **주의:** PLC 연결 설정 저장 시 하드웨어 설정 파일에 기록되며, 변경 사항은 **프로그램 재시작 후 적용**된다.
- **흑체 연결 설정 카드**: '직접 제어 사용' 여부를 체크하고, 흑체 1/2의 연결 방식(Serial: COM 포트/Baud Rate, IP: IP 주소/포트)을 선택 후 **[저장]**한다.
  > ⚠️ **주의:** 흑체 연결 설정 변경 역시 **프로그램 재시작 후 적용**된다.
- **챔버 흑체 목표 온도 제어 카드**: 흑체 1 및 흑체 2의 목표 온도를 입력하고 **[적용]** 버튼을 눌러 흑체 컨트롤러에 목표 온도를 설정한다.
- **관리자 설정 카드**: 과열 상한, 상온/2차 냉동기 경계, 냉동기 딜레이(분), 바이패스 경계, MFC 최소/최대 출력, 페어글라스 경계 값을 PLC 장비 메모리로부터 **[불러오기]**하거나 수정 후 **[저장]**한다.

> 📷 **[그림 8] PLC 설정 — 관리자 설정 카드**
> - **캡처 대상:** 관리자 설정 카드(과열 상한 등 한계값 입력)
> - **화면/상태:** 값이 입력된 상태
> - **표시 영역:** 창 가운데

- **서보 포인트 좌표(20) 카드**: 1번부터 20번까지의 서보 X/Y 포인트 좌표 목록을 PLC로부터 **[불러오기]**하거나 수정 후 PLC 메모리에 **[저장]**한다.

> 📷 **[그림 9] PLC 설정 — 서보 포인트 좌표**
> - **캡처 대상:** 서보 포인트 좌표(20) 카드
> - **화면/상태:** 20개 포인트 좌표가 채워진 상태
> - **표시 영역:** 창 오른쪽

- **하단 상태 표시줄**: 화면 하단에 PLC/흑체 연결 저장 상태, 불러오기/저장 성공 메시지 또는 오류(예: 'PLC 미초기화') 상태가 표시된다.
