# 05-PLC-설정-화면 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 상
- 한 줄 요약: 화면 구성은 요약되어 있으나, 설치·설정·유지보수 관리자가 실제로 설정하고 검증할 수 있는 절차와 주의사항이 부족하다.

## 수정 필요 항목
1. [장 전체] 문제: 화면 항목을 나열할 뿐 설정 순서, 저장 방법, 성공 여부 확인 절차가 없다. -> 제안: `현재값 불러오기 → 값 수정 → 저장 → 연결 또는 동작 상태 확인` 순서로 작업 절차를 작성한다.
2. [PLC 연결] 문제: IP 주소·포트·국번의 형식과 저장 후 연결 확인 방법이 설명되지 않았다. -> 제안: 각 필드의 입력 형식과 기본 또는 현장 적용값의 확인처, 저장 결과 및 연결 상태 확인 위치를 명시한다.
3. [PLC 연결] 문제: PLC 설정 변경이 설비 동작에 미칠 수 있다는 경고가 없다. -> 제안: 변경 전 운전을 정지하고 기존 값을 기록하며, 검증되지 않은 주소나 값을 임의로 입력하지 말라는 경고를 추가한다.
4. [흑체 연결 설정] 문제: `직접 제어 사용`의 의미와 Serial/IP 선택 기준이 불명확하다. -> 제안: 직접 제어를 활성화하는 조건, 흑체별 연결 방식 선택 방법, 방식별 필수 입력값을 구분해 설명한다.
5. [흑체 연결 설정] 문제: `COM/Baud`, `주소/포트`처럼 한글과 영문 표현이 혼용되고 각 값의 역할이 설명되지 않았다. -> 제안: 화면 표시명과 동일한 명칭을 사용하고, 예를 들어 `COM 포트`, `통신 속도(Baud rate)`, `IP 주소`, `포트`로 통일한다.
6. [관리자 설정] 문제: 과열 상한, 경계, 딜레이, 출력값의 단위·허용 범위·상호 관계가 없다. -> 제안: 화면에 표시되는 단위와 허용 범위를 항목별 표로 정리하고, 최소값이 최대값보다 클 수 없는 등의 제약이 있다면 함께 명시한다.
7. [관리자 설정] 문제: `상온/2차 냉동기 경계`, `바이패스 경계`, `페어글라스 경계`가 어떤 운전 판단에 사용되는지 알기 어렵다. -> 제안: 각 값의 적용 목적과 값 변경 시 영향을 한 문장씩 설명한다.
8. [관리자 설정/서보 포인트 좌표] 문제: `불러오기`가 PLC 현재값, 저장된 설정값 또는 초기값 중 무엇을 읽는지 불명확하다. -> 제안: 불러오기 대상과 수정 중인 값이 덮어써지는지 명시한다.
9. [서보 포인트 좌표(20)] 문제: 포인트 번호 범위, X/Y 좌표 단위, 유효 범위와 실제 이동 전 검증 방법이 없다. -> 제안: 포인트 번호와 좌표 단위·범위를 명시하고, 저장 전 축 이동 범위 및 충돌 가능성을 확인하도록 경고한다.
10. [장 전체] 문제: PLC 연결 설정, 흑체 설정, 관리자 설정, 서보 좌표가 한 목록에 압축되어 있어 화면 설명과 작업 절차를 구분하기 어렵다. -> 제안: `화면 구성`, `설정 절차`, `항목 설명`, `주의사항`, `저장 후 확인`으로 절을 나눈다.

## 누락/추가 제안
- 변경 전 기존 설정값을 기록하거나 화면을 캡처하는 절차를 추가한다.
- 저장 성공·실패 메시지와 실패 시 확인할 항목을 설명한다.
- 설정이 즉시 적용되는지, 재연결 또는 프로그램 재시작이 필요한지 확인하여 명시한다.
- 현장 PLC 주소 및 서보 좌표는 검증된 설비 명세를 기준으로 입력해야 한다는 주의문을 추가한다.
- 흑체 1·2 각각에 대해 연결 상태를 확인하는 방법이 있다면 절차에 포함한다.
- 여러 저장 버튼이 각 카드에 독립적으로 적용되는지 명확히 설명한다.

## 이미지 자리 검토
- [그림 7] 적절 — 전체 화면의 카드 배치와 설정 영역을 파악하는 데 유용하다. 다만 각 카드와 저장 버튼이 식별되도록 번호 또는 강조 표시를 추가하는 것이 좋다.
- [그림 8] 적절 — 관리자 설정의 입력 필드와 단위를 확인하는 데 필요하다. 실제 운영값이나 민감한 현장값 대신 예시값을 사용하고, 주요 필드를 표시해야 한다.
- [그림 9] 적절 — 20개 포인트의 배열, X/Y 입력란, 불러오기·저장 버튼을 설명하는 데 유용하다. 좌표 단위와 포인트 번호가 보이도록 캡처 범위를 지정해야 한다.
