# 05-PLC-설정-화면 — claude 검토 (Round 1)

## 종합 평가
- 수정 필요도: 중
- 한 줄 요약: 실제 화면에 있는 카드 하나(흑체1/2 목표 온도 적용)가 챕터에서 통째로 빠졌고, 저장 후 재시작이 필요한 항목에 대한 경고가 없다.

## 수정 필요 항목
1. [본문 목록] 문제: 화면에는 "PLC 연결 / 흑체 연결 설정 / 챔버 온습도·흑체(목표 온도) / 관리자 설정 / 서보 포인트 좌표" 5개 카드가 있는데(`PlcControlSettingsView.xaml`), 챕터 본문 목록에는 4개만 기술되어 있고 흑체1·흑체2 목표 온도 입력 + 적용 버튼(`ApplyBlackBody1Command`/`ApplyBlackBody2Command`, loc키 `Plc_ChamberBbTitle`, "챔버 온습도 / 흑체")이 빠져 있음. -> 목록에 5번째 항목으로 "흑체 목표 온도: 흑체1/2 목표 온도(℃) 입력 → 적용" 추가.
2. [PLC 연결 / 흑체 연결 설정 항목] 문제: `SavePlcConnection`, `SaveBlackBodyConnection` 커맨드는 저장 후 상태 메시지로 "재시작 후 적용"을 명시하는데(코드상 확인), 챕터에는 이 재시작 필요 여부가 전혀 언급되지 않음. 관리자 설정·서보 포인트는 즉시 적용(재시작 불필요)이라 차이가 있어 사용자가 혼동할 수 있음. -> "PLC 연결·흑체 연결 설정은 저장 후 프로그램 재시작이 필요하다"는 경고문 추가.

## 누락/추가 제안
- 흑체 연결 방식이 IP일 때와 Serial일 때 입력 필드가 토글되는 UI 동작(선택한 방식에 따라 COM/Baud 또는 IP/포트 필드만 표시)에 대한 설명 한 줄 추가 권장.
- 서보 포인트 좌표(20)의 "불러오기"가 PLC에서 실시간으로 읽어오는 동작이고, "저장"이 즉시 PLC에 쓰는 동작임을(설정 파일 저장이 아님) 한 줄로 명확히 하면 좋음.

## 이미지 자리 검토
- [그림 7] 적절 — 화면 전체 구성 파악에 필요.
- [그림 8] 적절하나 범위 재확인 필요 — "관리자 설정 카드"만 캡처하는데, 흑체 연결 설정 카드와 흑체 목표 온도 카드는 어떤 그림에도 포함되지 않음. 두 카드에 대한 그림이 없다면 [그림 7] 전체 캡처로 대체 설명하거나, 별도 그림(예: [그림 7-1] 흑체 연결/목표 온도 카드)을 추가 검토.
- [그림 9] 적절 — 서보 포인트 좌표 입력 형태 확인에 필요.
