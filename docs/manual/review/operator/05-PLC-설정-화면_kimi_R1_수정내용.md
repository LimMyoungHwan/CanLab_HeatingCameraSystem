• # 05-PLC-설정-화면 — Kimi 검토 (Round 1)

  ## 종합 평가
  - 수정 필요도: 상
  - 한 줄 요약: 화면을 구성하는 4개 영역을 한 줄씩 나열한 수준으로, 설치·설정·유지보수 관리자가 실제 값을 입력·저장·검증하는 절차, 단위, 주의사항, 연동 동작 등 실무에 필요한 내용이 대부분 누락되어 있다.

  ## 수정 필요 항목
  1. [전체 구조] 문제: H1 아래 4개 항목을 bullet 한 줄로만 나열하고 각 영역별 상세 절차가 없음. -> 제안: "PLC 연결 설정", "흑체 연결 설정", "관리자 설정", "서보 포인트 좌표 설정"으로 H2를 분리하고, 각 섹션에 진입 방법 → 값 입력 → 저장/적용 → 확인 순서의 절차를 추가.
  2. [PLC 연결] 문제: "IP 주소·포트·국번(Station) → 저장"만 있어 연결 테스트, 재연결, 변경 시 주의사항이 없음. -> 제안: 저장 시 즉시 연결 재시도되는지 여부, 연결 상태 표시 위치, LS XGT FEnet(TCP 2004) 프로토콜임을 명시. IP/국번 변경 중 통신 끊김 주의를 추가.
  3. [흑체 연결] 문제: "직접 제어 사용 체크"의 의미와 체크/해제 시 동작 차이가 설명되지 않음. -> 제안: 체크하면 운영자가 UI에서 흑체를 수동 개폐/온도 제어할 수 있고, 해제하면 레시피/자동 모드에서 제어된다는 점을 명시.
  4. [동작 일관성] 문제: "불러오기/저장"이 관리자 설정과 서보 포인트에만 있고 PLC·흑체 연결에는 없어 영역별 버튼 구성이 불분명함. -> 제안: 각 영역별로 사용 가능한 버튼(저장, 불러오기, 적용, 연결 테스트 등)을 명시하거나, 통일된 동작이 아님을 설명.
  5. [용어/단위] 문제: "과열 상한", "상온/2차 냉동기 경계", "바이패스 경계", "MFC 최소/최대 출력", "페어글라스 경계" 등 필드의 단위와 의미, 허용 범위가 없음. -> 제안: 각 필드의 단위(°C, % 등)와 기본값, 입력 가능 범위를 표로 정리.
  6. [서보 포인트 좌표] 문제: "포인트별 X/Y"만 있어 좌표계, 단위, 홈 위치, 이동 테스트, 레시피 매핑 관계가 누락됨. -> 제안: 좌표 단위(mm/pulse), 홈 위치 기준, 입력 후 "이동 테스트" 버튼 사용 절차, 포인트 번호와 레시피 스텝/캡처 위치의 매핑 관계를 추가.

  ## 누락/추가 제안
  - 화면 진입 경로(메뉴 이름·버튼)와 필요한 권한(관리자) 안내.
  - 저장 전 유효성 검사 및 저장 실패 시 오류 메시지 예시.
  - 설정 변경 후 재시작·재연결이 필요한 항목 구분(예: PLC IP 변경 시 즉시 재연결, COM 포트 변경 시 Agent 재시작 등).
  - 통신 실패 시 점검 항목(방화벽, 케이블, 국번, COM 포트 번호, Baud rate).
  - UI에서 수정한 값이 `%LOCALAPPDATA%\HeatingCameraSystem\hardware.json`에 반영되는지 여부 설명.
  - 설정 백업·복원(내보내기·불러오기) 기능이 있다면 절차 추가.
  - 기본값 초기화(공장 초기화) 버튼이 있는 경우 경고와 함께 절차 추가.

  ## 이미지 자리 검토
  - [그림 7] 적절 — 연결/흑체/관리자/포인트 카드가 한 화면에 배치된 전체 모습을 보여주기 위해 필요함. 본문에 각 카드의 화면 위치(왼쪽/가운데/오른쪽)를 함께 설명하면 더 유용함.
  - [그림 8] 적절 — 관리자 설정 카드는 필드 수가 많고 단위/범위 설명이 필요한 영역이라 확대 캡처가 필요함.
  - [그림 9] 적절 — 20개 포인트의 X/Y 좌표 테이블은 한 화면에 셀이 많아 별도 캡처가 필요함. 포인트 번호 열과 X/Y 레이블이 모두 보이도록 요구할 것.
