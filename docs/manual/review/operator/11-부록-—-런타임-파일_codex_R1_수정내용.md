# 11-부록—런타임 파일 — codex 검토 (Round 1)

## 종합 평가
- 수정 필요도: 높음
- 핵심 요약: 파일 위치를 한눈에 볼 수 있다는 장점은 있으나, 경로 표기와 파일 역할이 불명확하고 백업·복구·직접 편집 시 주의사항이 없어 설치·설정·유지보수 관리자가 안전하게 활용하기 어렵다.

## 수정 필요 항목
1. [표 전체] 문제: 각 파일의 생성 주체, 생성 시점, 편집 가능 여부가 없다. → 제안: `생성 주체`, `편집 방법`, `적용 시점` 열을 추가하고, 설정 변경 후 재시작이 필요한 파일을 명시한다.
2. [hardware.json] 문제: “Master 설정”만으로는 PLC·시리얼 등 어떤 설정을 포함하는지 알 수 없다. → 제안: “Master의 PLC·시리얼 하드웨어 연결 설정”처럼 범위를 구체화한다.
3. [data.db] 문제: “LiteDB 이력”이라는 설명만으로 저장 데이터와 취급 방법을 판단하기 어렵다. → 제안: 실제 저장 항목을 명시하고, 프로그램 실행 중 직접 편집·교체하지 말라는 경고를 추가한다.
4. [recipe\*.json] 문제: “레시피” 외에 파일 생성·수정 방법과 실제 사용 조건이 제시되지 않았다. 또한 `data.db`와의 저장 역할 구분도 불명확하다. → 제안: 레시피가 JSON 파일에 저장되는지 LiteDB에 저장되는지 확인한 뒤 실제 구현과 일치하도록 수정하고, 중복 저장처럼 보이는 설명을 해소한다.
5. [agent.json] 문제: “Agent 설정”만으로 필수 항목과 Master의 카메라 매핑 조건을 알 수 없다. → 제안: `AgentId`, `CameraIndex`, NATS 주소, `StoragePath` 등 주요 항목을 설명하고 `Agent_{CameraIndex}` 매핑 규칙을 안내한다.
6. [캡처 이미지] 문제: “Agent StoragePath / Master ImageCache”는 설정값과 실제 경로가 혼재되어 있으며 기본 경로가 제시되지 않았다. → 제안: Agent 원본 저장 경로와 Master 캐시 경로를 별도 행으로 분리하고 각각의 기본값, 변경 방법, 삭제 영향을 명시한다.
7. [manager-settings/state.json] 문제: 파일명인지 디렉터리 구조인지 모호하고, 설정과 상태가 한 파일인지 두 파일인지 구분되지 않는다. → 제안: 실제 파일별 전체 경로를 각각 제시하고, 운영자가 편집 가능한 설정 파일과 자동 관리되는 상태 파일을 분리한다.
8. [Agent 로그] 문제: “7일 보관”의 삭제 방식과 로그 파일명 규칙이 없어 장애 조사 및 백업 기준을 세우기 어렵다. → 제안: 일별 파일명, NDJSON 형식, 자동 삭제 시점, 보관 기간 변경 가능 여부를 명시한다.
9. [경로 표기] 문제: `%LOCALAPPDATA%`, `Agent exe 폴더`, `StoragePath`처럼 서로 다른 기준이 설명 없이 사용된다. → 제안: 환경 변수와 상대 경로의 의미를 먼저 설명하고 실제 경로 확인 예시를 제공한다.
10. [표 전체] 문제: Windows 경로와 와일드카드가 일반 문장처럼 표시되어 가독성이 떨어진다. → 제안: 모든 경로와 파일명을 코드 형식으로 표기한다.

## 누락/추가 제안
- 설정 파일이 없을 때 기본값으로 자동 생성되는지와 최초 생성 시점을 명시한다.
- `hardware.json`과 `agent.json` 변경 후 프로그램 재시작이 필요하다는 안내를 추가한다.
- 백업 전 Master, Agent, AgentManager를 종료해야 하는 파일과 실행 중에도 복사 가능한 파일을 구분한다.
- 복구 절차를 추가한다. 최소한 종료, 기존 파일 별도 보관, 백업본 복사, 재실행, 연결 및 설정 확인 순서를 안내해야 한다.
- `data.db` 손상이나 설정 오류에 대비해 파일을 덮어쓰기 전에 원본을 보관하도록 경고한다.
- 로그, 이미지, 데이터베이스의 예상 용량 증가와 디스크 여유 공간 점검 방법을 안내한다.
- 캡처 이미지나 로그를 삭제했을 때 Master 화면 또는 이력 조회에 미치는 영향을 명시한다.
- 권한 문제를 예방하도록 `C:\HeatingCameraSystem\` 경로의 쓰기 권한 요구사항을 설명한다.
- 실제 운영 환경에 따라 달라지는 경로는 “기본 경로”와 “설정에 따른 변경 경로”로 구분한다.
- 파일별 민감 정보 포함 여부와 외부 반출 시 주의사항을 추가한다.

## 이미지 자리 검토
- 그림 블록 없음. 이 장은 경로 중심의 참조표이므로 이미지가 반드시 필요하지는 않다. 다만 `%LOCALAPPDATA%\HeatingCameraSystem\` 폴더와 Agent 실행 폴더를 찾는 과정이 익숙하지 않은 관리자를 위해 Windows 탐색기 주소창에 경로를 입력한 예시 화면을 추가하면 유용하다.
