# 01-이-매뉴얼에-대하여 — 검토 종합 (Round 1)

## 판정

수정 필요(중). 핵심 사실은 맞지만 참조 링크, 설정 파일 명칭, 내부 개발 표기를 바로잡아야 한다.

## 합의·다수 수정 (코드 확인됨)

- `[사용자 매뉴얼]`을 실제 문서 `../user-manual/INDEX.md` 링크로 변경한다.
- `설정 파일(hardware.json/agent.json/manager)`을 `hardware.json, agent.json, manager-settings.json, manager-state.json`으로 명확히 표기한다.
- `소스 주석의 ponytail 표시` 안내를 삭제한다. 운영자는 4장 PLC 필드 표와 실제 A&D PLC 명세를 기준으로 주소를 확인하도록 안내한다.
- PLC 임시값 경고는 유지한다. 코드에서 `ServoSpeedPercent(D2560)`, `BitEmergencyStop(M2000)`, Y축 조그 `(P725/P726)`, `ServoPointYBase(D3012)`가 미확정 값으로 확인된다.
- 소개 장에는 이미지가 필요하지 않다.

## AI 지적이 부정확 (코드검증)

- `hardware.json 내 주석을 확인`하라는 대체 문구는 부정확하다. `hardware.json`은 `System.Text.Json`으로 생성되는 일반 JSON 파일로 소스 주석이 포함되지 않는다.
- `manager-settings/state.json`을 하나의 파일처럼 쓰면 안 된다. 실제 파일은 `manager-settings.json`과 `manager-state.json` 두 개다.

## 보류 (설비 안전/도메인 확인 필요)

- `전원 차단 → 주소 변경 → 시뮬레이션/수동 점검` 절차는 코드로 검증할 수 없는 설비 안전 절차이므로 임의 추가하지 않는다. 실제 PLC·챔버 안전 규정과 현장 담당자 확인 후 관련 장에 반영한다.
