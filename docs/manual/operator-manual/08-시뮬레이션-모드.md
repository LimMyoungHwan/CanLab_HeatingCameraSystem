# 8. 시뮬레이션 모드

시뮬레이션 모드는 다음 두 설정 파일에서 지정합니다.

- `hardware.json`: `%LOCALAPPDATA%\HeatingCameraSystem\`
- `agent.json`: Agent 실행 파일 폴더

`hardware.json`은 Master 시작 시, `agent.json`은 Agent 시작 시 읽습니다. 설정을 변경한 뒤 해당 프로세스를 재시작하십시오.

| 시나리오 | `hardware.json` | `agent.json` | 용도 |
| --- | --- | --- | --- |
| 운영(실HW) | `SimulationMode=false` | `SimulationMode=false` | 실제 PLC/셔터/카메라 |
| 전체 시뮬 | `SimulationMode=true` | `SimulationMode=true` | 하드웨어 없이 전체 흐름 |
| 외부 Simulator | `SimulationMode=false`로 설정하고 PLC 주소를 Simulator로 지정 | 사용 시나리오에 맞게 설정 | XGT FEnet과 NATS 카메라 경계 검증 |
| 하이브리드 | `SimulationMode=true` | `SimulationMode=false` | PLC 없이 실카메라 캡처 확인 |

Master의 `SimulationMode=true`는 PLC·셔터·카메라/페어링·흑체를 Fake 구현으로 전환합니다. Agent의 `SimulationMode=true`는 카메라·셔터를 Fake 구현으로 전환합니다. NATS 서버는 시뮬레이션되지 않으므로 별도로 실행해야 합니다.

## 외부 Simulator

외부 Simulator는 Master 내부 시뮬레이션을 끄고 PLC 주소를 Simulator로 지정하여 XGT FEnet과 NATS 카메라 경계를 검증합니다. 저장소 루트에서 다음 명령을 실행합니다.

```
./docs/deployment/start-external-simulator.ps1
```

기본 설정 파일은 `HeatingCameraSystem.Simulator\simulator.json`입니다. 파일이 없으면 `simulator.example.json`을 복사하여 자동 생성합니다. 다른 설정 파일을 사용하려면 다음과 같이 지정합니다.

```
./docs/deployment/start-external-simulator.ps1 -ConfigPath <설정 파일 경로>
```

실행 중 사용할 수 있는 명령은 다음과 같습니다.

| 명령 | 용도 |
| --- | --- |
| `status` | PLC와 카메라 상태 확인 |
| `plc online` | PLC 온라인 전환 |
| `plc offline` | PLC 오프라인 전환 |
| `plc fault <0-19> on` | 지정한 PLC 오류 활성화 |
| `plc fault <0-19> off` | 지정한 PLC 오류 해제 |
| `camera <AgentId> online` | 카메라 온라인 전환 |
| `camera <AgentId> fault` | 카메라 오류 전환 |
| `camera <AgentId> offline` | 카메라 오프라인 전환 |
| `quit` | Simulator 종료 |

## E2E 스크립트

.NET 8 SDK와 `nats://127.0.0.1:4222`에서 접근 가능한 NATS 서버가 필요합니다. 다음 명령은 저장소 루트에서 실행합니다.

### 내부 Fake E2E

```
./docs/deployment/run-e2e-simulation.ps1
```

시뮬레이션 Agent 2대와 내부 Fake PLC를 사용하여 4단계 레시피를 실행하고, 캡처 결과 4건과 JPEG 파일 4건을 검증합니다. 별도 옵션은 없습니다.

### 외부 Simulator E2E

```
./docs/deployment/run-external-simulator-e2e.ps1
```

외부 Simulator를 기동하여 XGT FEnet PLC 통신과 NATS 카메라 캡처 경계를 검증합니다.

| 옵션 | 기본값 | 용도 |
| --- | --- | --- |
| `-NatsUrl` | `nats://127.0.0.1:4222` | NATS 서버 주소 |
| `-FEnetPort` | `2004` | FEnet 수신 포트 |
| `-ConfigPath` | `HeatingCameraSystem.Simulator\simulator.json` | Simulator 설정 파일 |
| `-StartNatsDocker` | 미지정 | NATS에 연결할 수 없을 때 Docker Compose로 NATS 기동 |

### Manager 승인 루프 E2E

```
./docs/deployment/run-manager-e2e.ps1
```

Fake 카메라 2대의 발견·승인·AgentId 부여·상태 저장과 런타임 로드·하트비트·개별 비활성화 동작을 검증합니다. 별도 옵션은 없습니다.

각 E2E의 정상 판정 기준은 실행되는 드라이버 콘솔의 `*** PASS ***` 출력과 프로세스 종료 코드 `0`입니다. Manager E2E의 다른 종료 코드는 `1=FAIL`, `2=NATS 연결 실패`, `3=timeout`입니다.

그림 11을 캡처할 때는 실행한 스크립트명, `*** PASS ***`, 캡처 수량과 검증 범위가 함께 보이도록 합니다.

> - **캡처 대상:** E2E 러너 실행 후 '*** PASS ***' 출력 콘솔
> - **화면/상태:** run-e2e-simulation.ps1 통과 화면

## 시험 전후 설정

시험 전에 `hardware.json`과 `agent.json`을 백업합니다. 시험이 끝나면 백업한 운영값과 PLC/NATS 주소를 복원하고, 변경한 파일을 읽는 Master와 Agent를 재시작합니다.

실행 또는 연결 문제가 발생하면 [10. 트러블슈팅](10-트러블슈팅.md)을 참조하십시오.
