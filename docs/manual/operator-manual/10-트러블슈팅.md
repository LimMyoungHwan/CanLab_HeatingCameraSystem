# 10. 트러블슈팅

설정 변경 전 관련 설정 파일을 백업하십시오. 자동 운전 중에는 설정을 변경하지 말고, 먼저 운전자가 **STOP**으로 자동 운전을 중지한 뒤 하드웨어가 안전한 상태인지 확인하십시오.

점검은 **통신 → 설정 → 장치 점유 → 로그** 순서로 진행하십시오. 해결되지 않으면 장애 시각, Agent ID, 레시피 단계, 오류 화면을 수집하여 담당자에게 전달하십시오.

| 증상 | 원인 | 확인/조치 |
| --- | --- | --- |
| Agent 초록 점 안 뜸 | Agent 또는 NATS 연결 끊김 | Agent는 5초마다 상태를 보내며 Master는 15초 동안 상태가 없으면 오프라인으로 판정합니다. Agent 콘솔의 `Connected to NATS`와 NATS URL을 확인하고, `Test-NetConnection <NATS IP> -Port 4222`의 `TcpTestSucceeded`가 `True`인지 확인하십시오. |
| 캡처 타임아웃 | 스텝 CameraIndex와 AgentId 불일치 | 스텝 CameraIndex ↔ AgentId 매칭(4.6)을 확인하십시오. 예: CameraIndex=1 → Agent_1 |
| PLC 온습도 0 고정 | PLC 통신 설정 또는 연결 문제 | `%LOCALAPPDATA%\HeatingCameraSystem\hardware.json`의 `Plc.IpAddress`와 `Port`를 확인하고, `Test-NetConnection <PLC IP> -Port 2004`의 `TcpTestSucceeded`가 `True`인지 확인하십시오. |
| 값이 이상한 숫자 | PLC 장치 주소 또는 비트 인덱스 설정 오류 | `%LOCALAPPDATA%\HeatingCameraSystem\hardware.json`의 D/M/P 토큰과 `UseHexBitIndex`를 확인하십시오. 온도·습도 값은 모두 ÷10 스케일입니다. |
| Devices에 카메라 안 뜸 | Manager 또는 NATS 연결 문제 | HCS-Manager 예약 작업이 `Running`인지, Master와 Manager가 동일한 NATS 서버를 사용하는지 확인하십시오. `<AgentManager 실행 파일 폴더>\manager-state.json`의 해당 카메라 항목도 확인하십시오. |
| 승인했는데 Agent 안 뜸 | Agent 실행 파일 또는 Manager 설정 문제 | `AgentExePath`에 Agent.exe가 존재하는지 확인하고 `<AgentManager 실행 파일 폴더>\logs\{AgentId}` 로그를 확인하십시오. SimulationMode이면 spawn하지 않습니다. |
| 셔터 미응답 | COM 포트 불일치, 포트 점유 또는 통신 설정 오류 | `<Agent 실행 파일 폴더>\agent.json`의 `PortName`과 시리얼 통신 설정을 확인하십시오. 다른 프로그램이 COM 포트를 점유하고 있지 않은지 확인하고, 화면의 셔터 상태뿐 아니라 실제 셔터 상태도 함께 확인하십시오. 화면의 상태는 물리 장치에서 조회한 값이 아니라 소프트웨어에 저장된 상태입니다. |
| 캡처 실패 | 카메라 드라이버, USB 연결 또는 장치 점유 문제 | 카메라 드라이버와 USB 연결을 확인하고 다른 프로그램이 카메라를 점유하고 있지 않은지 확인하십시오. 이후 Agent 콘솔에서 캡처 실패 시각의 로그를 확인하십시오. |
| 레시피 '챔버 안정화' 멈춤 | 현재 온도가 목표 온도의 허용 오차 안에 들지 않음 | 안정화 완료는 현재 온도와 레시피 설정의 `TemperatureTolerance`만으로 판정합니다. 운전자가 **STOP**으로 자동 운전을 중지한 뒤 히터 상태와 온도 측정값을 확인하십시오. |
| data.db 열 수 없음 | Master 중복 실행 또는 데이터베이스 파일 오류 | 실행 중인 모든 Master 프로세스를 종료한 뒤 Master를 다시 실행하십시오. 계속 실패하면 `%LOCALAPPDATA%\HeatingCameraSystem\data.db` 원본을 보존하고 복사본을 백업한 뒤 담당자에게 전달하십시오. |
