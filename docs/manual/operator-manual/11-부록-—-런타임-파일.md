# 11. 부록 — 런타임 파일

| 파일 | 위치 | 비고 |
| --- | --- | --- |
| hardware.json | %LOCALAPPDATA%\HeatingCameraSystem\ | Master 설정. 최초 실행 시 자동 생성 |
| data.db | %LOCALAPPDATA%\HeatingCameraSystem\ | 레이아웃, 촬영·챔버·알람 이력, 카메라 설정 등을 저장하는 LiteDB |
| recipe\*.json | %LOCALAPPDATA%\HeatingCameraSystem\recipe\ | 현재 레시피의 실제 저장소 |
| agent.json | Agent exe 폴더 | 콘솔 Agent 설정. 일반 실행 시 자동 생성 |
| Agent 원본 이미지 | Agent StoragePath | 기본 위치: `<Agent exe>\ImageStorage\` |
| Master 이미지 캐시 | %LOCALAPPDATA%\HeatingCameraSystem\ImageCache\ | Master가 사용하는 캡처 이미지 캐시 |
| manager-settings.json | `<InstallRoot>\Manager\` | Manager 설정. 시작 시 1회 로드, 누락 시 메모리 기본값 사용(자동 저장 안 함) |
| manager-state.json | `<InstallRoot>\Manager\` | Manager 카메라 승인·상태. `ManagerStateStore`가 생성·갱신(직접 편집 금지) |
| agentui.json | `%LOCALAPPDATA%\HeatingCameraSystem\AgentUI\` | AgentUI 설정. 누락·읽기 실패 시 생성 |
| AgentUI 캡처 | `%LOCALAPPDATA%\HeatingCameraSystem\AgentUI\Captures\` | AgentUI 기본 캡처 폴더 |
| 콘솔 Agent 로그 | `<Agent exe>\logs\agent-YYYYMMDD.log` | 한 줄 JSON(CLEF) 일별 롤링, 최근 7개 파일 보존(`LogPath`로 변경 가능) |
| AgentUI 로그 | `%LOCALAPPDATA%\HeatingCameraSystem\AgentUI\logs\agentui-YYYYMMDD.ndjson` | CLEF NDJSON 일별 롤링, 최근 14개 파일 보존 |
| AgentManager 감시 로그 | `<InstallRoot>\logs\{AgentId}\` | Manager가 수집하는 Agent 로그 경로(배포 시 Agent `LogPath`와 일치) |

## 경로 표기

- `%LOCALAPPDATA%`는 현재 Windows 사용자별 로컬 응용 프로그램 데이터 폴더이다. 파일 탐색기 주소 표시줄에 `%LOCALAPPDATA%\HeatingCameraSystem`을 입력해 실제 경로를 확인한다.
- `<Agent exe>`는 실행 중인 콘솔 Agent 실행 파일이 있는 폴더이다.
- `StoragePath`는 `agent.json`에 지정된 이미지 저장 경로이다.
- `<InstallRoot>`는 AgentManager 설치 루트이며 기본값은 `C:\HeatingCameraSystem`이다.

## 생성·변경·삭제

- `hardware.json`은 Master 최초 실행 시 생성된다. 변경 내용은 Master를 재시작한 뒤 적용된다. 삭제하면 다음 실행 시 기본값으로 다시 생성된다.
- `data.db`가 없으면 자동 생성된다. 삭제하면 저장된 레이아웃, 이력, 카메라 설정 등의 데이터가 유실된다.
- `recipe\*.json`은 레시피 저장 시 생성된다. 삭제한 레시피 데이터는 자동 복구되지 않는다.
- 콘솔 Agent의 `agent.json`은 일반 실행 시 실행 파일 폴더에 생성된다. 다중 인스턴스 CLI 실행에서는 파일을 만들지 않고 실행 인수와 기본값을 사용할 수 있다. 설정 변경 후에는 Agent를 재시작한다.
- Agent 원본 이미지와 Master 이미지 캐시는 서로 다른 저장소이다. 파일을 삭제하면 해당 위치의 이미지가 유실된다.
- `manager-settings.json`과 `manager-state.json`은 별도 파일이다.

## 백업·용량 관리

`data.db`, `recipe\*.json`, 필요한 캡처 이미지와 로그는 운영 정책에 따라 백업하고 저장 장치의 여유 공간을 정기적으로 확인한다. 세부 설정은 [04. 설정 파일 레퍼런스](04-설정-파일-레퍼런스.md), LiteDB 관리는 [09. LiteDB(data.db) 관리](09-LiteDB(data.db)-관리.md)를 참조한다.
