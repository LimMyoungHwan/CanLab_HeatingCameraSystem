# 6. 시리얼 셔터 프로토콜

셔터는 7바이트 raw binary로 제어한다(ASCII 명령 아님).

```
열기:  0x04 0x00 0x01 0x00 0x00 0x00 0x00
닫기:  0x04 0x00 0x00 0x00 0x00 0x00 0x00
(3번째 바이트만 0x01/0x00 차이. cameraIndex는 식별용이며 버퍼에 안 들어감)
```

- 상태 조회 미지원 → 마지막 명령 기준 소프트웨어 캐시 반환
- 다른 셔터 모델: Protocols/SerialShutterController.cs의 _openBuffer/_closeBuffer 수정 후 재배포
