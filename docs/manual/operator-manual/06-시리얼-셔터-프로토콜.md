# 6. 시리얼 셔터 프로토콜

셔터는 7바이트 raw binary로 제어한다(ASCII 명령 아님).

```
열기:  0x04 0x00 0x01 0x00 0x00 0x00 0x00
닫기:  0x04 0x00 0x00 0x00 0x00 0x00 0x00
```

두 명령은 왼쪽 세 번째 바이트(오프셋 2)만 `0x01`/`0x00`으로 다르다. `cameraIndex`는 식별자일 뿐 전송 버퍼에는 포함되지 않는다.

- 상태 조회 미지원 → 마지막 명령 기준 `_isOpen` 소프트웨어 캐시 반환
- 캐시값은 실제 셔터 상태를 보장하지 않으며, 재시작 직후 기본값은 `false`(닫힘)
- 구현 소스: `HeatingCameraSystem.Protocols/SerialShutterController.cs`
- 포트·보레이트 등 연결 설정: [4. 설정 파일 레퍼런스](04-설정-파일-레퍼런스.md)의 `SerialSettings` 참조
- 다른 셔터 모델: 제조사 프로토콜과 통신 조건을 확인하여 `_openBuffer`/`_closeBuffer`를 수정하고, 빌드·테스트·실장비 검증 후 재배포
- 설치 또는 설정 변경 후 열기와 닫기를 각각 실행하고 실제 동작 확인
