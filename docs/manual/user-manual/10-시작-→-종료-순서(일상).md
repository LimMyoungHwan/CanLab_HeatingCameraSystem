# 10. 시작 → 종료 순서(일상)

1. NATS 서버가 켜져 있는지 확인(보통 상시 가동)
2. Master 실행 → 자동으로 NATS/PLC 연결(실패해도 화면은 뜸)
3. 카메라(Agent) PC 기동 → Agent 또는 AgentUI 프로그램 실행 → 대시보드에서 Agent 온라인 표시 확인 후 진행

> 📷 대시보드의 PLC 상태와 Agent 온라인 수 화면

4. Agent 설정을 변경하는 경우에만 설정 조회 → 값 편집·전송 → ACK로 성공 여부 확인
5. 대시보드에서 레시피 선택 → 선택한 레시피와 PLC·필요 Agent 상태 확인 → START

> 📷 대시보드의 레시피 선택과 START/STOP 화면

6. 진행률·현재 단계·알람 수로 모니터링

> 📷 대시보드의 진행률·현재 단계·알람 화면

7. 대시보드 상태가 `완료`인지 확인 → 이력 조회에서 촬영 결과 확인(성공한 촬영만 이력에 저장됨)

> 📷 이력 조회 화면

8. 종료 전 레시피 상태가 `완료` 또는 `중지됨`인지 확인 → 프로그램 종료(Master 창을 닫아도 실행 중 레시피에 STOP 명령이 자동으로 호출되지 않음)
