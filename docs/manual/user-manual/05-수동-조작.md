# 5. 수동 조작

레시피 없이 챔버·서보·흑체·장비·카메라를 직접 조작하는 화면이다. 초기 셋업, 점검, 좌표 확인 등에 사용한다.

수동 조작 전 자동 운전이 정지되어 있고 비상정지가 해제되어 있는지 확인한다. PLC를 사용하는 조작은 PLC 연결 상태를, 카메라 조작은 대상 Agent와 카메라의 연결 상태를 확인한 후 실행한다. 명령의 성공·실패 및 통신 오류는 화면 하단 상태 메시지에서 확인한다.

> 📷 **[그림 10] 수동 조작 전체**
> - **캡처 대상:** 수동 조작 화면 전체
> - **화면/상태:** 모든 카드가 보이도록
> - **표시 영역:** 창 전체


## 5.1 챔버 / 온도 램프

1. PLC 연결 상태와 비상정지 해제 여부를 확인한다.
2. 목표 온도(℃)와 목표 습도(%RH)를 입력하고 각각 '적용'을 누른다. 습도 제어가 필요하면 '습도 제어'를 선택한다.
3. 화면 하단 상태 메시지에서 적용 결과를 확인한 후 '온도제어 시작'을 누른다. 정지하려면 '온도제어 정지'를 누른다.
4. 온도 램프는 챔버 온도제어가 실행 중일 때 사용한다. 목표 온도(℃)와 도달시간(분)을 입력하고 '램프 시작'을 누른다. 중단하려면 '중지'를 누른다.
5. 화면 하단 상태 메시지에서 적용·실행 결과와 램프 진행 또는 완료 상태를 확인한다.

입력값은 설비에 설정된 허용 범위 안에서 입력한다.

> 📷 **[그림 11] 챔버·온도 램프 카드**
> - **캡처 대상:** 수동 조작 좌측 상단의 챔버 카드와 온도 램프 카드
> - **화면/상태:** 정상 표시 상태
> - **표시 영역:** 창 왼쪽 위


## 5.2 모터/팬 · 장비 원터치

1. PLC 연결 상태를 확인한다.
2. '서보 속도 (1~100%)' 또는 '팬 속도 (Hz)' 값을 입력하고 '적용'을 누른다. 팬 속도 적용 후 '현재' 값이 갱신되는지 확인한다.
3. 장비 원터치에서 '1차 냉동기', '2차 냉동기', '상온 냉동기', '블로워1', '블로워2', '칠러', '도어락', '조명', '페어글라스' 토글을 선택한다.
4. 토글 상태를 바꾸면 PLC 명령이 즉시 전송된다. 토글의 상태 표시와 화면 하단 상태 메시지에서 결과를 확인한다.

팬 속도는 설비에 설정된 허용 범위 안에서 입력한다.

> 📷 **[그림 12] 장비 원터치 카드**
> - **캡처 대상:** 장비 원터치 토글 스위치들이 있는 카드
> - **화면/상태:** 토글 상태가 보이도록
> - **표시 영역:** 창 가운데/우측


## 5.3 서보 조작

1. PLC 연결 상태와 비상정지 해제 여부를 확인한다. X BUSY 또는 Y BUSY 표시가 켜져 있으면 해당 축이 이동 중이므로 추가 이동 명령을 실행하지 않는다.
2. JOG 이동은 'X 축 JOG -', 'X 축 JOG +', 'Y 축 JOG -', 'Y 축 JOG +' 버튼을 누르는 동안 해당 방향으로 이동하며, 버튼을 떼면 정지한다.
3. 원점 복귀는 'X 원점' 또는 'Y 원점'을 누른 후 해당 축의 BUSY 표시가 꺼지고 위치값이 원점으로 갱신되는지 확인한다.
4. 절대 위치 이동은 X 또는 Y 목표 위치(mm)를 입력하고 'X 이동' 또는 'Y 이동'을 누른다. 상대 위치 이동은 스텝값(mm)을 입력하고 해당 축의 '-' 또는 '+'를 누른다.
5. 포인트 이동은 1~20번 버튼 중 하나를 누른다. 각 포인트의 좌표는 PLC 설정 화면의 '서보 포인트 좌표 (20)'에 저장된 값을 사용한다.
6. 이동 후 X/Y 위치, BUSY 표시, 현재 포인트와 화면 하단 상태 메시지에서 결과를 확인한다.

위치와 스텝값은 설비에 설정된 허용 범위 안에서 입력한다.

> 📷 **[그림 13] 서보 조작 카드**
> - **캡처 대상:** 서보 조작 카드(JOG·원점·절대/상대 이동)와 포인트 이동(20버튼)
> - **화면/상태:** 위치값이 표시된 상태
> - **표시 영역:** 창 가운데


## 5.4 흑체 / 카메라 제어

1. 흑체 컨트롤러 연결 상태를 확인한다. '흑체1 목표(℃)' 또는 '흑체2 목표(℃)'에 기준 온도를 입력하고 '적용'을 누른다.
2. 화면에 표시되는 흑체별 '현재' 값과 화면 하단 상태 메시지에서 적용 결과를 확인한다. 목표 온도는 설비에 설정된 허용 범위 안에서 입력한다.
3. 대상 Agent와 카메라의 연결 상태를 확인한 후 '카메라 선택'에서 조작할 카메라를 선택한다. 필요하면 컬러맵을 선택한다.
4. 'RUN'은 카메라를 실행하고 'STOP'은 실행을 중지한다. '셔터 열기'와 '셔터 닫기'는 셔터를 제어하고, '캡처'는 선택한 카메라에 캡처 명령을 전송한다. 'NUC'는 비균일 보정(Non-Uniformity Correction)을 실행한다. '설정 저장'과 '정보 갱신'은 선택한 카메라에 해당 명령을 전송한다.
5. 명령 후 카메라 이름 옆의 Ack 상태를 확인한다. '⏳'는 전송됨, '✔'는 성공, '✘'는 실패 또는 전송 오류를 의미한다. RUN 실행 후에는 실시간 영상이 표시되는지도 확인한다.

> 📷 **[그림 14] 카메라 제어 카드**
> - **캡처 대상:** 수동 조작 하단의 카메라 제어 카드(영상 + RUN/STOP/셔터/캡처/NUC 버튼)
> - **화면/상태:** 카메라 영상이 나오는 상태
> - **표시 영역:** 창 아래쪽

> **[주의]** 비상정지 버튼은 즉시 챔버 온도제어를 정지시킨다. 실제 설비에서 이상 상황 시 주저하지 말고 사용한다.
