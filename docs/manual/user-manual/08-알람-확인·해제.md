# 8. 알람 확인·해제

알람 패널은 Master 주 창의 왼쪽 탐색 영역에 항상 표시됩니다.

## 실시간 알람 확인

- 새 알람은 목록 맨 위에 추가되며 최대 100건까지 표시됩니다.
- 각 항목에서 발생 시각, 발생원, 메시지를 확인합니다.
- “확인”은 화면에 표시된 정보를 읽는 것을 의미하며 별도의 확인·인지 상태는 없습니다.
- 등급 필터는 단일 선택 콤보 상자입니다. 기본값은 `전체`이며 `전체/정보/경고/오류` 중 하나를 선택하면 해당 등급과 정확히 일치하는 현재 알람만 표시됩니다.

## 알람 표시 삭제

- 각 알람 옆 ✕를 누르면 별도 선택이나 상세 확인 없이 해당 항목이 현재 메모리 목록에서 제거됩니다.
- ✕는 PLC 상태, 부저 또는 오류 비트를 변경하지 않습니다.
- 알람은 발생 시 별도 이력 저장소에 기록되므로 현재 목록에서 삭제해도 이력은 유지됩니다.

## PLC 제어

- **PLC 부저 OFF:** PLC의 부저 OFF 트리거 비트에 모멘터리 펄스를 전송합니다. 현재 알람 목록은 삭제하지 않습니다.
- **PLC 에러 리셋:** PLC의 에러 리셋 트리거 비트에 모멘터리 펄스를 전송합니다. 버튼을 누른 것만으로 오류 해제가 완료된 것은 아닙니다.
- **PLC 원점 복귀:** X/Y 좌표를 0,0으로 설정한 포인트 1 이동을 요청합니다. 수동 제어 화면의 축별 원점 복귀 기능과는 다릅니다.
- 버튼 아래 메시지에는 PLC 명령 호출의 완료 시각 또는 실패 사유가 표시됩니다. PLC가 초기화되지 않았거나 통신 예외가 발생한 경우에도 실패 메시지가 표시됩니다.
- 실제 오류 해제와 원점 도달 여부는 PLC 상태 화면에서 별도로 확인합니다.
- PLC 오류 감지 후 레시피 복구 잠금은 모든 오류 비트가 해제되고 X/Y 현재 위치가 각각 0점 ±0.5 mm 이내일 때 풀립니다. 자동으로 레시피가 재개되지는 않습니다.

## 알람 이력 조회

1. `이력 조회` 화면에서 `알람 이력` 탭을 선택합니다.
2. 시작일과 종료일을 설정합니다.
3. 알람 수준을 `전체/정보 이상/경고 이상/오류만` 중에서 선택합니다.
4. `조회`를 누릅니다.

> 📷 **[그림 21] 알람 패널·공용 버튼**
> - **캡처 대상:** 좌측 알람 목록과 PLC 부저 OFF/에러 리셋/원점 복귀 버튼
> - **화면/상태:** 알람이 표시된 상태
> - **표시 영역:** 창 왼쪽
