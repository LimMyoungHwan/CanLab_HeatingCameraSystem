# 11. 자주 겪는 문제(사용자용)

| 증상 | 확인 사항 |
| --- | --- |
| 대시보드에 카메라 초록 점이 없음 | 카메라는 기본 5초마다 하트비트를 보내며, Master는 15초 동안 응답이 없으면 오프라인으로 표시합니다. 카메라 PC가 켜져 있는지와 네트워크 연결을 확인하고, 15초 이상 계속 회색이면 운영자에게 문의 |
| 촬영이 제한시간 초과(캡처 타임아웃) | 대상 Agent가 온라인인지와 지시한 카메라가 실제 카메라에 올바르게 매핑되어 있는지 확인하고, 문제가 계속되면 운영자에게 문의 |
| 온도/습도가 0으로 고정 | PLC 연결 표시가 비정상이면 PLC 또는 네트워크 연결을 확인하고, 연결 표시가 정상인데도 온도와 습도가 계속 0이면 운영자에게 장비 점검 문의 |
| 레시피가 '챔버 안정화'에서 멈춤 | 현재 온도가 목표 온도의 허용범위에 들어올 때까지 대기하는 단계입니다. 기다린 뒤에도 진행되지 않으면 장비를 직접 점검하거나 STOP 후 운영자에게 문의 |
| 히터/카메라가 반응 없음 | 수동 조작 화면과 카메라 제어에서 RUN/히터 동작 상태를 확인하고, 계속 반응하지 않으면 운영자에게 문의 |
| 알람이 계속 뜸 | 알람 필터는 표시만 걸러 주며 원인을 해소하지 않습니다. 부저 끄기와 오류 리셋은 별도 기능이므로 원인을 확인한 뒤 필요한 조치를 하고, 알람이 다시 발생하면 운영자에게 문의 |
| RECIPE 목록이 비어 있음 | 목록을 새로고침한 뒤 항목을 추가하고, 계속 비어 있거나 추가할 수 없으면 운영자에게 문의 |

운영자에게 문의할 때는 문제 발생 시각, 대상 Agent/카메라, 알람 메시지, PLC 및 Agent 연결 상태를 함께 전달합니다.
