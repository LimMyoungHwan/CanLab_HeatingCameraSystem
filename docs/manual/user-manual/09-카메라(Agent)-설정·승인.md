# 9. 카메라(Agent) 설정·승인

'Agent 설정' 화면은 두 개의 탭으로 구성된다. 카메라 PC(Agent) 원격 설정과, 새 카메라 승인·관리다. Agent는 카메라 PC에서 실행되며, 하나의 Agent 설정에 여러 카메라 항목을 추가·삭제할 수 있다. 상세한 관리는 운영자 매뉴얼을 따르고, 여기서는 운전자가 마주치는 기본만 다룬다.

- 탭1 '에이전트 원격설정': 온라인 Agent 선택 → [조회] → 값 확인·수정 → [설정 전송] → 화면 하단 성공/실패 메시지 확인
- 탭2 '디바이스 관리': 발견된 카메라 목록에서 미승인 카메라를 선택해 [승인] 또는 [거부], [이름 저장], [시리얼 전송], [로그 가져오기]

## 에이전트 원격설정

온라인 Agent를 선택하고 [조회]를 누른다. 조회 전에는 입력 폼이 숨겨지고 안내 문구만 표시된다. 조회가 완료되면 다음 설정값을 확인하거나 수정할 수 있다.

- NATS URL
- 저장 경로
- 하트비트 주기(Agent 상태 보고 간격, 초)
- 캡처 포맷과 장수
- 카메라 목록의 Agent ID, OpenCV 인덱스, 별칭, 장치명, 시리얼 COM

카메라 목록은 [카메라 추가]와 [삭제]로 편집한다. 수정을 마치면 [설정 전송]을 누르고 화면 하단 메시지에서 성공 또는 실패 여부를 확인한다.

전송된 설정은 저장되며 AgentUI를 재시작한 뒤 적용된다. 성공하면 '저장됨. AgentUI 재시작 후 적용됩니다.'가 표시된다. 응답이 없으면 Agent가 온라인 목록에 있는지와 Master·Agent의 NATS 연결 상태를 확인한다.

## 디바이스 관리

카메라 인벤토리는 자동으로 수신되지만, 승인은 운전자가 미승인 장치를 선택하고 [승인]을 눌러 요청한다.

- [승인]: 미승인 장치를 선택한 경우에만 활성화
- [거부], [이름 저장], [로그 가져오기]: 장치 선택 필요
- [시리얼 전송]: 승인된 장치를 선택한 경우에만 활성화

[이름 저장]을 누르면 선택한 카메라의 Alias(별칭)를 AgentManager로 전송하고 Master의 카메라 장치 저장소에도 갱신한다.

[로그 가져오기]는 최대 5 MiB의 로그를 요청한다. 30초 동안 응답이 없으면 시간 초과 메시지가 표시된다.

> 📷 **[그림 22] Agent 설정 — 에이전트 원격설정**
> - **캡처 대상:** Agent 설정 탭1(온라인 Agent 선택 + 설정 폼 + 카메라 목록)
> - **화면/상태:** Agent 1대를 조회해 값이 채워진 상태
> - **표시 영역:** 창 가운데

> 📷 **[그림 23] Agent 설정 — 디바이스 관리**
> - **캡처 대상:** Agent 설정 탭2(발견 카메라 목록 + 승인/거부/이름저장/시리얼 설정)
> - **화면/상태:** 카메라 1대 이상 표시된 상태
> - **표시 영역:** 창 가운데

> **[참고]** 새 카메라를 붙였는데 촬영이 안 되면, 이 '디바이스 관리' 탭에서 해당 카메라가 승인(Approved)되어 있는지 먼저 확인한다. 카메라 인벤토리는 자동으로 수신되며, 승인은 미승인 장치를 선택해 [승인]을 눌러 요청한다. 운영자 매뉴얼 7장 참조.
