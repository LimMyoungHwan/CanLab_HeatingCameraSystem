# 6. 상태 모니터링(PLC 상태)

PLC의 전체 상태를 감시하는 읽기 전용 화면이다. 정상 동작 시 기본 1초 간격으로 상태 읽기를 시도하며, 이 화면에는 값을 바꾸는 제어 명령이 없다.

> 📷 **[그림 15] PLC 상태 화면**
> - **캡처 대상:** PLC 상태 화면 전체(상단 요약 바 + 각 카드)
> - **화면/상태:** PLC 연결된 상태(값이 표시됨)
> - **표시 영역:** 창 전체

- 상단 요약: PLC 연결, 챔버 온도(현재/목표), 챔버 습도(현재/목표), 진행 상태(현재 단계 / 전체 단계와 진행 막대), 서보 포인트(POINT·X/Y)
- PLC 연결: 연결 시 녹색, 연결 끊김 시 빨간색으로 표시한다. 하단 상태 메시지에는 `갱신 HH:mm:ss` 또는 `읽기 실패: ...`가 표시된다. 읽기 실패 시 수치와 램프가 빈 스냅샷의 기본값으로 바뀌므로, 빨간 연결 램프와 상태 메시지를 함께 확인한다.
- 챔버 환경 카드: 챔버 현재·목표 온도(℃), 현재·목표 습도(%RH), 팬 속도(Hz), GAS 유속을 표시한다.
- 흑체 기준 온도 카드: 흑체 1·2의 현재·목표 온도(℃)를 표시한다.
- 서보·직교로봇 카드: X/Y 현재 위치(mm), PLC가 보고한 현재 포인트 번호(POINT), X/Y 에러코드와 X/Y BUSY·원점 램프를 표시한다.
- 진행·기타 카드: 현재 단계 / 전체 단계 값과 진행 막대를 표시한다.
- PLC 알람 카드: 모든 등록 알람명이 항상 나열되며, 활성 오류 비트는 빨간색, 비활성 비트는 회색으로 표시한다. 알람 확인과 해제는 8장 「알람 확인·해제」를 참조한다.
- 하단 입력/출력: 입력 P000~P01F와 출력 P020~P03F 중 이름이 설정된 신호만 표시한다. 녹색은 비트 ON, 회색은 OFF이며, 점등은 논리 상태를 나타낼 뿐 정상 판정 자체를 뜻하지 않는다.
- 하단 장비 상태: 히터, 1차 냉동기, 2차 냉동기, 상온 냉동기, 바이패스, 도어램프, 페어글라스, MCF, 블로워 1·2를 표시한다. 녹색은 비트 ON, 회색은 OFF이다.
- PLC 알람은 오류 비트를 나타내고, 입력·출력과 장비 램프는 해당 비트의 ON/OFF 상태를 나타낸다.
- 기본 1초 간격으로 상태를 읽으므로 그보다 짧은 비트 변화는 화면에서 놓칠 수 있다.

그림 15는 연결 램프, 상태 메시지, 수치와 진행 상태가 함께 보이는 화면을 기준으로 확인한다.

> 📷 **[그림 16] PLC 입출력·장비 램프**
> - **캡처 대상:** PLC 상태 화면 하단의 입력/출력/장비 상태 표시등 영역
> - **화면/상태:** 정상 표시 상태
> - **표시 영역:** 창 아래쪽

그림 16은 녹색과 회색 램프가 함께 보이는 화면을 기준으로 확인한다.
