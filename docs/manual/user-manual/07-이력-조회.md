# 7. 이력 조회

촬영 결과와 챔버 데이터, 알람을 조회할 수 있다. 이력 조회 화면 상단의 [촬영 이력]·[챔버 이력]·[알람 이력] 버튼으로 이력을 전환한다.

이력 종류 선택 → 시작일·종료일 지정 → 필요한 필터 선택 → [조회] → 결과 확인 순서로 조회한다. 세 이력 모두 같은 날짜 필터와 [조회] 버튼을 사용하며, 타임스탬프 내림차순으로 조회하여 `yyyy-MM-dd HH:mm:ss` 형식으로 표시한다. 화면에서는 UTC/로컬 시간 변환을 수행하지 않는다.

조회 조건은 시작값 이상, 종료값 이하이다. 최초 날짜 범위는 오늘 00:00을 기준으로 이틀 전부터 오늘 23:59:59까지이다. 종료일을 다시 선택하면 해당 날짜 00:00으로 설정된다. 시작일이 종료일보다 늦으면 별도 경고 없이 결과가 비게 된다.

모든 이력은 페이지당 10건을 표시한다. `«`, `‹`, `›`, `»` 버튼으로 처음·이전·다음·마지막 페이지를 이동하며, 현재/전체 페이지와 레코드 수를 확인할 수 있다. 조회 결과가 없으면 별도 안내 없이 표가 비고 `Showing 1-0 of 0 records`가 표시된다.


## 7.1 촬영 이력

- 필터: 시작/종료 날짜, 카메라 그룹 → [조회]
- 카메라 그룹: 드롭다운의 기본값은 `All Units`이며, `Agent-PC-01(CAM-01~16)`, `Agent-PC-02(CAM-17~32)`, `Agent-PC-03(CAM-33~64)` 중에서 선택
- 표: 타임스탬프, 카메라 ID, 온도(℃), 습도(%RH), 썸네일, [열기]
- 온도와 습도: 촬영 시 PLC에서 읽은 현재 챔버 온도와 습도이며, PLC 읽기 실패 시 두 값 모두 `0`으로 기록
- 썸네일과 상세 창: 동일한 `ImagePath`를 표시하며, 경로가 없거나 이미지를 읽지 못해도 별도 안내나 대체 이미지는 표시되지 않음
- [CSV 내보내기]: 현재 페이지가 아니라 지정한 날짜와 카메라 그룹에 맞는 촬영 이력 전체를 파일로 저장

[CSV 내보내기]를 누르면 저장 대화 상자에서 위치를 선택한다. 기본 파일명은 `history_yyyyMMdd_HHmmss.csv`이며 UTF-8 BOM 형식으로 저장된다. 열은 `Timestamp, CameraId, Temperature, Humidity, RecipeStepId, ImagePath`이고, 타임스탬프는 ISO 8601 형식, 온도와 습도는 소수 둘째 자리까지 기록된다. 저장에 성공하면 하단 상태 문구가 `Exported N records to 파일명`으로 바뀐다. 별도 성공 창이나 쓰기 실패 전용 안내는 없다.

카메라 그룹 필터와 CSV 저장 범위는 촬영 이력에만 적용된다. 챔버·알람 이력 화면에서도 CSV 버튼은 표시되지만 내보내는 내용은 촬영 이력이다.

촬영 이력과 캐시 이미지는 `DataRetentionDays` 설정에 따라 기본 30일 보관되며 하루마다 정리된다.

> 📷 **[그림 17] 이력 조회 — 촬영 이력**
> - **캡처 대상:** 촬영 이력 탭(필터 + 표 + 썸네일)
> - **화면/상태:** 조회 결과가 여러 건 표시된 상태
> - **표시 영역:** 창 가운데


## 7.2 챔버 이력

- 표: 시간, 온도(°C), 습도(%RH), BB1(°C), BB2(°C)
- BB1·BB2: 기록 시점의 흑체 1·2 현재온도(PV)

챔버 이력에는 현재 자동 삭제가 연결되어 있지 않다.

> 📷 **[그림 18] 이력 조회 — 챔버 이력**
> - **캡처 대상:** 챔버 이력 탭(시간/온도/습도/BB1/BB2 표)
> - **화면/상태:** 조회 결과 표시 상태
> - **표시 영역:** 창 가운데


## 7.3 알람 이력

- 필터: 시작/종료 날짜, 알람 수준 → [조회]
- 알람 수준: `전체`, `정보 이상`, `경고 이상`, `오류만`
- 조회 범위: 각각 전체, Info 이상, Warning 이상, Error만 조회
- 표: 시간, 등급, 출처, 메시지
- 조회 전용 목록이며 확인·해제 기능은 없음

알람 이력에는 현재 자동 삭제가 연결되어 있지 않다.

> 📷 **[그림 19] 이력 조회 — 알람 이력**
> - **캡처 대상:** 알람 이력 탭(시간/등급/출처/메시지 표 + 알람 수준 필터)
> - **화면/상태:** 알람이 조회된 상태
> - **표시 영역:** 창 가운데


## 7.4 이미지 상세 보기

촬영 이력에서 [열기]를 누르면 동일한 이미지 한 장, 카메라 ID, 타임스탬프, 온도, 습도 및 고정된 10°~70° 색상 막대가 있는 상세 창이 뜬다. 우측 상단 [✕] 버튼으로 닫는다.

> 📷 **[그림 20] 이미지 상세 보기**
> - **캡처 대상:** 촬영 이미지 상세 모달(확대 이미지 + 열화상 스케일 + 메타정보)
> - **화면/상태:** 이미지 1건을 연 상태
> - **표시 영역:** 화면 중앙 팝업
