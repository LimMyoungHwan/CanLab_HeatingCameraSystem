# 3. 대시보드

대시보드는 운전 중 가장 많이 보는 화면이다. 좌측 텔레메트리 카드, 가운데 카메라 영상, 우측 카메라(Agent) 목록과 레시피 실행 패널로 구성된다.

> 📷 **[그림 4] 대시보드 전체**
> - **캡처 대상:** 대시보드 화면 전체
> - **화면/상태:** 레시피 실행 중이면 진행바가 보여 더 좋음
> - **표시 영역:** 창 전체


## 3.1 상단 상태 요약(HUD)

| 항목 | 표시 의미 |
| --- | --- |
| PLC | 초록색은 연결, 빨간색은 연결 끊김 |
| AGENTS | 현재 온라인 Agent 수를 `N ONLINE` 형식으로 표시 |
| POINT | 현재 서보가 위치한 포인트 번호 |
| ALARMS | 현재 알람 건수 |

- 비상정지가 걸리면 상단에 'EMERGENCY STOP ACTIVE · 비상정지 동작 중' 배너 표시


## 3.2 텔레메트리 카드(좌측)

PV는 현재값, SV는 목표값, BUSY는 서보 축이 동작 중임을 뜻한다.

| 카드 | 표시 내용 |
| --- | --- |
| CHAMBER(챔버) | 현재/목표 온도(℃), 현재/목표 습도(%RH), 온·습도 추세 그래프 |
| BLACKBODY(흑체) | 흑체1/2 현재값(PV)·목표값(SV) |
| MOTION(서보) | X/Y 위치(mm), X/Y 동작 중(BUSY)·원점 표시등, X/Y 에러코드 |
| PROGRAM(진행) | 현재/전체 스텝, 팬 속도(Hz), 가스 유속 |
| EQUIPMENT(장비) | 히터·1차 냉동·2차 냉동·상온 냉동·바이패스·도어램프·페어글라스·MCF·블로워1/2 표시등 |


## 3.3 카메라 영상(가운데)

- Mode 1은 레시피 실행 중 현재 스텝의 활성 카메라 1대를 자동으로 추적하며, 활성 카메라가 없으면 '대기'로 표시
- 고정 분할 모드는 Mode 2(8칸)/Mode 3(4칸)/Mode 4(2칸)/Mode 5(1칸)
- 컬러맵 선택(컬러/그레이스케일)
- Mode 2~5에서는 우측 카메라 목록에서 카메라를 선택한 뒤 가운데 영상 칸으로 끌어다 놓아 배치, 우클릭으로 비움
- 빈 칸에는 'DRAG CAMERA HERE' 표시
- 각 칸에 카메라 번호·실시간 영상·측정 온도(℃) 표시, 신호 없으면 'No Signal'

> 📷 **[그림 5] 카메라 영상 영역**
> - **캡처 대상:** 가운데 카메라 피드 그리드와 상단 Mode 1~5 버튼, 컬러맵 선택
> - **화면/상태:** 카메라가 1대 이상 영상을 표시 중인 상태
> - **표시 영역:** 창 가운데


## 3.4 카메라(Agent) 목록(우측)

- 카메라 Agent를 PC별로 그룹화해 표시
- 각 Agent의 온라인 상태를 램프로 표시
- 연결 상태는 'Connected', 영상 송출 상태는 'Streaming'으로 표시
- Mode 2~5 영상 칸에 배치할 카메라를 끌어오는 출발점


## 3.5 레시피 실행 패널(우측)

1. RECIPE 드롭다운에서 실행할 레시피 선택(목록이 비면 새로고침 버튼)
2. START 버튼으로 실행 시작
3. 진행바(0~100%)와 상태 문구로 진행 확인
4. 중간 중단은 STOP 버튼으로 현재 실행 중인 레시피를 중단하며, 처리 중에는 '중지 중…' 표시
5. 상태 문구는 '실행 중: {레시피명}', '완료', '중지 중…', '오류: {메시지}'로 표시
6. CONFIG 버튼은 현재 사용하지 않음

레시피를 선택하지 않으면 '레시피 선택 필요'가 표시된다. PLC 에러가 발생한 뒤에는 에러를 클리어하고 서보 원점 복귀를 완료할 때까지 START 버튼이 잠긴다.

> 📷 **[그림 6] 레시피 실행 패널**
> - **캡처 대상:** 우측 RECIPE 선택 콤보 + START/STOP + 진행바 + 단계 문구
> - **화면/상태:** 레시피 실행 중(진행바가 차 있는 상태) 권장
> - **표시 영역:** 창 오른쪽 하단
